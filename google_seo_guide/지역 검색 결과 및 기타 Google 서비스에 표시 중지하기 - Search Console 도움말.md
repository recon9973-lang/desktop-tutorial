# 지역 검색 결과 및 기타 Google 서비스에 표시 중지하기

Google이 내 사이트에서 크롤링한 콘텐츠가 다음과 같은 여러 Google 서비스에 표시되지 않도록 선택 해제할 수 있습니다.

-   [Google 쇼핑](http://www.google.com/shopping)
-   [Google 항공편 검색](http://www.google.com/flights)
-   [Google 호텔](https://www.google.com/travel/hotels) 및 공유숙박
-   지역 검색 결과(지역 관련 검색어를 입력하면 표시되는 전문적인 검색 결과 페이지)

선택 해제 옵션을 선택하면 Googlebot이 크롤링한 사이트의 콘텐츠가 위 서비스에 표시되지 않습니다. 위 서비스에 현재 표시되고 있는 콘텐츠는 선택 해제 시점을 기준으로 30일 이내에 삭제됩니다.

선택 해제 옵션은 도메인 이름별로 적용됩니다. 예를 들어 `example.com`을 지정하면 하위 도메인(예: `sub.example.com`)을 비롯해 해당 도메인의 모든 콘텐츠를 선택 해제할 수 있습니다. 선택 해제된 도메인에 콘텐츠를 게재하는 도메인을 포함하여 추가 도메인을 소유한 경우(예: `example.org` 또는 `example2.com`), 별도의 도메인에 있는 콘텐츠에 선택 해제가 적용되도록 하려면 각 도메인을 별도로 선택 해제해야 합니다. 개별 하위 도메인(예: `sub.example.com`) 또는 도메인 내의 개별 디렉터리(예: `example.com/sub`)만 지정할 수는 없습니다.

지역 검색 결과의 경우 이 선택 해제 옵션이 전 세계적으로 적용됩니다. 나머지 서비스의 경우에는 선택 해제 옵션이 google.com 도메인에서 호스팅되는 서비스에만 적용됩니다.

[Search Console에서 선택 해제 설정 확인 또는 변경](https://search.google.com/search-console/opt-out)
