# GROUND(@ground_geo) 콘텐츠 스케줄 — 용어 설명 시리즈

배나미 페르소나(25세·캔디드·"훅 먼저 → 정보 뒤")로 SEO/GEO/AEO 핵심 용어를 하루 1개씩 쉽게 풀어주는 시리즈.
발행은 `queue.json` 순서대로 **하루 1장 자동**(`.github/workflows/publish-ig.yml`).

| 일차 | id | 주제(용어) | 훅 | 상태 |
|----|-----|-----------|-----|-----|
| 1 | geo-01 | GEO(생성형 엔진 최적화) | 요즘, 아무도 검색 안 해요 | 큐 대기 |
| 2 | aeo-02 | AEO(답변 엔진 최적화) | 챗GPT한테 우리 브랜드 물어봤더니… | 큐 대기 |
| 3 | seo-03 | SEO(검색 최적화) | SEO, 30초컷 요약 | 큐 대기 |
| 4 | eeat-04 | E-E-A-T | AI가 믿는 콘텐츠엔 이게 있어요 | 큐 대기 |
| 5 | schema-05 | 구조화 데이터(스키마) | AI한테 떠먹여 주는 법 | 큐 대기 |
| 6 | llmstxt-06 | llms.txt | AI한테 보내는 초대장 | 큐 대기 |
| 7 | mention-07 | 백링크→언급(멘션) | 링크보다 '언급'이 중요해요 | 큐 대기 |
| 8 | smartblock-08 | 네이버 스마트블록 | 네이버도 이제 '답'을 보여줘요 | 큐 대기 |

## 다음 이어갈 용어(백로그 후보)
지식그래프 / 시맨틱 검색 / NAP 일관성 / 롱테일 키워드 / 검색의도(인포·트랜잭션) /
코어 웹 바이탈 / 사이트맵·robots / 네이버 인플루언서·플레이스 / 리치 스니펫 / 제로클릭 검색

## 제작 규칙(고정)
- 이미지: 배나미 실사 소스(`scratchpad/nami/*`)를 베이스로 **정사각형 1080×1080** 렌더(훅 오버레이 + `GROUND 🌿` 배지). 인물·정체성 보존, 인체구조 QC 필수.
- 캡션: 훅 1줄 → 쉬운 설명 3~4포인트 → 참여 유도 → 해시태그(항상 `#GROUND` 포함).
- 중복 이미지 금지(포스트마다 다른 소스 컷).
- 의료·과장·보장 표현 배제.
