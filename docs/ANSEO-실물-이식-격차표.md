## 3. 이 방의 규율 준수 체크

- **배포 금지**: `VEO_DEPLOY_ORDER`(사장님 오더 원문) 없이는 deploy.sh가 거부 — 이 방은 커밋까지만, 배포는 별도 오더.
- **판 규율**: changelog.ts 맨 앞=APP_VERSION, api `__version__` 동기화, 계약 info.version 동기화, WORKLIST §2 미배포 목록 + WORKLIST-HISTORY 등재(관문 시험이 강제 — S1에서 실제로 빨간불을 먼저 맞고 등재함).
- **표기 규율**: formatScore만(반올림 금지), 서울 시각, 두 낱말(커밋·배포), 색으로만 말하지 않기, 명세 숫자 하드코딩 금지.
- **이 방의 한계**: API쪽 ci-local(파이썬·DB)은 못 돈다 — S1은 버전 문자열 외 API 무변경으로 한정했고, 서버 코드를 만지는 슬라이스(S6·S7)는 DB 있는 방 또는 CI로 검증한다.
