# 상권 탭 정렬 — 적용 체크리스트 (가 → 나 → 다)

## 0. 넣기 전에

| 할 것 | 확인 |
|---|---|
| `anseo-market-layout.css` 를 상권 화면 스타일에 넣는다 | 클래스는 전부 `mk-` 로 시작해 기존 것과 안 부딪힌다 |
| `:root` 블록의 값을 `packages/ui/tokens.css` 변수명으로 갈아 끼운다 | **이 블록 말고는 손댈 곳이 없다** |
| 현재 상권 화면의 카드 목록을 적어 둔다 | 다 에서 한 장도 빠뜨리지 않기 위해 |

## 가 · 지도에서 같은 과를 가른다 — 반나절

- [ ] `anseo-market-markers.js` 를 넣는다
- [ ] 마커를 셋으로 가른다 — `markerImage("same"|"other"|"us")`
      - 같은 과 `#c98500` 채운 점 + 링 (zIndex 30)
      - 그 외 `#3987e5` 속빈 점 (zIndex 20)
      - 우리 `#00ed64` 삼각 핀 (zIndex 40)
- [ ] 같은 과 판정은 `isSameDept(우리 과목, 상대 과목)` **한 곳에서만** 한다
      — 지도와 목록이 따로 판정하면 둘이 어긋난다
- [ ] 범례를 지도 위에 붙인다 — `legendHTML({same, other})`, 개수 병기
- [ ] 반경이 3km 이상이면 `needsCluster(전체)` 가 참 → 「군집 표기 필요」 띠를 띄운다

**받는 조건**
- 지도만 보고 같은 과와 그 외가 갈린다
- 색을 흑백으로 바꿔도 모양으로 갈린다 (색 단독 금지)
- 범례 개수 합 = 반경 표의 「전체」 값

---

## 나 · 경쟁 목록을 가로 3칸으로 — 반나절

- [ ] 「경쟁 — 1km」 막대 카드를 **지운다**
      — 오른쪽 반경 표와 같은 값을 두 번 그리고 있었고,
        9와 3,736을 한 축에 놓느라 작은 반경이 안 보였다
- [ ] 그 막대를 반경 표 안 **인라인 막대**(`.mk-ibar`)로 옮긴다
- [ ] 경쟁 목록을 `.mk-c12` (전폭)로 옮긴다
- [ ] 표에 `.mk-table` 을 입힌다 — 아래 넷이 한 벌이라 하나라도 빠지면 다시 밀린다
      - `table-layout:fixed`
      - `<col>` 로 열 폭 고정 (병원명 **280 이상**)
      - `white-space:nowrap`
      - `text-overflow:ellipsis` + `title` 툴팁으로 전문
- [ ] 표방 진료과목은 칩 **3개 + `+N`**, 전문은 `title`
- [ ] 숫자 열은 `.n` (tabular-nums · 우측 정렬)

**받는 조건**
- 한 곳이 **한 줄**이다 (병원명 12자 + 과목 5개 + 거리까지)
- 행이 넘쳐도 **카드 안에서만** 스크롤한다 — 바깥 화면은 안 밀린다
- 창을 1180 아래로 줄여도 열이 무너지지 않는다

**실측 — 왜 1칸으로는 안 되나**

| | 필요한 폭 |
|---|---|
| 쓸 수 있는 폭 (1칸) | ≈272px |
| 병원명 한 줄 | ≈180–260px |
| 과목 한 줄 (5개 붙는 곳 있음) | ≈300–430px |
| 거리까지 한 줄 | **≈560px 이상** |

폭이 모자라서 생긴 일이라 글자 크기를 줄여도 안 풀린다.

## 다 · 12칸 그리드로 세운다 — 1~2일

- [ ] 바깥을 `.mk-grid` 로 바꾼다 (세 줄 쌓기 제거)
- [ ] 카드 폭을 **4·5·6·7·8·12칸** 중에서만 고른다
- [ ] 카드 높이를 **S(176) · M(366) · L(556)** 셋 중에서만 고른다
- [ ] 카드 골격을 `.mk-hd` / `.mk-bd` / `.mk-ft` 셋으로 통일한다
- [ ] 재지 못한 그림 자리는 `.mk-slot`, 못 받은 칸은 `.mk-empty` 로 채운다
      — 빈 자리를 그대로 두면 다시 들쑥날쑥해진다
- [ ] 묶음 머리 넷을 넣는다 — **입지·경쟁 / 사는 사람 / 오가는 사람 / 상권**
- [ ] 줄 짜임을 `anseo-market-markup.html` 대로 맞춘다
      `12 / 12 / 7+5 / 12 / 6+6 / 8+4 / 6+6 / 8+4 / 12`
- [ ] 두 인구 카드(시군구 · 반경 1km)는 **같은 차례 · 같은 축**으로 둔다

**받는 조건**
- 줄마다 카드가 **같은 높이**로 끝난다
- 화면 어디에도 **빈 자리가 없다**
- 1180 / 760 에서 12 → 6 → 1 로만 접힌다

## 라 · 덤 (따로 판단하실 것)

- [ ] **집계 중인 달을 갈라 표시** — 방문자 12개월의 마지막 달이 17,084명으로
      앞선 열한 달 평균(63,742명)의 **27%** 인데 완성된 달과 같은 막대다.
      한 달 만에 73% 빠진 것처럼 읽힌다. 빗금 + 「집계 중」으로 갈라 둔다.
      **데이터에 「확정/집계 중」을 가르는 값이 있어야 한다** — 없으면 이 건만 뒤로.
- [ ] **3km 이상 군집 표기** — 가 에서 띠로 막아 두었지만 근본은 군집이다.

## 확인하는 법

```
1  1440 폭에서 연다 — 줄마다 카드 끝이 맞는가, 빈 자리가 있는가
2  경쟁 목록에서 가장 긴 병원명을 찾는다 — 한 줄인가
3  반경 칩을 500m → 10km 로 눌러본다 — 지도·범례·표·KPI 가 함께 움직이는가
4  3km 에서 「군집 표기 필요」 띠가 뜨는가
5  흑백으로 두고 지도를 본다 — 같은 과가 여전히 갈리는가
6  1180 · 760 으로 줄여본다 — 12 → 6 → 1 로만 접히는가
```

# AEO 언급현황 — 추가 (2026-09-16)

> 시안 `docs/시안/2026-09-16-ANSEO-AEO-언급현황-시안.html`
> 파일 `anseo-wordcloud.js` + `anseo-market-layout.css` 끝에 붙인 블록

## 가 · 언급현황을 워드클라우드로 — 반나절

- [ ] `anseo-wordcloud.js` 를 넣고 `drawCloud(box, words)` 를 부른다
      words: `[{t:"말", n:언급수, k:"us"|"rival"|"term"}]`
- [ ] 담는 칸에 `.mk-cloud` + 부모 본문에 `.mk-bd--flush` (**높이를 안 주면 0 이 되어 한 글자도 안 앉는다**)
- [ ] 범례는 `legendHTML(words)` — 누르면 그 갈래만 남게 `dim`/`on` 을 토글
- [ ] 「표 보기」로 `tableHTML(words)` 와 맞바꾼다 — **정확한 수는 표에서 본다**
- [ ] 창 크기가 바뀌면 `drawCloud` 를 다시 부른다(디바운스 120ms)

**받는 조건**
- 낱말이 **겹치지 않는다**(반환값 = 앉힌 개수; `words.length` 보다 적으면 칸이 좁은 것)
- 흑백으로 두어도 우리 브랜드가 **굵기와 크기**로 갈린다
- 마우스를 올리면 정확한 언급 수가 뜬다

## 나 · 설명을 한 줄로 — 한 시간

- [ ] 네 문단을 지우고 `.mk-oneline` 한 줄로 — **기간 · 우리 · 경쟁사 · 비율** 넷만
- [ ] 고지·산식·제외 규칙은 `?` 팝오버 안으로 **옮긴다**(지우지 않는다)
- [ ] 「보장하지 않습니다」를 맨 앞에 두지 않는다
- [ ] 못 받은 값은 `«—»` — **0 으로 채우지 않는다**

## 다 · 아래 줄 빈칸 없애기 — 한 시간

- [ ] 그래프 + 「그 외 25곳」 줄을 **8칸 + 4칸**으로 (합 12)
- [ ] `6 + 3 + 3` 같은 조합을 쓰지 않는다 — 남는 칸이 빈칸이 된다
- [ ] 한 칸에 카드를 둘 쌓을 때는 **합이 줄 높이와 같게**
      예: `M(366) + gap(14) + S(176) = L(556)`
- [ ] 줄 수가 적어 아래가 뜨는 목록은 `.mk-bd--fillrow` + `.mk-bars--fill`
      → 카드 높이에 맞춰 고르게 펴진다

**받는 조건**
- 화면 어디에도 **빈 자리가 없다**
- 한 줄 안 카드가 **같은 높이로 끝난다**

## 이 시안에서 실측한 것

```
낱말 30개 전부 앉음 · 겹침 0쌍 · 칸 밖으로 나간 것 0
왼쪽 카드 556 = 오른쪽 칸 (366 + 14 + 176) 556
가로 밀림 1560 · 1100 · 700 · 400 에서 전부 0
색   우리 #00ed64 ↔ 경쟁사 #c98500 · 적록 ΔE 15.0 · 정상 28.8
```

**함정 하나 더** — 캔버스 `measureText` 로 재면 CSS 와 굵기·글꼴이 어긋나 낱말이 겹친다.
**화면에 먼저 숨겨 그린 뒤 `offsetWidth` 로 잰다.** 이 구현이 그렇게 돼 있다.
