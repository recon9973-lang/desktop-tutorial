# patches — 다른 저장소에 낼 고침을 담아 두는 자리

작업 방(컨테이너)은 세션마다 초기화된다. 이 방에서 밀 권한이 없는 저장소의 고침은,
밀기 전에 여기에 패치로 남겨 둔다. 방이 사라져도 일이 안 사라진다.

되살리는 법:

```bash
git -C <대상 클론> checkout -b <가지 이름> origin/main
git -C <대상 클론> am docs/patches/<파일>.patch
```
