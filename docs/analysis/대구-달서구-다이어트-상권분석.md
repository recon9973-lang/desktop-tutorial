## 2. 병원 밀집도 (다이어트 관련 공급)

### 2-0. 밀집도 실측 ✅ (심평원 요양기관 전수 명부, 2026-03 · 사용자 제공 원자료)
**달서구 요양기관 872개** (대구 전체 4,225개 중 **20.6%**). 종별 분해:

| 종별 | 개수 | 비중 |
|---|---|---|
| **의원(양방)** | **429** | 49.2% |
| 치과의원 | 216 | 24.8% |
| **한의원** | **173** | 19.8% |
| 병원 | 21 | 2.4% |

| 한방병원 | 7 | 0.8% |

- **인구 1만 명당 16.9개** (872 ÷ 51.5만). **인구 비중 21.9% vs 기관 비중 20.6%** → 인구 대비 의료공급이 대구 평균보다 **소폭 과소** = 신규 진입 여지.
- **의원(429) : 한의원(173) = 2.5 : 1** — 양방 의원이 수적으로 압도적. **그런데도 '다이어트' 검색 상위는 한의원이 점유**(§2-2) → **양방 의원의 다이어트 마케팅 공백**이 핵심 기회(공급이 아니라 *마케팅*의 빈틈).
- **읍면동 밀집도**(기관 수): 상인동 129 > 감삼 83 > 월성 81 > 이곡 79 > 송현 74 > 진천 72 > 두류 71 > 용산 49. **월배권 상인동이 의료 최대 밀집**, 달구벌대로변 감삼·두류가 뒤를 잇는 이중 축.

### 2-1. 경쟁 상위 샘플 ✅ (리뷰순, 2026-07-23)
| 검색어 | 상위 노출(리뷰순) | 위치 |

### 2-2. 핵심 = "공급의 빈틈"이 아니라 "마케팅의 빈틈" ✅+🟡
- **공급은 양방 의원이 우세**(429개, 한의원의 2.5배). **그럼에도 `다이어트`·`다이어트한의원` 검색 상위 노출은 한의원이 점유**(리뷰순 상위 5 중 4가 한방, §2-1). 즉 **한방이 다이어트를 적극 마케팅**하는 반면, **다수의 양방 의원은 다이어트/비만을 전면에 내세우지 않아 검색 점유를 내주고 있음.**
- → **기회는 개원(공급)보다 "양방 의원의 다이어트 마케팅"**: 이미 존재하는 429개 양방 의원이 위고비·삭센다·대사 포지션으로 검색·콘텐츠를 잡으면 한방 우위를 뒤집을 수 있음. (= VENOM의 서비스 지점)
- 대구 미용·비만 브랜드 상권은 전통적으로 중구(동성로)·수성구(범어)에 쏠려 있어 🟡, 달서구 양방의 다이어트 브랜딩은 **선점 이익**이 큼.

### 2-3. 생활권 전략 (기관 밀집 실측) ✅
- 기관 수 밀집 1위 **상인동(129)** = 월배권 핵심 의료상권, 이어 **감삼(83)·월성(81)·이곡(79)·두류(71)**. **월배권(상인·월성·진천)** 과 **달구벌대로권(감삼·두류)** 의 이중 축.
- 개원/집중 타깃 선정 시 **고밀 상권(상인·감삼)** 은 경쟁 강도↑·유동↑, **성서 배후(이곡·용산)** 는 대단지 배후 대비 상대적 여지 검토.

### 2-4. 실측 의료 수요 — 심평원 진료통계 ✅ (2022, 달서구 주민 주상병 기준)

- 비만(E66) 진료는 30~34세(24명)에서 정점, 20~59세에 고루 분포(미용 목적 연령대와 일치).
- ⚠️ 주상병 기준 진료인원(코드 간 중복 가능), 소수 셀은 마스킹(*) 처리되어 174명은 하한. 2022년 데이터.

### 즉시 실행
1. **양방 의학 비만치료(위고비·삭센다·식욕억제·대사)** 를 핵심 메시지로 → 한방 편중 시장의 빈틈 + 키워드 트렌드 정중앙 + **비만 의료화 갭(진료 174명 vs 검색 폭증) 선점.**
2. **40대(±30·50대) 타깃**, 건강·리바운드 방지 소구. 20대는 보조.
3. **대사질환 배후(고혈압·당뇨·고지혈 13만+) 연계 채널** — 건강검진·내과 연동으로 남성 40~50대 유입.
4. **12~1월 광고 선행**, 봄 피크 수확. **대구/랜드마크 롱테일 SEO·GEO 선점**(달서구 정확어는 콘텐츠 커버만).
5. 실측 데이터 완비 → **1페이지 제안서**(venomad-proposal)로 합본해 수주 자료화.
