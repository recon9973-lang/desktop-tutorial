# 달서구 다이어트·비만 클리닉 마케팅 제안서 (1페이지)

> 대상: 대구 달서구 다이어트·비만 진료 **양방 의원** · 제안: VENOM(베놈) 병원마케팅 · 2026.07
> 근거: 행안부·심평원·Naver DataLab **실측 데이터**(상세는 `대구-달서구-다이어트-상권분석`)

## 1. 현황 진단 — 기회는 있는데 아무도 안 잡고 있다
1. **수요는 대구 최대.** 달서구 인구 515,142명(대구 1위), 다이어트 주 소구층 **여성 263,101명**이 대구 자치구 중 가장 많음.
2. **양방 의원은 많은데 검색을 못 잡음.** 달서구 의료기관 872개 중 **의원 429 > 한의원 173(2.5배)** 인데도, '달서구 다이어트' 검색 상위 노출은 **한의원이 점유.** → 양방 의원의 **다이어트 마케팅 공백.**
3. **검색은 폭발, 병원 전환은 정체.** 위고비·삭센다 검색은 2024년 이후 폭증했으나, 달서구에서 비만(E66)으로 실제 진료받은 인원은 **연 174명**뿐. 반면 대사질환(고혈압·당뇨·고지혈) 진료는 **13만+명.** → **"검색 → 내원" 전환의 빈 공간이 곧 매출 기회.**

## 2. 전략 방향 — "달서구 양방 의학 비만치료" 검색 선점
- **한 줄 포지션**: *달서구에서 위고비·삭센다·대사 기반 의학 비만치료를 검색하면 우리 병원이 먼저 보이게 한다.*
- **타깃**: (1차) 여성 30~50대(40대 코어) · (2차) 남성 40~50대(대사증후군 연계 체중관리).
- **왜 이 전략인가**: 수요·공급·검색 데이터가 모두 "양방 다이어트 마케팅 공백"을 가리킴. 지금 선점하면 경쟁이 얇아 이익이 큼.
