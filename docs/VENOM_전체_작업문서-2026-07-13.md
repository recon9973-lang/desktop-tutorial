## 3. 기능별 상세

### 3.1 SEO / GEO / AEO 진단
- **SEO 진단 엔진**(무료 룰 엔진): `seo/seo-engine.js` + `seo/seo-rules.json`, 근거는 `google_seo_guide/`(구글 203문서). 온페이지 라이트 스코어러 폴백 포함(의존성 0, gzip 해제 대응).
- **GSC 실측 연동**: `lib/search-console.js`, 설정법 `docs/GSC_SETUP.md`, 상태 `/api/health`의 `hasGSC`.
- **AI 노출 매트릭스(AEO)**: `api/insights.js` + `lib/ai-engines.js` — Perplexity·ChatGPT·Gemini·Claude에 환자 질문을 실제로 던져 노출(언급/인용) 실측. → §5 참고.
- 스킬 `seo-audit`(컨설턴트급 리포트), `seo-medical-expert`(의료광고법).

### 3.2 콘텐츠 자동화
- 자동 블로그: `api/generate-post.js`→`publish-post.js`, 크론 `cron-daily-posts.js`. 품질은 `eval-judge.js`(LLM-as-Judge).
- 블로그 이미지 규칙(고정): GitHub DB 실사진을 베이스로 **AI image-to-image 재가공**(인물 한국인 정체성 유지, 무드만 변형, 중복 금지, 텍스트/로고 없음, 의료광고법 준수), 결과는 `preview/images/blog-ai/<postId>.webp`에 자체 저장. 파이프라인: Higgsfield(`nano_banana_2`) → 매니페스트 → `fetch-blog-ai.yml`.

### 3.3 클리닉 / 병원봇 진단 (`clinic/`, `hospital-bot/`)
- **원장님_앱**(`/clinic`): 병원 검색정보 진단 — 반경별 경쟁·노출·플레이스·GEO 실프로빙(인용률·SoV·감성·등급), 웹 풀리포트, 제안서/견적 자동 초안, 24h 캐시.
- **hospital-bot**(`api/hospital-bot.js` + `hospital-bot/`): 카카오 오픈빌더 연동, 전업종 진단(의료광고법은 의료 업종만), '내키' 화이트리스트 온보딩, 미측정 지표 투명 표기.

### 3.4 관리자 대시보드 (`admin.html`)

## 5. AI 노출 실측 파이프라인 (핵심)

```
ai-expose-input.json → [GitHub Actions] AI Exposure Check
  러너 → /api/insights?type=aeo (40콜, 동시성5) → cited/mentioned/none/error
    ├─ 로그 RESULTS_JSON
    └─ content/ai-expose-latest.json 커밋(HEAD:main) → Vercel 배포 → 관리자 렌더
```
- 판정: **cited**(citation에 core) / **mentioned**(본문 core 또는 `d.mentioned`) / **none** / **error**(분모 제외)
- 발견형(q0~q3, 비브랜드) vs 브랜드형(q4)
- 최근 실측(run 29172884932, 측정불가 0건): 시원통증 **25% / 발견형 6%**, 시원스킨 **15% / 발견형 0%**.

## 6. 배포·브랜치·보안 규칙
- **배포**: `main` 자동배포(Vercel). 작업은 `claude/*` → 검증(JS 구문 + Playwright) → commit → PR → squash-merge → 브랜치 origin/main 리셋.
- **커밋 트레일러(필수)**: `Co-Authored-By: Claude Opus 4.8 …` + `Claude-Session: …`. 모델 ID·비밀키·허위 통계는 커밋/PR/코드에 넣지 않는다.
- **비밀키**: 코드/문서에 없음 → Vercel 각 프로젝트 Env / GitHub Actions secrets / 로컬 `.env.local`. (레지스트리: `docs/API-KEYS-REGISTRY.md`)
- **샌드박스 egress**: `vercel.app` 차단 → 배포 API 호출·이미지 자체저장은 GitHub Actions로 우회.
