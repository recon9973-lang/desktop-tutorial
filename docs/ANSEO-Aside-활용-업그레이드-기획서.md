## 0. 한 장 요약

**Aside 는 「로그인된 웹사이트를 사람 대신 열고·읽고·누르는 AI 브라우저」다.**

## 1. Aside 가 무엇인가 — 쉬운 말로

| 물음 | 답 | 근거 |
|---|---|---|
| 뭐 하는 물건인가 | 크롬과 같은 엔진으로 만든 **별도 브라우저 프로그램**이다. 사람이 「이거 해 줘」 하면 AI 가 그 브라우저 안에서 사이트를 열고, 읽고, 누르고, 입력해 **일을 끝까지** 한다. 몇 분·몇 시간짜리 일도 이어서 한다 | YC 소개 · eesel 설명 |
| 남들과 뭐가 다른가 | 다른 AI 도구는 사이트마다 「연동」을 만들어야 한다. Aside 는 연동 없이 **사람이 이미 로그인해 둔 사이트를 그대로** 쓴다 | YC 소개 · MOGE 요약 |
| 기억하나 | 한다. 일이 끝날 때마다 사람·회사·결정을 뽑아 **내 컴퓨터 안에 마크다운(글) 파일**로 저장한다. 「막혔을 때 통했던 길」도 기억한다. 파일을 열어 사람이 고칠 수 있다 | Aside 메모리 소개 · eesel 리뷰 |
| 내 자료는 어디로 가나 | 「로컬 우선」이다 — 작업 기록·메모리는 내 컴퓨터에 있고, AI 회사에는 **그 일에 필요한 화면 내용만** 간다 | eesel 설명(개인정보 방침 인용) |
| 누가 만들었나 | 미국 Y Combinator 2025 가을 기수 **Aside Computer**. 2024년 창업, 샌프란시스코, **한국인 세 사람**(대표 Jun Kim · 공동창업 Chanhee Lee · Sanghun Lee) | YC 소개 · 한국 후기 |
| 값 | **미공개**(2026-06 기준). 프로그램은 무료로 받고, AI 는 **내가 이미 내는 ChatGPT·Claude 구독 또는 내 API 열쇠**를 꽂아 쓴다. 회사 서버에서 돌리는 작업은 별도 크레딧 | eesel 가격 글 |
| 어디서 도나 | **사람 컴퓨터**(맥 · 윈도우 판도 나왔다는 한국 기사 제목 확인). 서버에 얹는 물건이 아니다 | AI코리아커뮤니티 기사 제목 |
| 멀리서 시킬 수 있나 | 유료(Pro) 판은 **슬랙·텔레그램**에서 말로 시킬 수 있다 | Huntify·MOGE 요약 |
| 얼마나 잘하나 | 회사가 공개한 시험표에서 웹 과제 300개 중 297개 성공(99.0%) — **단 자기가 자기를 채점한 값**이고 그때 쓴 AI 는 GPT-5.5 였다 | at-inc/aside-benchmarks(GitHub) |
| 한국 사용자 평 | 「로그인이 다 유지된다」가 강점. **아직 새 물건이라 버그·버벅임** 있음. 「고객을 직접 상대하는 일·계정을 통째로 넘기는 일엔 아직」 | 브런치·디지털마케터·Daily-It 후기 요약 |

**한 줄로:** *"사이트에 사람 대신 들어가 눈으로 보고 손으로 누르는 인턴"* 이다. 코드가 아니라 **눈과 손**이다.

### Aside 가 아닌 것 (오해 방지)
- ANSEO 서버 안에 넣는 부품이 아니다. **사장님(또는 실무자) 컴퓨터 위에서 도는 프로그램**이다.
- 정기 진단처럼 서버에서 혼자 도는 「크론」이 아니다. 정해진 시각에 돌리려면 그 컴퓨터가 켜져 있어야 한다(회사 서버 크레딧으로 돌리는 길은 값 «—»).
- 채점기가 아니다. **Aside 가 본 것을 ANSEO 에 넣어 주는 것**까지가 역할이고, 판정은 ANSEO 규칙이 한다.

## 3. 활용안 — 넷으로 묶어 열여섯 가지

각 안마다 **① 무엇을 ② 어떻게(Aside 에게 하는 말) ③ ANSEO 에 어떻게 들어가나 ④ 조심할 것 ⑤ 순위** 를 적었다.
「Aside 에게 하는 말」은 실제로 그대로 붙여 넣어 시험할 수 있게 썼다.

### 묶음 A · 진단에 실측값 채우기 (연동 없이 재던 자리)

#### A1. 네이버 서치어드바이저 읽기 — 「진단 못 함」을 실측으로 (순위 ★★★)
- **무엇**: 거래처 사이트가 서치어드바이저에 등록돼 있나, 소유 확인이 됐나, 사이트맵·RSS 가 제출됐나, 최근 색인 요청·오류가 있나.
- **Aside 에게**: *"네이버 서치어드바이저(searchadvisor.naver.com)에 로그인돼 있어. 「웹마스터 도구 → 사이트 목록」에서 `example-clinic.co.kr` 을 찾아 ① 소유 확인 여부 ② 사이트맵 제출 여부와 제출 주소 ③ 「검증 → robots.txt」 결과 ④ 최근 7일 「리포트 → 콘텐츠 노출/클릭」 숫자를 표로 적고, 각 화면을 캡처해 줘. 없으면 「없음」이라고만 적어."*
- **ANSEO 에**: 96항목의 `naver_swa_registered`·`sitemap 제출`·`impressions_available` 자리. **지금은 태그만 보고 「진단 못 함」** 인 것을 「됨/안됨 + 캡처 근거」로.
- **조심**: 우리 대행 계정에 거래처가 **권한을 준** 사이트만. 거래처 아이디로 로그인하지 않는다.

#### A2. 지도 4종 등록 상태 — 시안 M5 의 「모름」 칸 없애기 (순위 ★★★)
- **무엇**: 네이버 플레이스·구글 비즈니스 프로필·카카오맵·빙 플레이스에 거래처가 있나, **상호·주소·전화(NAP)** 가 홈페이지와 같나, 플레이스 주소(URL)는 무엇인가.
- **Aside 에게**: *"「그랜드아름다운의원 춘천」을 네이버 지도·카카오맵·구글 지도·빙 지도에서 각각 검색해. 있으면 그 업체 페이지 주소, 화면에 적힌 상호·주소·전화번호를 그대로 적고, 홈페이지 `…` 에 적힌 것과 다른 글자가 있으면 표시해 줘. 없으면 「미등록」. 네 곳 모두 캡처."*
- **ANSEO 에**: 거래처 상세 「지도 4종」 구역(M5) 의 3상태 칩 + 플레이스 URL 저장 → `citation_channels` 인용 대조에 연결. 96항목 `nap_consistent`(수집 부적합 3건 중 하나)의 **실측 근거**.
- **조심**: 등록·수정은 하지 않는다(1단계). 「등록」 버튼은 사람이.

#### A3. 병원 포털 등재 확인 + 미분류 규칙판 근거 (순위 ★★★)
- **무엇**: AEO 조사에서 인용 209건 중 **미분류 178건(85.2%)** 이었고, 강남언니·바비톡·여신티켓이 규칙표에 없었다. ① 콘솔에서 미분류 도메인 목록을 복사 ② 그 포털들에 우리 거래처가 등재돼 있나 확인.
- **Aside 에게**: *"veo.seokorea.org 콘솔에 로그인돼 있어. 대시보드 → 「AI 가 어디를 보나」 → 접힌 줄 「미분류 안에 무엇이 있나 — 도메인 N곳」을 펼쳐 도메인 전부를 적어 줘(12곳까지만 보이면 그 수도 적어). 그다음 강남언니·바비톡·여신티켓에서 「그랜드아름다운의원」을 검색해 등재 여부·페이지 주소·후기 개수를 적어."*
- **ANSEO 에**: 대장 §4-B 의 **규칙판 4(미용의료 채널)** 입력 근거. 거래처 AEO 탭 「채널 등록 현황」에 등재 여부.
- **조심**: 포털 후기·별점 숫자는 **그 시각의 화면값**이라 날짜를 같이 적는다. 의료광고법상 후기 내용을 우리 리포트에 옮기지 않는다(숫자·유무만).

#### A4. 네이버 AI 브리핑 「눈으로」 관측 — 보조 근거 (순위 ★★)
- **무엇**: 7엔진 중 **네이버 AI 브리핑은 「검색 끔」 조건이 없는 화면 요약**이고 지금 SerpAPI 로 받는다. 실제 로그인 네이버에서 질문을 쳤을 때 브리핑이 뜨나·우리 거래처가 언급되나를 **캡처로** 남긴다.
- **Aside 에게**: *"네이버에서 「춘천 피부과 추천」을 검색해. 결과 맨 위에 AI 브리핑이 뜨면 그 글 전체와 아래 출처 링크를 적고, 안 뜨면 「없음」. 화면 캡처 한 장."*
- **ANSEO 에**: 관측 자료에 **「사람 눈 관측(보조)」** 표시로 넣는다 — 기계 관측과 섞지 않고 곁에 둔다(§5 ①).
- **조심**: **ChatGPT·제미나이·퍼플렉시티 화면을 이렇게 긁지 않는다**(§4 ②). 네이버는 「검색 결과 화면」이라 성격이 다르지만, 그래도 하루 몇 번 수준·거래처 질문만.

#### A5. 경쟁사 후보 → 실제 상호·플레이스 표 (순위 ★★)
- **무엇**: 상권 탭이 심평원 좌표로 「같은 과 반경 내 기관」을 내지만, 네이버 지도에 실제로 어떤 이름으로 나오는지·플레이스 주소·후기 수는 사람이 찾았다(춘천 경쟁사 6곳 등록이 사장님 몫으로 남아 있다).
- **Aside 에게**: *"네이버 지도에서 「춘천 피부과」로 검색해 상위 10곳의 상호·주소·전화·플레이스 주소·방문자 리뷰 수를 표로. 심평원 목록 `…` 과 상호가 같은 줄에는 표시."*
- **ANSEO 에**: `/competitors` 등록 폼에 붙여 넣을 표. 경쟁 로스터 PoC(개편 제안서 실행 7)의 **재료**.

#### A6. 거래처 홈페이지 「사람 눈」 점검 (순위 ★★)
- **무엇**: 렌더러를 켤지 결정하려면 「자바스크립트로 본문을 그리는 거래처가 몇 곳인가」를 알아야 하는데 작업 방에서 못 돌린다. Aside 가 실제 브라우저로 열어 **본문이 보이나·모바일에서 어떻게 보이나·혼합 콘텐츠 경고가 뜨나**를 캡처.
- **Aside 에게**: *"이 8개 주소를 하나씩 열어 ① 첫 화면에 본문 글이 있나(메뉴·푸터 말고) ② 자물쇠 경고가 있나 ③ 휴대폰 폭으로 줄였을 때 본문이 보이나를 적고 각 캡처."*
- **ANSEO 에**: 「렌더러 켜기」 결정의 **사전 대조표**. 켜기 전 점수가 내려갈 거래처를 미리 안다.

#### A7. 심평원·공공 자료 「파일 수동 갱신」 대행 (순위 ★)
- **무엇**: 상권 기획안의 데이터 원천 중 「파일 수동」 갱신(내려받기 → 형식 확인 → 올리기)을 Aside 가 한다.
- **조심**: 올리기는 「최고 관리자 전용」 화면이라 2단계 이후.

### 묶음 B · 운영 손 줄이기 (사장님 몫이던 것)

#### B1. 운영 콘솔 눈 확인 대행 — 작업 방의 「못 쟀습니다」를 메운다 (순위 ★★★)
- **무엇**: 방마다 「배포는 나갔는데 화면에서 도는지는 «—»」 가 반복된다. 휴지통이 보이나, 「그냥 두면 N일 뒤 자동삭제」 문구가 있나, 판 번호가 몇인가, 진단 결과 7구획이 다 그려지나.
- **Aside 에게**: *"veo.seokorea.org 콘솔에서 ① 「거래처」 목록에 줄마다 「삭제」와 제목 옆 「테스트 자리」·「휴지통」이 보이나 ② 휴지통에 「그냥 두면 N일 뒤 자동삭제」 문구가 있나 ③ 화면 하단 판 번호를 적고 셋 다 캡처해 줘."*
- **ANSEO 에**: 인계본(`RESUME-*.md`)의 «—» 자리를 실측으로 채운다. 결과 마크다운을 `docs/aside-runs/YYYY-MM-DD-<무엇>.md` 로 저장소에 커밋(§5 ③).

#### B2. 배포·설정 화면 읽기 (순위 ★★★)
- **무엇**: Railway `veo-worker` 변수(`VEO_RENDERER_ENABLED` 현재값) · GitHub `Settings → Rulesets` 의 「이 비공개 저장소에서는 적용되지 않는다」 문구 · **Neon 월 전송량**(5GB 초과 사고 재발 감시) · Vercel 배포 상태.
- **Aside 에게**: *"Neon 콘솔 프로젝트 `…` 의 「Usage」에서 이번 달 Data transfer 값과 한도를 적어. Railway `veo-worker` → Variables 에서 `VEO_RENDERER_ENABLED` 값을 적어. 값은 바꾸지 마."*
- **조심**: **읽기만.** 스위치를 켜는 건 「일부 거래처 점수가 내려가는 결정」이라 사장님이.

#### B3. 조치 이행 확인 → 「진단 요청」 (순위 ★★)
- **무엇**: 이슈에 적힌 조치(예: 메타 설명 추가)를 거래처가 했는지 실제 페이지에서 확인하고, 됐으면 콘솔에서 「진단 요청」을 눌러 이슈가 닫히게 한다(페이지 진단은 30분에 안 걸린다 — 0.3.550).
- **Aside 에게**: *"이슈 목록에서 상태가 「조치 요청」인 것을 하나씩 열어, 적힌 페이지를 새 탭으로 열어 조치가 됐는지 보고, 됐으면 「진단 요청」을 눌러. 안 됐으면 이유를 한 줄 적어."*
- **조심**: 버튼을 누르는 첫 「쓰기」 작업이다. 2단계에서.

#### B4. 리포트 전달 (순위 ★★)
- **무엇**: 공유 리포트(`/results/<토큰>`)를 열어 PDF 로 저장하고, 거래처 담당자에게 보낼 메일 초안을 Gmail 에 만든다(보내기는 사람이).
- **조심**: 발송은 사람. 의료광고법 검수(원고 검수 화면)를 거친 문안만.

#### B5. 사용량·비용 화면 주간 읽기 (순위 ★)
- **무엇**: 콘솔 「사용량·비용」 + OpenAI·SerpAPI 대시보드를 금요일에 읽어 한 표로.
- **ANSEO 에**: 「GEO 관측이 돈이다」(월 $94 계산)의 **실제 청구액**을 «—» 아닌 숫자로.

### 묶음 C · 영업·온보딩

#### C1. 상담 전 사전 조사 한 장 (순위 ★★)
- **무엇**: 신규 병원 상호·주소만 주면 지도 4종·서치어드바이저 흔적·포털 등재·홈페이지 첫인상을 한 장으로. `location-auto` 스킬(구 단위 상권분석)과 붙이면 **제안서 재료**가 된다.
- **Aside 에게**: A2 + A3 + A6 을 한 번에 시키는 문장.

#### C2. 거래처 온보딩 자동 채움 (순위 ★)
- **무엇**: 「업체 등록」 4필드 + 지도 4종 URL + 경쟁사 후보를 Aside 가 모아 오면 실무자는 확인만.
- **조심**: 등록은 사람 검토 뒤 저장(2단계).

### 묶음 D · 일하는 방식

#### D1. 텔레그램·슬랙에서 오더 (Pro) (순위 ★★)
- **무엇**: 사장님이 밖에서 텔레그램에 「그랜드 지도 4종 봐 줘」 → 사무실 컴퓨터의 Aside 가 A2 를 돌리고 결과·캡처를 답한다.
- **조심**: 유료 판. 컴퓨터가 켜져 있어야 한다.

#### D2. Aside 메모리 ↔ 저장소 인계본 잇기 (순위 ★★★ · 값 0)
- **무엇**: Aside 메모리는 **마크다운 파일**이다. 이 저장소 인계본도 마크다운이다. 「콘솔 어디에 무엇이 있나」·「어느 버튼이 진단 요청인가」를 Aside 메모리에 적어 두면 **다음 오더부터 설명이 필요 없다.** 거꾸로 Aside 가 적은 「통했던 길」을 `docs/aside-memory/` 로 커밋하면 작업 방들도 읽는다.
- **조심**: 메모리에 **비밀번호·열쇠는 절대 안 적는다.** 커밋 전 훑는다(gitleaks 가 돈다).

#### D3. 작업 방(Claude Code) 과 Aside 의 역할 분담 (순위 ★★★ · 값 0)
- **원칙**: **방은 코드·판정, Aside 는 눈·손.** 방이 「화면에서 한 번 봐 주십시오」라고 적던 자리를 「Aside 에게 이 문장을 주십시오」로 바꾼다.
- **인계 규칙 한 줄 추가 제안**: *「사람 손을 빌리는 인계 항목은 Aside 문장으로 적는다」* — 이미 `RESUME-auto-diagnosis.md` 에 「도구가 대신할 수 있는지부터 묻는다」가 있다.

#### D4. 주간 「눈 점검」 묶음 (순위 ★)
- B1 + B2 + B5 + A2(변경 감시)를 매주 금요일 한 문장으로. Pro 없이도 사람이 금요일에 한 번 시키면 된다.

## 4. 하지 말 것 · 조심할 것

| # | 무엇 | 왜 | 대신 |
|---|---|---|---|
| ① | **거래처 계정으로 로그인시키지 않는다** | Aside 는 로그인된 계정을 그대로 쓴다. 한국 후기도 「계정을 통째로 넘기는 일엔 아직」 | 대행 계정에 **권한 위임**(서치어드바이저·구글 비즈니스 모두 위임 기능이 있다) |
| ② | **ChatGPT·제미나이·퍼플렉시티·클로드 화면을 눌러 관측을 뽑지 않는다** | 이용약관상 자동 조작 금지 위험 + 우리는 이미 **공식 창구**로 관측한다(443건 $4.29 실측). 값싸 보여도 계정 정지 위험 | 공식 창구 유지. 네이버 AI 브리핑만 「검색 화면」이라 보조 캡처(A4) |
| ③ | **Aside 가 읽은 값을 그대로 점수에 넣지 않는다** | 새 물건이라 잘못 읽을 수 있다. 「실측 > 추정 > 날조 금지」 원칙 | **「브라우저 대행 관측」** 이라는 출처 등급을 따로 두고 **캡처를 근거로** 붙인다(§5 ①) |
| ④ | 1단계에서는 **쓰기(등록·수정·버튼)를 시키지 않는다** | 지도 정보 수정·설정 스위치는 되돌리기 어렵다 | 읽기·캡처·표 만들기까지. 쓰기는 2단계부터 항목별로 |
| ⑤ | **비밀번호·API 열쇠를 Aside 메모리·오더 문장에 적지 않는다** | 메모리는 파일이고, 우리는 그 파일을 커밋할 계획이다 | 로그인은 사람이 브라우저에서 한 번. 열쇠는 Vercel·Railway 화면에서만 |
| ⑥ | **환자 개인정보가 보이는 화면은 열지 않는다** | 예약·상담 화면엔 환자 이름·번호가 있다. AI 회사로 화면 내용이 간다 | 마케팅·검색·지도 화면만. 심평원 자료는 기관 단위만 |
| ⑦ | **후기 문장·전후사진을 리포트로 옮기지 않는다** | 의료광고법 | 등재 여부·개수·날짜만 |
| ⑧ | 「99% 성공」을 믿고 검토를 빼지 않는다 | **자기 채점** 값이고 우리 사이트(네이버·콘솔)로 잰 게 아니다 | 1단계 2주 동안 **우리 자리에서 맞은 비율**을 직접 센다(§6 판정 기준) |
| ⑨ | 컴퓨터가 꺼지면 안 돈다는 걸 잊지 않는다 | 서버가 아니다 | 정기 진단·관측은 지금처럼 서버 크론. Aside 는 「사람이 시키는 일」 |

## 5. ANSEO 쪽에서 미리 만들어 둘 것 (코드 · 작다)

Aside 를 쓰기 시작하면 「사람이 본 값」이 처음으로 ANSEO 에 들어온다. 그것을 기계 관측과 **섞이지 않게** 받을 자리가 필요하다.

| # | 무엇 | 어디 | 크기 |
|---|---|---|---|
| ① | **출처 등급 「브라우저 대행 관측」** — 관측·항목 값에 출처(`source`)와 **근거 캡처 파일** 을 붙일 수 있게. 화면엔 작은 표시(「사람 눈」)와 날짜 | 관측 저장 모델 + 96항목 결과 표시 | 소 |
| ② | **지도 4종 상태 필드**(됨/안됨/모름 + URL + 확인일) | 거래처 상세 — 시안 M5 그대로 | 중(이미 기획됨) |
| ③ | **`docs/aside-runs/` 규격** — Aside 결과 마크다운을 커밋하는 자리와 파일 머리 형식(대상·날짜·오더 문장·캡처 목록) | 이 저장소 | 소(문서) |
| ④ | **미분류 규칙판 입력구** — 도메인 목록을 붙여 넣으면 규칙판 후보를 내는 자리(대장 §4-B) | 콘솔 관리 화면 | 소 |
| ⑤ | **인계본 문법** — 「사장님 몫」 항목 옆에 「Aside 에게 하는 말」 칸 | `RESUME-*.md` 규칙(CLAUDE.md 한 줄) | 소(문서) |

①이 먼저다. 이것이 없으면 Aside 결과가 갈 곳이 캡처 폴더뿐이고, 그러면 §4 ③이 깨진다.
