## 1. 사전 준비 (팀이 1회 설정 · 필수)

### 1-1. ADMIN_SECRET — 쓰기 잠금 (보안 필수)
콘솔/API의 **쓰기(생성·수정·삭제)**는 `ADMIN_SECRET`으로 잠긴다. **미설정이면 공개 URL에서 누구나 쓰기가 가능**하므로 실데이터 투입 전 반드시 설정한다.
- **Vercel**: 프로젝트 `desktop-tutorial` → Settings → Environment Variables → `ADMIN_SECRET` 추가(강한 난수) → 재배포
- **GitHub 저장소 Secret**: Settings → Secrets and variables → Actions → `ADMIN_SECRET`(동일 값) — 자동화 워크플로(리포트·GSC수집·반복업무)가 인증에 사용
- **콘솔**: 우상단 입력칸에 같은 값 입력 → "저장"(브라우저에 저장, 관리자 콘솔과 공유)

### 1-2. GSC 서비스계정 (성과 자동수집용 · 선택이나 권장)
- Google Cloud → 서비스계정 생성 → JSON 키 발급
- 각 거래처 GSC 속성에 서비스계정 이메일을 **사용자로 추가**(읽기)
- Vercel env에 `GSC_CLIENT_EMAIL` + `GSC_PRIVATE_KEY`(또는 `GSC_SERVICE_ACCOUNT_JSON`) 설정
- 미설정이어도 **성과 탭 CSV 붙여넣기**로 즉시 사용 가능

### 1-3. AI 엔진 키 (실측용, 이미 운영 중)
`PERPLEXITY_API_KEY`, `OPENAI_API_KEY`, `GEMINI/GOOGLE_AI` , `ANTHROPIC_API_KEY` — 기존 사이트에서 사용 중. 없으면 해당 엔진만 skip.

## 2. 신규 거래처 온보딩 — 7일 (콘솔 버튼 매핑)

| Day | 할 일 | 콘솔 위치 |
|---|---|---|
| 1 | 거래처 등록(명·업종·지역·홈페이지·**핵심키워드**·**경쟁사**·단계·활성) | 거래처 → **+ 새 거래처** |
| 1 | 채널 현황 등록(웹·GSC·GBP·네이버·유튜브·링크드인 등, 접근상태·위험도) | 거래처 상세 → **채널** 탭 → 채널 저장 |
| 2 | GSC/GA4 권한 확보 → `gscProperty` 입력(개요 편집) · sitemap/robots/색인 확인 | 상세 → 개요 편집 |
| 3 | FAQPage/Article Schema 대상 페이지 선정 · llms.txt 확인(위생 항목) | (사이트 작업) |
| 4 | 프롬프트셋 5~10문항 등록(발견형·브랜드형 구분) | 상세 → **AI 인용 모니터링** (※ 현재는 `content/geo/prompt-sets.json` 편집 → 커밋. 콘솔 편집 UI는 2차) |
| 5 | 콘텐츠 캘린더 4주치 등록(제목·유형·키워드·발행예정일) | 상세 → **콘텐츠 캘린더** 탭 |
| 5 | 채널 플레이북에서 업무 생성(위키/레딧은 D=안내만 자동강등) | **업무 보드** → 플레이북에서 업무 생성 |
| 6 | 첫 AI 실측 실행 → 매트릭스·발견형 노출률·SOV 확인 | GitHub → Actions → **AI Exposure Check** → Run |
| 7 | 7일 진단 리포트 생성 | 상세 → **리포트** 탭 → 주간 리포트 생성 |

> **경쟁사(competitors)를 등록해야 SOV가 산출된다.** 비우면 SOV는 "경쟁사 미등록"으로 표시.

## 3. 주간 운영 루프

| 요일 | 활동 | 방법 |
|---|---|---|
| 월 | 이번 주 반복 업무 생성 · LinkedIn/블로그 초안 승인 | 업무 보드 → **🔁 이번 주 반복 업무 생성** / 승인 큐 상단 |
| 화 | 콘텐츠 발행 · 색인 요청 · llms.txt 갱신 | 콘텐츠 캘린더 상태 갱신 |
| 수 | 영상/이미지·Schema 검증 | (사이트 작업) |
| 목 | Reddit/커뮤니티 답변 기회 확인(위키/레딧 **직접 게시**) | 업무 보드 D레벨 카드(안내) |
| 금 | 성과 수집(GSC 자동수집 or CSV) · 주간 리포트 확인 | 성과 탭 GSC 자동수집 / 리포트 탭 |

**자동으로 도는 것**(설정 후):
- AI 실측: 매월 1일 (또는 수동 dispatch)
- GSC 수집: 매일 07:00 KST (`geo-metrics-collect.yml`)
- 반복 업무: 매주 월 07:00 KST (`geo-task-recur.yml`)
- 주간 리포트: 매주 금 17:00 KST (`geo-weekly-report.yml`)
- 자동화 실행 결과: **자동화 로그** 섹션
