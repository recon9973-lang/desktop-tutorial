## 2. 서비스별 벤치마크

### 2.1 소상공인 상권정보시스템 (sg.sbiz.or.kr) — 국내 공공 표준
- **영역**: 지도 클릭 → 원형·다각형·골목상권 선택. 원형은 **최대 반경 1.5km** ✅.
- **데이터**: 경쟁 점포·유동인구·소비 특성·매출 추정, 행정동 인구·세대·업소 수 ✅. 상가(상권)정보 원자료를 공공데이터포털에 공개(반경·다각형 검색 API 포함).
- **시각화**: 지도 + 보고서형 화면(업종 밀집·유동인구 시간대·연령).
- **접근**: 무료, 소상공인시장진흥공단 운영.
- **우리에 가져올 것**: 원자료 API가 v1의 «보조 소스» 그대로. 화면 문법 중 **«업소 밀집 → 경쟁 → 매출» 순서**는 소상공인용이라 병원엔 과함 — 우리는 «경쟁·교통·인구» 3구역만.
- **주의**: 1.5km 상한은 상권 툴의 상식. 우리 10km 고리는 병원급 진료권용이라는 근거를 화면에 적어야 한다.

### 2.2 통계청 SGIS 생활권역 통계지도 — 인구 정본에 가장 가까운 공공 툴
- **영역**: 지점 선택 → **주행시간·주행거리·반경** 중 택1로 영역 생성, 행정구역 경계와 무관 ✅.
- **데이터**: 인구주택총조사·전국사업체조사의 위치 기반 자료를 **격자로 집계**(인구·가구·사업체) ✅.
- **시각화**: 영역 통계 + 격자 분포 지도. 모바일판 있음.
- **접근**: 무료, OpenAPI 별도 제공(경계·인구).
- **가져올 것**: ① 영역 3방식 ② 격자 분포 지도 ③ 영역 통계 표. v1의 «행정동 면적 가중» 대신 **격자 합산**이 더 정확 — P3 정밀도 보강의 정본 후보.
- **한계**: 센서스 기반이라 5년 주기(상주 인구 최신성은 행안부 월간이 우위). 두 소스를 «최신성(행안부) × 공간정밀(SGIS 격자)»로 병용.

### 2.3 서울시 상권분석서비스 (golmok.seoul.go.kr)
- **영역**: 점포 위치·업종 선택 후 **보행거리·보행시간·반경/다각형** 기준 ✅.
- **데이터**: 100대 생활밀착 업종·골목상권 단위 매출 패턴, 추정 유동인구, 자가진단(내 점포 매출·임대료 입력 → 유사 업체 비교).
- **가져올 것**: **도보 시간 기준 영역**(병원은 도보 내원 비중이 큼) · «자가진단» 발상 = 거래처의 실제 지표를 입력받아 반경 평균과 비교(우리는 검색량·AEO 지표로 대체 가능).
- **한계**: 서울만.

### 2.4 심평원 의료경영지원서비스 · 병원정보 API — 의료 공공 정본
- **데이터**: 의료기관 위치·진료과목·의료자원 분포·질환/진료 이용 통계 무료 ✅. 개원 희망 전문과·지역의 **주거인구·병원 밀집도**, 만성질환 수요, 날씨별 환자 증감 비교, 개원 1년차·1년 후 매출 예측(보도 기준) 🟡.
- **API**: 병원정보서비스 — 좌표·반경·진료과목·종별 필터(v1 §3.2 정본).
- **가져올 것**: «**진료과별 밀집도 + 주거인구**» 한 쌍이 의료 입지의 최소 단위라는 확인. 질환별 수요(주상병 진료인원)는 시군구 단위라 고리에 못 넣고 🟡 참고 카드로.
- **주의**: 예상 매출은 우리 범위 밖(의료광고법·점수 없음 원칙).

### 2.5 메디게이트 개원입지 서비스 (2023-12 출시) — 국내 의료 특화 민간
- **데이터**: 심평원·소진공·행안부·부동산원 공공데이터 + **나이스지니데이타 병의원 카드매출** + **SKT 지오비전 퍼즐**(의원 이용 통계) ✅.
- **화면**: 지도에서 지역 선택 → 전문과 의원 수·**최근 개폐업 현황**·평균 카드매출·월별 매출 추이·**이용자 연령·거주동** → **지역 간 비교** ✅.
- **접근**: 의사 회원 대상(가격 언급 없음).
- **가져올 것**: ① 개폐업 추이 ② 이용자 «거주동» 분포(= 진료권 실측; 우리는 통신·카드 데이터가 없어 🔴 자리만) ③ 지역 간 비교 화면.
- **차이점**: 메디게이트는 «개원 전 의사», 우리는 «개원 후 마케팅 거래처». 매출·환자 수 대신 **검색·AI 노출과 입지의 결합**이 우리 차별점.

### 2.6 나이스비즈맵 · 오픈업 · KT 잘나가게 · SKT 지오비전 퍼즐 — 민간 상권
| 서비스 | 강점 | 우리에 주는 교훈 |
|---|---|---|
| 나이스비즈맵 | 카드 매출 기반 고객 동선·업종 평균 매출, **월간 상권 보고서 구독** ✅ | «지정 상권이 매월 어떻게 변하나» = 월간 스냅샷·추이(v1 P3와 같음) |
| 오픈업(핀다) | 지도에서 **개별 매장 추정 매출**(범위·1년 추이) 무료 ✅. «추정치는 사실 증명 아님» 고지 | 타 업체 추정치 공개는 반발을 부른다(소상공인 반발 기사). 경쟁 병원 추정치 표시 금지 |
| KT 잘나가게 | **건물 단위** 유동인구·유입 경로, 무료 ✅ | 유동인구는 통신사 소유. 필요하면 API 계약(🔴) |

### 2.7 호갱노노 (부동산) — 반경 편의시설 UX의 국내 모범
- 단지 기준 **지하철역 거리·도보 시간**, 초등학교 통학구역, **도보 5·10·20분 범위** 보육시설, 반경 1km 내 시설 수, 병원·약국·마트 개수 ✅.
- **가져올 것**: «도보 N분» 칩 문법과 «가장 가까운 역까지 도보 분» 한 줄 — 일반 사용자가 이미 익숙한 표현. v1 §5.3 교통 구역에 그대로.

### 2.8 jSTAT MAP (일본 총무성 통계국) — 무료 공공 GIS의 완성형
- **영역**: 원(반경 지정, 예 1km) 또는 **到達圏**(도달권) ✅.
- **리치 리포트**: 로그인 시 지역분석 리포트 — 지도 캡처 + 인구 증감·세대 그래프 + 영역 안 소지역별 인구·종사자·세대·인구밀도, **Excel 출력** ✅.
- **가져올 것**: «지도 캡처 + 표 + 그래프» 한 벌을 파일로 — 리포트 §입지의 형식 정본.

### 2.9 일본 診療圏調査(진료권 조사) 생태계 — 의원 입지 분석의 표준 공식
- 표준 정의: 개원 시 **1일 예상 외래 환자 수**를 추정하는 조사. 진료권은 **동심원 거리** 또는 **차량 도달시간**으로 설정, 일반 의원은 **반경 1km 전후** ✅.
- **표준 공식** ✅: 추계 환자 수 = 진료권 인구 × 수진율(후생노동성 환자조사, 인구 10만 명당) ÷ (같은 과 경쟁 의원 수 + 1). «+1»은 자기 원.
- 산출물: 경쟁 의료기관 플롯 지도 + 개요 일람표 + 추계 환자 수 시뮬레이션.
- 공급자: DtoD 컨시어지·클리닉스테이션·클리닉개업내비(회원 무료 간이 WEB 조사), 리코리스·MSNW 등 개업 지원사, **MiSol**(클라우드: 동심원/도달권/임의 다각형/시구정촌/2차 의료권, 입원·외래 상병분류별 추계, 경쟁 일람·신규 시설 수요량 자동 산출, Excel 다운로드, 라이선스 초기비+월액) ✅.
- **가져올 것**: 공식을 한국 데이터로 치환한 «추계 환자 수(참고)» 카드. 단, 우리 원칙상 **점수·보장이 아닌 🟡추정**으로, 산정식을 팝오버에 그대로 공개.

### 2.10 Esri ArcGIS Business Analyst — 글로벌 GIS 표준
- **영역**: 링(거리) · **드라이브타임/거리** 다중 간격, 디스크/링 선택 ✅.
- **리포트**: 인구·소비·시장 잠재력·Tapestry 세그먼트 · **사이드바이사이드 비교 인포그래픽**(링 vs 드라이브타임, 최대 10개 영역, 차이값 표시) ✅. «긴급진료소 여러 곳의 의료 접근성 비교» 예시가 문서에 있음.
- **가져올 것**: ① 비교 인포그래픽 문법(차이값 강조) ② 링과 등시선을 한 화면에 겹쳐 «반경은 넓은데 도달은 좁은» 곳 드러내기.
- **한계**: 유료·미국 데이터 중심. 한국 인구 데이터는 자체 적재 필요.

### 2.11 Google Places Insights / Places Aggregate API
- **기능**: 지정 영역(반경 등) 안 장소를 유형·영업 상태·평점·가격대로 **집계 카운트**(INSIGHTS_COUNT) 또는 place ID 반환. BigQuery에서 약 300개 장소 유형·70개 속성 ✅. «500m 반경 안 체육관·학교·대중교통역 밀도» 같은 예시.
- **가격**: 쿼리 사용량 과금(수치 언급 없음).
- **가져올 것**: 반경 안 **대중교통역·학교·마트 개수** 같은 «생활 인프라» 보조 지표를 한 번의 집계 호출로. 다만 카운트 결과의 저장·표시 약관 확인 필요 🔴.

### 2.12 Placer.ai · SafeGraph — 유동·방문 데이터(미국)
- 모바일 패널 기반 방문·체류 추정, Placer 기업 구독 **연 5만 달러 안팎**부터 ✅. 패널 편향(젊은·고소득) 있어 1차 데이터로 검증 권고.
- **교훈**: 유동인구는 어디서나 비싸고 편향이 있다. 우리 v1의 🔴 처리(자리만) 유지, 필요 시 SKT·KT API.

### 2.13 Stratasan(Definitive Healthcare) — 병원 시장 점유 지도
- **시장 지배(Market Dominance) 지도**: 병원별 도달 범위를 색으로, 시장 점유·페이어 믹스·경쟁 강도 지도, 서비스 라인별 심층 ✅. «거리가 점유를 좌우한다»는 자체 분석.
- **가져올 것**: 우리 AEO의 **인용 점유(SOV)**를 **지도 위 거리**와 겹치기 — «가까운 경쟁일수록 AI 답변에서 함께 언급되는가». P3 이후 연구 과제.

### 2.14 미국 Census Business Builder · 캐나다 CPDV
- 지역·업종 선택 → 지도에서 인구·경제 데이터 열람·다운로드 ✅. 소기업용 단순 메뉴.
- **교훈**: 공공 데이터 브라우저는 «선택 → 지도 → 표 → 다운로드» 4단이면 충분. 우리 히어로(지도+표)와 같은 구조.

## 4. 공통 패턴 (모든 상위 서비스가 갖춘 것)

1. **첫 화면 = 지도 + 요약 표 하나.** 지표 상세는 아래로. (SGIS·jSTAT·Esri·메디게이트 공통)
2. **영역은 사용자가 고르고, 기본값은 업종이 정한다.** 상권 1.5km, 의원 1km, 병원 더 넓게.
3. **경쟁은 «같은 업종·같은 과»로 좁혀서 센다.** 전체 병원 수는 참고일 뿐.
4. **인구는 연령×성별 피라미드 + 타깃 구간 강조.** (메디게이트 연령, MiSol 상병별, Esri Tapestry)
5. **변화(추이)를 판다.** 개폐업·월간 보고서·매출 추이 — 정적 스냅샷보다 «지난달 대비».
6. **비교가 곧 인사이트.** 지역 A vs B, 링 vs 드라이브타임.
7. **추정치는 추정이라고 크게 쓴다.** (오픈업 고지·일본 診療圏 «예측치» 단서)
8. **출력물이 있다.** Excel·PDF·월간 보고서 — 화면만으로 끝나는 서비스가 없다.

## 6. 우리 차별점 (벤치마크 대비)

- 모든 상권·개원 툴은 **«개원 전 어디에 낼까»** 를 묻는다. ANSEO는 **«이미 있는 거래처를 어떻게 알릴까»** 를 묻는다. 그래서 입지 결과가 **키워드·AEO 질문·경쟁사 식별·리포트**로 흘러가는 것이 유일한 차별점이고, 매출·환자 예측은 우리 몫이 아니다.
- 반경 10km까지 보는 이유는 병원급 진료권과 «역명·동명 키워드 사다리»를 위해서다. 상권 툴의 1.5km 상한과 다르다는 점을 화면에 적는다.
- 유동인구·카드매출은 남의 데이터다. 없는 것을 «—»로 두는 정직함이 오픈업식 추정 공개보다 낫다.
