## 1. 조사 환경 (정직하게)

이 방과 조사원 컨테이너의 프록시는 `data.go.kr`·`kosis.kr`·`sgis`·`ktdb`·`zenodo.org`·`kaggle` 등 한국 공공·학술 도메인을
거의 다 막는다 (000/403). 그래서 조사원들은 (a) `apis.data.go.kr` 게이트웨이를 가짜 키로 두드려 **엔드포인트 실존
여부**(코드 30 = 실존 · 12 = 없음) 를 확정하고, (b) GitHub 의 실제 호출 코드·저장된 응답으로 **요청/응답 필드** 를
확인했으며, (c) 페이지 본문(공공누리 유형·트래픽 한도) 은 「못 확인」 으로 남겼다. Zenodo 는 이 방의 바깥 샌드박스가
열려 이 방이 직접 실측했다.

## 2. 1순위 실측 — Zenodo 전국 1km 24시간 유동인구 (이 방 · 바깥 샌드박스)

- 레코드 API `zenodo.org/api/records/17103641`: `license cc-by-4.0` · `access open` · 2025-09-13 공개 ·
  파일 `Floating_pop_1km_2022.zip` 3,608MB · `2023` 3,606MB · `2024` 3,625MB.
- zip 안: `2024/Floating_pop_YYYYMMDD.tif` 366개 (하루 한 파일 · **24밴드 = 시간대**) · EPSG:5179 · 620 x 650 · float32 ·
  1km 격자 · bounds 740000~1390000 / 1450000~2070000.
- 통째로 받지 않고 **원격 zip 부분 읽기**(`remotezip`) 로 하루 파일(38.7MB) 만 17초에 꺼냈다.
- 2024-01-11 실측: 12시 밴드 전국 합 **53,905,924** · 03시 **50,769,640** · 값 있는 격자 117,124 / 403,000 · 최대 격자
  138,837명/km² (12시). 전국 합이 실제 인구(약 5,100만) 와 맞는다 — 「그 시각에 그 자리에 있는 사람」 의 추정치.
- 논문: Lee, Kang, Sung, Hwang, *A nationwide 24-hour floating population dataset for South Korea derived from
  multi-source data, 2022-2024* (GIScience & Remote Sensing 2026 · SKT 유동인구를 건물·토지피복·접근성·기상으로 학습해
  전국 외삽). **한계**: 추정치 · 학습 라벨이 대도시 중심이라 비도시 정확도 검증 필요 · 2024 까지 · 재갱신 없음 · 성·연령 없음.
- **집계 설계** (샌드박스 백그라운드 잡): 2024 년 매달 평일 2·주말 2 = 48일 표본 (공휴일 제외) → 격자별 **평일 24h
  평균 · 주말 24h 평균** → 값 있는 격자만 컬럼형 gzip JSON (row·col·lat·lng·wd[24]·we[24]) → Higgsfield → fetch-file.
- **창구 설계**: 반경 안(최소 탐색 반경 800m) 격자 중심점의 평균 밀도(명/km²) x π r² = 반경 안 시간대별 유동인구 추정 ·
  낮 최고/밤 최저 · 낮/밤 배율 · 평일/주말 · 주민등록 반경 인구(v0.3.513) 와 견줌 (「낮에 몇 배 몰리나」).
- 출처 표기 (CC BY): 「Lee et al. (2025) 전국 24시간 유동인구 1km 2022–2024 · Zenodo 10.5281/zenodo.17103641 · CC BY 4.0
  · SKT 통신 기반 ML 추정」.

## 3. 2·3순위 실측 — 공공데이터포털 API (조사원 · 게이트웨이 타격 + GitHub 가동 코드)

**관광공사 방문자수** `apis.data.go.kr/B551011/DataLabService/locgoRegnVisitrDDList` (시군구) · `metcoRegnVisitrDDList` (시도):
`serviceKey·MobileOS·MobileApp·startYmd·endYmd·pageNo·numOfRows·_type=json` · 지역 필터 없음(날짜로 전국 772행/일) ·
응답 `baseYmd, signguCode, signguNm, daywkDivCd/Nm, touDivCd/Nm(1현지인·2외지인·3외국인), touNum(소수·통신 추정)` ·
「방문자」= 일상생활권 밖 체류자 · 일별 순방문자(2박3일 = 3명) · 시군구·시도 집계 기준 달라 합산 금지 · 활용신청 당일
자동승인 사례(2026-05-16) · 개발계정 1,000건/오퍼레이션/일.

**행안부 인구이동** `apis.data.go.kr/1741000/ppltnDataStus/selectPpltnDataStus`: `srchFrYm·srchToYm`(YYYYMM · 한 번에
최대 3개월) · `mvinAdmmCd`(전입 10자리) · `mvtAdmmCd`(전출 10자리) · `lv` · `type=json` · `numOfRows=1000` · 응답
`statsYm, mvin*/mvt*(시도·시군구·동), totNmprCnt, maleNmprCnt, femlNmprCnt, male0AgeNmprCnt…male110AgeNmprCnt,
feml0…feml110` (1세 단위) · 2022-10 집계 시작 · 전국 OD 는 시도 x 시도 289 스코프 x 페이지네이션이 검증된 방식.
우리 행정동 코드(행안부 10자리) 와 **같은 코드 체계** 라 그대로 붙는다.

두 API 모두 **콘솔 「외부 연결 열쇠」의 공공데이터포털 열쇠 자리**(심평원과 같은 `data_go_kr_service_key`) 에 얹힌다.
사장님 손 = 공공데이터포털 로그인 → 두 API 활용신청(자동승인) → 열쇠가 아직 없으면 콘솔에 1회 입력.
