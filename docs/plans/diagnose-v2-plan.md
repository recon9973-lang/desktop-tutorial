# 무료진단 v2 기획 보고서 — 통합·멀티 AI 실측·인포그래픽 개편

> 오더: ①진단 서비스가 한눈에 안 들어옴(SEO·GEO 묶기 등) ②AI 진단의 실체(실제 AI인가 웹 진단인가) 구분
> ③웹 진단이면 Gemini·ChatGPT·Claude·Perplexity 구분 진단 가능한지 ④업체명만 넣으면 유사 질문 변형 진단 가능한지
> ⑤인포그래픽 적극 활용한 가독성 개편 — 검토·브레인스토밍·기획 후 보고

## 1. 현재 진단 도구의 실체 (코드 실측 — 질문 ②에 대한 답)

| 도구 | 실체 | 데이터 소스 |
|---|---|---|
| SEO 분석 | **웹 진단** | 페이지 HTML을 수집해 자체 엔진(SEOEngine)이 60여 항목 정적 채점. Google 기준 |
| 속도(PSI) | **웹 진단** | Google PageSpeed 실측 |
| GEO 분석 | **웹 진단** | 페이지 구조가 'AI가 인용하기 좋은가'를 규칙 기반 채점 — **AI에게 물어보는 것이 아님** |
| **AI 추천 확인(AEO)** | **진짜 AI 실측** | **Perplexity(sonar)에 실제로 질문**해 그 순간의 AI 답변·인용 출처를 받아옴. DB 없음, 저장 없음 |
| 키워드 검색량 | 웹 진단 | 네이버 검색광고 API |
| 검색 트렌드 | 웹 진단 | 네이버 데이터랩 |
| 노출 체크 | 웹 진단 | 네이버 검색 API(블로그·카페 문서량) |

**결론**: 7개 중 AI 실측은 1개(Perplexity)뿐. "GEO 분석"이라는 이름 때문에 AI 진단처럼 보이지만 실제로는 웹 구조 진단 — 이름과 실체의 불일치가 혼란의 원인. v2에서 명확히 분리·표기해야 함.

## 2. 멀티 AI 엔진 구분 진단 — 기술 타당성 (질문 ③)

| 엔진 | 지금 가능? | 근거 |
|---|---|---|
| **Perplexity** | ✅ 즉시 | 이미 연결·가동 중 |
| **ChatGPT** | ✅ 즉시 | OpenAI 키 보유(자동발행에 사용 중). Responses API 웹검색 도구로 "지역+진료과 추천" 실질문 가능 |
| **Gemini** | 🔶 키 추가 필요 | Google API 키는 있으나(PSI용) Generative Language API 활성화/별도 키 필요. Search grounding 지원 |
| **Claude** | 🔶 키 추가 필요 | Anthropic 키 미보유. 웹검색 도구 지원 |

- **1단계(즉시)**: Perplexity + ChatGPT **2엔진 비교** 출시 — 추가 비용은 호출당 수십 원 수준
- **2단계**: 사장님이 Gemini·Claude 키를 발급하면 환경변수만 추가해 **4엔진 매트릭스** 완성
- 각 엔진 결과는 "언급됨/인용됨/미노출" 3단계 판정 + 원문 답변 접기로 표시

## 3. 유사 질문 자동 변형 진단 (질문 ④) — 가능, 핵심 차별화

병원명(+지역·진료과)만 입력하면 환자들이 실제로 묻는 패턴 5종으로 자동 변형:

1. "{지역} {진료과} 잘하는 곳 추천해줘"
2. "{지역} {진료과} 어디가 좋아?"
3. "{지역} {진료과} 비용 합리적인 곳"
4. "{병원명} 어때? 믿을 만해?"
5. "{지역}에서 {대표시술} 잘하는 병원"

→ **엔진(2~4) × 질문(5) 매트릭스**로 실측, 각 셀에 언급 여부 표시. "20번 물어봤는데 몇 번 나왔는가"가 단일 점수보다 훨씬 설득력 있는 리드젠 자료.
- 비용·시간: 1회 진단당 API 10~20콜, 30~60초 소요 → 순차 진행바 + "하루 10명 한정"과 자연스럽게 결합
- 남용 방지: 동일 브라우저 1일 N회 제한(localStorage) + 서버 측 간단 rate limit

## 4. 한눈에 들어오는 구조 — 3계층 통합 (질문 ①)

브레인스토밍한 4개 안 중 채택안:

| 안 | 내용 | 판정 |
|---|---|---|
| A. 순서만 정리 | 도구 7개 나열 유지 | 기각 — 근본 해결 아님 |
| B. 탭 분리 | 도구를 탭으로 숨김 | 기각 — 숨긴다고 단순해지지 않음 |
| **C. 목적 기준 3계층** | 아래 상세 | **채택** |
| D. 종합진단 단일화 | 개별 도구 전부 제거 | 기각 — 전문가 도구는 재방문 유도 자산 |

**채택안 C — "무엇이 궁금한가" 기준 3개 번들:**

1. **🏆 종합 진단** (원클릭, 현행 유지·강화) — "우리 병원 지금 몇 점?"
2. **🤖 AI 노출 진단** = AI 추천 확인 + GEO 구조 + 노출 체크 통합 — "AI가 우리를 추천하나?"
   → 여기에 §2 멀티 엔진 + §3 유사 질문 매트릭스 탑재
3. **🔍 검색 수요 진단** = SEO + 속도 + 키워드 검색량 + 트렌드 통합 — "검색에서 잡히고 있나?"

개별 도구 7개는 각 번들 결과 하단의 "세부 도구" 접기로 이동 — 첫 화면에는 카드 3장만.

## 5. 인포그래픽 개편 (질문 ⑤)

이미 보유한 차트 엔진(infographics.js: 막대·radar·라인) + 신규 2종으로 텍스트를 시각화:

| 현재(텍스트) | 개편(인포그래픽) |
|---|---|
| 점수 숫자 나열 | **도넛 게이지 3개** (번들별 대표 점수) |
| AI 답변 텍스트 덩어리 | **엔진×질문 히트맵 매트릭스** (초록=인용/노랑=언급/빨강=미노출) — 신규 |
| 검색량 숫자 | **수요 게이지 + 경쟁도 배지** |
| 트렌드 막대 | 기존 상세 차트 유지 |
| 처방 텍스트 | **우선순위 로드맵 스텝바** (1→2→3 아이콘 카드) — 신규 |
| 자가진단 13항목 | **radar 차트**로 결과 요약 (기존 엔진 재사용) |
