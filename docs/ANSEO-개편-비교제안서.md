## 결론

**ANSEO는 측정의 정직성에서 GPTO보다 앞서 있고, 보여주기에서 뒤진다.**
명세 YAML + 체크섬 + coverage/confidence + `UNKNOWN` 거절은 GPTO에 없는 자산이다.
개편해야 할 것은 엔진이 아니라 **정보구조와 입구**다.

## 현재 구조 3대 문제 (코드 실측)

### ① 라우트 이름과 화면 내용이 어긋나 있다
| 메뉴 라벨 | 라우트 | 실제 H1 | 담고 있는 것 |
|---|---|---|---|
| 진단 | `/console/seo` | 진단 | SEO + GEO 준비도를 `axis` 토글로 겸용 |
| **AEO** | `/console/geo` | **AEO — AI 답변 노출** | 실제 AI 관측 + 질문 만들기 |

README 설계원칙 4번은 "GEO 준비도와 실제 AI 가시성은 끝까지 분리한다 — 별도 엔진, 별도 점수, **별도 화면**"인데 화면만 안 지켜졌다.

**이미 정답이 코드 안에 있다** — `lib/navigation.ts:95–100`의 거래처 상세 탭은 이미 `진단·SEO·GEO·AEO·이슈·리포트`로 갈라져 있다. 올바른 분류가 거래처 레벨에는 있고 최상위에만 없다. 개편은 **이미 있는 분류를 위로 올리는 일**이다.

### ② 질문 만들기가 관측 화면 안에 묻혀 있다
`geo/page.tsx:538` 질문 만들기 카드, 앞에 `:555 "어느 거래처의 질문인가요?"` 선행. 폼 자체는 `PromptSetForm.tsx` **1,443줄**로 균형 미리보기·월 비용·생성 근거 저장까지 갖췄다. 문제는 능력이 아니라 **도달 경로와 첫 화면 밀도**다.

### ③ 업체 등록이 4필드뿐
`customers/CompanyForm.tsx`: 업체명 · 업종 · 측정 URL · 소재지. 지도 등록 없음.
지도류는 `geo/citation-channels.ts`에 **인용 채널 분류용**으로만 존재 — AI가 지도를 인용한다는 걸 알면서 등록시키는 길은 제품에 없다.

### 요구 6 근거
리포트 S5·S6에서 자사 미언급 시 AI가 대신 인용한 것이 **카카오맵·네이버 지도**였다. 지도 등록은 선택이 아니라 **AEO 최소 진입 조건**이다.

### 요구 8 주의
`EngineTotalsStrip.tsx` 주석에 2026-08-22자 정정 지시("관측횟수가 아니라 데이터의 양")가 근거로 남아 있다. 이번 지시가 그 반대이므로 **주석도 함께 갱신**해야 다음 사람이 되돌리지 않는다.

## 화면별 데이터 정의 (요구 7)

| 화면 | 메인 인포그래픽 | 본문 | 추가 제안 |
|---|---|---|---|
| 대시보드 | 4영역 종합(SEO·GEO 점수, AEO 언급률, 열린 이슈) | 오늘 손댈 것·영역별 현황·12주 추이·검수 대기열 (이미 있음) | **업체 등록 입구를 여기로.** 등록 0곳이면 등록을 먼저 요구 |
| SEO | 페이지 축 분포 | 페이지별 검사·판정 분포·직전 대비·재검사 | `axis` 토글 제거. coverage·confidence 상설 |
| GEO | 준비도 항목 구성비 | 항목별 점수 + `fix_examples` + 명세 버전 | AEO와 나란히 보되 **합산 금지** — 준비도↑ 노출↓ 조합이 최고의 진단 |
| AEO | 엔진별 레이더(기존vs현재) + 전체 언급률 1줄 | 질문별 기존%→현재%·경쟁사 언급·참조 출처·모델별 응답 | **가중 언급률**·**참조 출처 집계**·질문 관리 분리 |

> 네 지표를 하나의 총점으로 합치지 않는 원칙은 유지한다. 대시보드 종합 그림은 **합산 점수가 아니라 4개 값을 나란히** 놓는 그림이다.

## 실행 순서

| # | 작업 | 규모 | 비고 |
|---|---|---|---|
| 1 | 상단 누적을 개수로 (요구 8) | 반나절 | 데이터 이미 존재, 로직 변경 없음 |

| 4 | 라우트 분리 + 메뉴 재편 (요구 7·2) | 1주+ | **분수령.** 리다이렉트·기존 리포트 링크 보존 필수 |
| 5 | 질문 만들기 프리필 (요구 4) | 1주 | import 완료 상태, 조립 규칙+화면만 |

1~3번은 구조를 안 건드려 병렬 가능하고 바로 체감된다. 4번이 분수령이다.

## GPTO에서 가져올 것 / 가져오지 말 것

**가져올 것** — 질문 카드 3요소 절제 · 대표 수치 3단 타이포 · 동적 y축 · 참조 출처 모델 귀속 배지 · 정직한 하락 표시

**가져오지 말 것**
- 가중치 수치 그대로(19.6/8.4) — 출처 미공개 가정치. 베끼면 `UNKNOWN` 원칙이 무너진다
- 블랙박스 종합 점수(80점) — 도입하려면 산식과 입력값을 펼쳐야
- 경쟁사 순위표 고객 노출 — 의료광고법 비교광고 소지
- 2단 노출 판정 — 우리 인용·언급 분리가 더 정밀. downgrade 금지
