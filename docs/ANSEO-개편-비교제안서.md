## 시안 5종 (아티팩트에 렌더 포함 — ANSEO 실제 토큰 사용)

토큰 실측: 보드 `#0d1417` · 면 `#182226` · 액센트 `#00ed64`(채움 전용) · 상태 5색(pass/warn/fail/na/unknown) · 알약 버튼 · tabular-nums (`packages/ui/tokens.css`)

- **M1 상단 스트립**: 참고 이미지(OptiAnalytics) 문법 — 상태점+제목 | 전체 누적 N회 | 엔진 색점+개수 1단 | 집계 시작일+접기. 숫자=`answers`, 글자수는 툴팁. 못 읽으면 「못 읽음」(ADR 0002 유지).
- **M2 대시보드 벤토**: 타일 크기=중요도(AEO 히어로 3단 타이포, SEO/GEO 중형, 할일 소형) + 거래처 F1 행(1행=1곳). **합산 점수 없음** — README 원칙 유지. 자체 리서치(08-17: Bloomberg 밀도·벤토 비대칭·F1 행문법)의 이행.
- **M3 AEO 탭**: 질문 카드 3요소 + `+ 새 질문 추가` 고정 버튼 + **엔진 격자(칸 명도=반복 3회 중 언급 수, 회색=답변없음·분모 제외 — IA 지적 2 확정안 그대로)** + 참조 출처(엔진 귀속 배지+복사/새창).
- **M4 질문 프리필**: 업체 칩 → 초안 8개(체크박스+질문+월 검색량+조립 근거 태그) → 균형·월 비용 푸터. 재료(`keyword-volume`·`question-sources`·`regionLadder`)는 이미 전부 import돼 있음 — 조립 규칙과 화면만 신규.
- **M5 지도 4종**: 네이버 플레이스/구글 비즈니스/카카오맵/빙 플레이스 × 3상태 칩 + 안내 링크. 저장 URL은 `citation_channels` 인용 대조로 연결.

## 타사 리서치 (WebSearch 2026-08-22)

기존 자체 리서치(`docs/design/2026-08-17-design-RESEARCH.md`)의 결론(밀도=기능·벤토 비대칭·F1 행·mono 숫자·기능색만)은 **살린다.** 그 위에 AEO 전문 도구 5개:

| 도구 | 화면 문법 | 가져올 것 |
|---|---|---|
| Profound | 인용 점유 시계열, 최심 인용 분석 | 도메인 단위 인용 점유 시계열 |
| Peec AI | share-of-voice 경쟁 라인차트 | 경쟁 언급 시계열(자사 흰점) |
| Otterly.AI | 프롬프트 단위 모니터링, 링크 위치 추적 | 질문=1급 시민 구조(M3 근거) |
| Ahrefs Brand Radar | 7개 인덱스, **언급/인용 별도 지표** | 분리 표기 — 데이터는 이미 구분함 |
| Semrush AI Toolkit | 게이지 vs 업계평균, 프롬프트=키워드(난이도·볼륨) | M4의 검색량 병기. "업계평균"은 자사 거래처 풀로 한정(날조 방지) |

공통 패턴: ①질문 단위 추적 ②언급/인용 구분 ③경쟁 벤치마크 ④인용 출처 분석. ANSEO는 ①②④ 데이터 보유, ③만 데이터부터 없음. **격차는 측정이 아니라 표현.**

## 브레인스토밍 (자산 유무 판정 포함)

- 인용 채널 크로스탭(채널×엔진) — `citation_channels` 보유, 시각화만
- 관측 사다리에 지도 0단계 — `PublishLadder` 보유
- 질문 포트폴리오 균형 스택 — `FUNNELS/INTENTS` 보유
- 언급 vs 인용 이중 지표 — 데이터 보유, 표기만
- AI 경유 유입 증빙(`utm_source=openai` 태깅) — 신규·소형
- 거래처 풀 평균 벤치마크 — 신규, "업계 평균" 날조 없이 가능
- 경쟁 브랜드 로스터 — 유일하게 데이터부터 신규(표기 정규화 難)
- **깨어남 단계는 보존** — 타사에 없는 고유 문법, 벤토 타일로 승격
