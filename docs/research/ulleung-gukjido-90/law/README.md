## 이 파일로 확정한 것 (17차 개정 §7)

- **영 §37②③** — 지가변동률 치환은 **"도로, 철도 또는 하천 관련 사업을 제외한 사업"**이면서
  **사업면적 20만㎡ 이상**일 때만 발동한다. 국지도 90호선(도로 · 2.7km)은 **두 겹으로 차단**된다.
  §37② **단서**는 한 방향으로만 작동한다 — 비교표준지 소재 시·군의 지가변동률이 **인근보다 작을 때만** 치환.
- **영 §38의2①** — 적용 공시지가 소급도 같은 문언(**도로·철도·하천 제외 + 20만㎡ 이상**)이다.
- **영 §39** 잔여지 판단 4호 · **§40⑤** 이주대책 제외 · **§41** 이주정착금 지급사유(2021.11.23. 4호 신설)
  · **§28** 시·도지사·토지소유자의 감정평가법인등 추천.

15차·16차가 GitHub 법령 미러와 검색 스니펫으로 인용했던 위 조문들을 **1차 자료로 대조 완료**했다. 오류는 없었다.

## 아직 저장소에 없는 것

- 토지보상법 **법률** 본문 · **시행규칙** 본문 — 세션 스크래치패드(`law.md` / `rule.md`)에만 있고 컨테이너와 함께 사라진다.
  legalize-kr 미러(`raw.githubusercontent.com`)에서 다시 받을 수 있다.
- 감정평가에 관한 규칙 · 감정평가 실무기준(국토부고시 제2023-522호) — `admrule-kr` 미러.
- 판례 코퍼스 124,909건 — `precedent-kr` 로컬 클론. 용량이 커서 저장소에 넣지 않는다.
