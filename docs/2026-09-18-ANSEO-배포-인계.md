## 0. 먼저 — **「앞의 넷」은 이미 나가서 돌고 있다**

사장님께는 대기 표에 넷이 쌓여 있다고 말씀드렸는데, 러너로 재 보니 **그 넷은 이미
main 에 들어갔고 운영에서 돌고 있다.** 다시 낼 것이 없다.

```
[실측 2026-09-18 23:11 KST · 러너 「도는 판 확인」 실행 35354658053]
  웹   https://veo.seokorea.org                  http 200 · 판 0.3.610
  서버 /api/health                               0.3.610 (뜬 지 768초)
  워커 /api/queue                                1대 · 0.3.610 · 뒤처진 0
  발행본 /api/scoring/specs                      GEO 1.9.0(10개) · SEO 1.14.0(17개)
```

대장 §2 머리말의 **「미배포 0.3.608~0.3.610」은 낡은 문장이다.** 그 셋은 지금 돈다.
`| 0.3.608 |` 셋과 `| 0.3.610 |` 하나는 **대기 표에서 빼 `WORKLIST-HISTORY.md` 로
옮겨야 한다** — 남겨 두면 다음 사람이 또 배포한다(감사 A-07·B-07). 이 방이 안 옮긴
까닭은 남의 방 줄이기 때문이다. **배포하는 방이 자기 줄을 옮기면 된다.**

까닭은 남의 방 줄이기 때문이다.

## 2. 이 방이 넘기는 것

```
저장소   veo-platform
가지     claude/wonderful-cori-8z4sqp      ← origin/main(0.3.610) 을 이미 합쳐 뒀다
커밋     4개
```

| 커밋 | 무엇 |
| --- | --- |
| `4d960dc` | `scripts/measure_customer_pages.py` — 거래처 홈페이지 장수를 재는 자 |
| `c845c3b` | 대장 §4-C 에 한 줄 — 「잴 준비됐다」 |
| `c2359d8` | 대기 표에 번호 없는 줄 하나 · 머리말에 꼬리 |
| `862a7f9` | main(0.3.610) 합침 — 겹친 자리는 저쪽을 받음 |

**무엇을 하나.** 거래처 명단을 DB 에서 읽어 사이트맵으로 장수를 세고, `--crawl` 을
붙이면 제품 크롤러(`ConsoleCrawler`)를 상한만 풀어 돌려 실제 장수까지 낸다. 결과는
화면 표와 `docs/research/<날짜>-customer-page-counts.json` 으로 남는다.

**왜 필요한가.** 크롤 상한 200 을 올릴지 내릴지 정하려면 거래처가 실제로 몇 장인지
알아야 하는데 지금 «—» 다. [실측 2026-08-01] 실도메인 8곳은 전부 당시 상한 100 장에
잘린 값이라 사이트 크기가 아니고, [실측 2026-08-11] 참사랑한의원 195장(상한의
97.5% · 9일에 +23장)이 마지막 기록이다.

**앱 코드는 안 건드렸다.** 새 파일 하나는 `scripts/` 에 있고 어느 곳도 이것을 부르지
않는다. 마이그레이션 없음 · 저장된 자료 무변경 · 잰 값 무변경 · 화면 무변경.

**이 방이 검사한 것**
```
ruff check       저장소 규칙 그대로(줄길이 100 · E,F,I,B,UP,S,C4,SIM,RUF) 통과
구문 검사        통과
가짜 사이트 실측  색인 사이트맵 펴기 · 중복 주소 한 번 · 경로별 가르기 ·
                 이미지 주소 제외(항목 5개 중 4장) · 사이트맵 없으면 «—» ·
                 엔터티 폭탄은 글자 `&b;` 로만 들어옴
대장 관문 재현    worklist.test.ts 의 검사를 같은 정규식으로 그대로 재현 — 전부 통과
```

**이 방이 못 돌린 것 (그쪽에서 받아야 한다)**
```
--crawl 경로      제품 크롤러를 부르는 길. 이 방은 바깥길이 막혀 확인 못 함
make ci-local     가상환경이 없다
웹 시험·빌드      apps/web 꾸러미가 없다 — 관문 재현은 진짜 시험이 아니다
```
`make deploy` 의 사전 점검이 이 셋을 전부 받는다.

안 썼다. 그런데 새 항목 없이 판을 물리면 `claim_version.py` 가 **이미 나간 기록에 새
