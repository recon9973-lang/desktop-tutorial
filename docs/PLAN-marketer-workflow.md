## 0. 이 문서의 목적 — "직원 머릿속·시트·캘린더에 흩어진 업무를 ERP 한 곳으로"

베놈 마케터들은 **여러 병원 거래처의 네이버 노출을 매일 관리**한다. 그런데 그 업무가 지금은 세 군데로 흩어져 있다.

- **구글 스프레드시트** — 키워드 노출 현황, 발행 로그, 방문자/조회수 보고
- **구글 캘린더 / 스케두** — 업체별 색상으로 구분한 일정
- **개인 메모(SMemo·포스트잇)·저장된 프롬프트·PC 폴더** — 인수인계 불가능한 암묵지

이 기획서는 담당자들이 **실제로 하는 일**(첨부 데이터)과 **직접 요청한 희망사항**을, 이미 82% 완성된 베놈 ERP(`marketing-agency-erp`) 위에 얹어 하나의 워크플로우로 통합하는 설계다. 신규 구축이 아니라 **기존 자산 재포장 + 자동화 글루 연결** 문제다.

> ⚠️ 실제 ERP 코드는 별도 저장소 `marketing-agency-erp`에 있고 이번 세션 범위 밖이다. 따라서 본 문서는 **구현을 지시하는 스펙/기획안**이며, 실제 코드 변경은 해당 저장소의 후속 세션에서 진행한다.

## 1. 현행 업무 분석 (As-Is) — 담당자 데이터 기반

### 1.1 담당자별 도구·업무

| 담당자 | 핵심 업무 | 사용 도구 | 남긴 문제/희망 |

### 1.2 실제 관리 대상 — "키워드 노출 현황" 시트 (핵심 산출물)

담당자들은 병원별로 아래 매트릭스를 손으로 채운다(실측 예시).

| 키워드 | 검색량 | 플레이스 | 상단통합 | 클립 | 브랜드콘텐츠 | 인기글 | 하단통합 | 이미지 | 파워플레이스 | 파워링크 |
|---|---:|---|---|---|---|---|---|---|---|---|
| 대구병원마케팅 | 430 | 달서2 | ○ | ○ | | | ○ | ○ | | |
| 대구치과마케팅 | 40 | | ○ | ○ | | | ○ | | | |
| 대구한의원마케팅 | 30 | | ○ | ○ | | | ○ | ○ | | |
| 대구마케팅 | 310 | 베놈X/달서2 | ○ | | | | | | | |
| 병원마케팅 | 6,310 | | | | | | | | | |

- **9개 노출 영역**(플레이스·상단통합·클립·브랜드콘텐츠·인기글·하단통합·이미지·파워플레이스·파워링크)을 키워드마다 체크.
- **"월보장" 키워드** = 계약상 순위를 보장한 키워드. 떨어지면 계약 리스크 → 담당자가 신현지 요청처럼 **자동 감지**를 절실히 원함.

### 1.3 발행·성과 관리 시트 (버팔로/티스토리 예시)

- **브블(브랜드블로그)·배포(정보성 배포계정)·월보장** 3종 트랙으로 포스팅번호·날짜·키워드·주제·링크를 기록.
- 방문자수/조회수를 브블·배포 각각 집계(예: 브블 6/1,309, 배포 6/175).
- **티스토리**(꾸다·베놈 계정)·**인스타그램**(팔선생·꾸다)까지 채널 다변화.

### 1.4 원고 생산 파이프라인 (신현지·서영석 원장 프롬프트 실측)

저장된 프롬프트로 **역할설정 → 13개+ 필수준수규칙**을 GPT/제미나이에 주입해 원고를 뽑는다. 실제 규칙 요지:
- 네이버 유사문서 회피(완전 재구성), 원장 1인칭 친근체 + 전문성, 조사·수식어 남발 금지
- 본문 2,500자, **핵심요약 → 목차 6개 → 소제목(15자↓) → FAQ** 구조
- 병원 홍보 배제(주제·키워드만), 단정형 표현("~이다"), 두괄식·숫자·표 활용(AI 인용 최적화 = AEO)
- **의료광고법 준수**(전후사진·효과보장·최상급 표현 배제)

> 이 프롬프트 자산이 지금은 **개인 파일에 흩어져** 있다. ERP의 프롬프트 라이브러리로 승격해야 한다.

### 1.5 이미지 생산 (미리캔버스·클립아트코리아·포토샵·제미나이)

카드뉴스·썸네일·본문 이미지·유튜브 썸네일을 미리캔버스/포토샵으로 제작, remove.bg로 배경제거, 제미나이로 구도수정. 의료광고 심의문구("본 포스팅은 의료법 제56조…") 삽입.

## 3. To-Be 통합 워크플로우 — "거래처 하나가 한 파이프라인을 흐른다"

```
거래처(병원) 온보딩
   └─ 키워드 등록(월보장/일반) · 프롬프트 프리셋 · 특이사항 노트 · 채널 계정
        │
        ▼
① 월간 작업 자동편성 ──▶ ② 원고 자동생성 ──▶ ③ 이미지/카드뉴스/GIF ──▶ ④ 발행(서식 자동)
   (발행 캘린더 생성)      (프리셋+의료광고검증)     (배경제거 내장)          (네이버/티스토리/인스타)
        │                                                                        │
        │                                                                        ▼
        └───────────────◀────── ⑥ 성과·보고서 자동집계 ◀──── ⑤ 노출 모니터링(월보장 알림)
                                  (방문자·조회수·순위)         (순위하락 카카오 알림톡)
```

각 단계는 **기존 ERP 자산에 직접 매핑**된다(다음 절).

## 5. 기능 모듈 명세

### M1. 거래처 워크스페이스 (Client Hub) — 인수인계의 단일 진실원천
- 병원 프로필(진료과·지역·플레이스ID·채널계정: 네이버 브블/배포, 티스토리, 인스타).
- **특이사항/인수인계 노트**(P9): 타임라인형, 작성자·날짜 스탬프, 담당 교체 시 그대로 승계.
- **월보장 계약 탭**: 보장 키워드·목표순위·계약만료일.
- 폴더 대체: 브블/배포/월보/사진/로고/보고서/의료심의를 **태그 기반 자산함**으로.

### M2. 키워드·노출 트래커 (Exposure Tracker) — 시트를 대체
- 9개 노출영역 매트릭스를 ERP 테이블로. 키워드별 검색량은 `insights.js`(네이버 키워드도구)로 **자동 채움**(P4).
- **월보장 모니터링(P3, 최우선)**: 스케줄러가 주기적으로 순위 스냅샷 → 하락/미노출 시 담당자·대표에게 **카카오 알림톡**.
  - 근거: 네이버 데이터랩 실측상 "대구병원마케팅" 검색 관심도가 2026-03에 평월 대비 급등(상대치 2.94)하는 등 **월단위 변동성이 커** 사람이 매일 보긴 어렵다 → 자동 감시가 실효적.
- 노출 히트맵·추세 그래프(상승/하락 색상).

### M3. 원고 스튜디오 확장 (Manuscript+) — P1
- **거래처 프롬프트 프리셋**: "역할설정 + 13필수규칙"(1.4)을 거래처별로 저장. `[키워드][병원][상세정보]` 슬롯만 채우면 원고 출력.
- 유형 프리셋: **브랜드블로그(원장 1인칭)** · **정보성 배포글** · **영수증 원고**.
- 파이프라인 통과: `medical-ad-validator`(의료광고법) → `content-validator`(깨짐/환각 전화번호 정리) → 유사문서 리스크 표시.
- **발행 서식 자동화(P5)**: 소제목 강조·색상·핵심요약 박스·FAQ 아코디언을 네이버 붙여넣기용 서식으로 출력.

### M4. 크리에이티브 스튜디오 — P6·P7
- 배경제거(내장) · 카드뉴스 템플릿 · 썸네일 · **GIF/짧은 모션**(Higgsfield). 의료광고 심의문구 자동삽입.
- 인물사진은 원본 정체성 유지(한국인·얼굴 보존) 규칙 적용(프로젝트 이미지 지침 준수).

### M5. 발행 오케스트레이터 — 멀티채널
- 네이버(브블/배포 계정 분리) · 티스토리(꾸다/베놈) · 인스타. 포스팅번호·링크·발행일 자동 로그(1.3 시트 대체).
- 발행 즉시 M2 트래커·M6 보고서에 연결.
- ⚠️ 네이버는 공식 발행 API 부재 → **완전 자동발행이 아니라 "원클릭 초안+서식 복사→검토 후 사람이 게시"** 반자동으로 설계(계정 정지 리스크 회피, 6.리스크 참조).

### M6. 스케줄 & 작업 자동편성 — P2·P8
- **월간 편성 생성기**: 거래처·주기(브블 주2·배포 매일 등)·마감(영수증 원고) 입력 → 한 달 작업카드 자동생성(P2).
- 업체별 색상, **작업카드 호버 요약**(주제·키워드·상태·특이사항)(P8). 구글캘린더 양방향 동기화 옵션(Make).

### M7. 대시보드 홈 — P10
- 오늘 할 일(마감·발행 예정) · **월보장 경보** · 채널 성과 스파크라인.
- **마케팅·AI 뉴스 피드**(P10): RSS/검색 수집. 2026 흐름("AI가 신뢰하는 병원=AEO/GEO", 네이버 통합검색 변화)을 매일 노출해 학습 습관화.

## 7. 자동화 시나리오 (Make + 카카오 알림톡)

## 8. 우선순위 (MoSCoW) & 3단계 로드맵

### MoSCoW
| 등급 | 항목 |
|---|---|
| **Must** | M2 노출 트래커+**월보장 모니터링/알림**(P3·P4), M3 원고 프리셋 자동생성(P1), M1 거래처 특이사항 노트(P9) |
| **Should** | M6 월간 편성 자동생성(P2)+호버요약(P8), M5 발행 로그(멀티채널), M7 대시보드 홈+뉴스피드(P10) |
| **Could** | M3 발행 서식 자동화(P5), M4 GIF(P6)·배경제거(P7), 구글캘린더 양방향 동기화 |
| **Won't(현시점)** | 네이버 **완전** 자동게시(계정 리스크), AI 완전 무검수 발행 |

### 로드맵
- **Phase 1 (2~3주) — "감시와 자동원고":** M1 특이사항 노트 → M2 트래커+월보장 알림 → M3 거래처 프리셋 원고. *가장 아픈 P3·P1·P9를 먼저 해결, 즉시 체감.*
- **Phase 2 (3~4주) — "편성과 발행":** M6 월간 편성+호버요약 → M5 멀티채널 발행 로그 → M7 대시보드+뉴스피드.
- **Phase 3 (여유 시) — "크리에이티브·꾸미기":** M3 서식 자동화 → M4 GIF·배경제거 → 캘린더 동기화.
