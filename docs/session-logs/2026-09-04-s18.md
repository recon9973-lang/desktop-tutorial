## 사장님 결정적 힌트 → 원인 확정

**«erp.seokorea.org 에서 어떻게 했는지 보라고»**

`marketing-agency-erp` 저장소 확인 (`/home/user/marketing-agency-erp/`):
- `scripts/build-region-data.py` — 원본 CSV/xlsx → 압축 JSON 변환 스크립트
- `src/server/data/region/hospital-points.json.gz` — **876KB** (심평원 79,764 병원 좌표를 컬럼형 gzip 으로)
- 데이터 형식: `{types, keys, t:[…], lat:[…], lng:[…], k:[…], n:[…]}` — 필드마다 별도 배열 · 필드명 오버헤드 없음

**이 방 잘못**: 20MB 원본 CSV 를 저장소에 통째로 커밋. ERP 는 **필요한 컬럼만 뽑아 gzip 압축** 후 커밋. 227,053행도 컬럼형 gzip 이면 5MB 이하가 될 것.
