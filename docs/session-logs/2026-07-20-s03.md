## 핵심축 1 — 키워드 발굴기 경량 MVP (완료 · #202)
s02에서 "다음 세션 최우선"으로 남겨둔 항목을 이번 세션에 구현 완료.
- 문제: 진단 '핵심 키워드' 카드가 제목추출("대구 한의원") 수준.
- 목표 달성: 실사용 키워드(대구한의원·대구북구한의원·대구교통사고한의원·대구통증치료·대구다이어트한의원) 도출.
- 신규 파일:
  - `data/regions-kr.json`: 지역계층(시·구·역). 대구 우선 + 강남·대전·부산.
  - `data/dept-modifiers.json`: 진료과별 증상·시술 사전(한의원·치과·피부과·정형외과·성형외과·내과·안과·비만[위고비·마운자로·삭센다]).
  - `lib/keyword-discover.js`: 붙여쓰기 조합 생성 + 티어 분류(대표/세부지역/증상·시술/롱테일) + 기회점수(검색량÷경쟁) 랭킹. 순수함수(node 단독 테스트).
  - `api/keyword-discover.js`: 조합→검색광고 배치(5개/호출)→자동완성 확장→검색량0 제거→분류·랭킹. 미설정/오류 시 조합 시드만이라도 노출(graceful).
  - `scripts/test-keyword-discover.js`: 회귀 24건(조합·분류·노이즈제외·랭킹·핸들러 e2e·폴백) 전부 통과.
- `index.html`: 진단 4단계를 키워드 발굴기로 교체, 티어별 키워드 카드 렌더. 지역 미입력 시 단일 키워드 폴백.

## 핵심축 2 — 종합 점수 100점 가중 모델 전환 (완료 · #203)
- 문제: 점수가 42+53+17+16+16+7=151 누적식이라 복잡·비직관.
- 해결: **100점 가중 모델**. `CAT_DEF` 가중치 content28·tech26·trust14·search12·writing10·security10 = 100. **속도(CWV)는 weight:0 별도 "+α" 게이지**(사용자 지시 "속도는 별도 + 알파").
- 카테고리 점수 = weight × (earned/rawMax). 종합 = 헤드라인 가중점수 합. improvable = 100 − total.

## 핵심축 4 — '정밀필요' → '확인 필요' 정직화 (완료 · #204)
- 문제: '정밀필요' 라벨이 애매(사용자: "결국 잘 안됐다는 뜻이자나").
- 해결: **'확인 필요'** 라벨(앰버 "!") + 설명("🔎 정적 수집으로 확인 안 됨 — 이미 있다면 PSI에서 인정, 없으면 아래 추가") + 다른 항목처럼 **수정코드 블록** 노출.
- **점수 정직화**: pending 항목을 분모(rawMax)에 0점으로 유지 → 미측정인데 100%로 부풀던 버그 수정(사용자 멘탈모델과 일치).
- seo-engine 캐시 v2.0.3 → **v2.1.1**.
