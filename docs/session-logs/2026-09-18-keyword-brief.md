사진의 「문서」·「비율」·「순위」 세 칸은 **ANSEO 가 재던 값이 아니었다.** 그대로 지어내면
제1 원칙이 깨지므로 세 가지를 여쭸고, 답을 받아 그대로 지었다.

```
문서·비율    → 「새로 재서 채운다」        (네이버 블로그 문서수 수집을 새로 만듦)
순위 T·E     → 「검색 1~10위 글이 어디에 올라온 것인지」
누적 범위    → 「화면을 보는 동안」        (브라우저 저장 안 씀)
```

## 무엇을 만들었나

### 화면 (`apps/web`)

- **`KeywordBrief.tsx` 새로 만듦** — 한 줄에 한 키워드. 키워드 · PC · 모바일 · 총합 ·
  문서 · 비율 · 순위. 머리글이 단위를 매번 적는다(「회」 / 「건」) — 검색 건수와 문서
  건수가 한 단위로 읽히는 것을 막는 자리다.
- **`LookupForm.tsx`** — 조회 결과가 덮이지 않고 **쌓인다.** 같은 키워드를 다시 조회하면
  줄이 늘지 않고 그 줄이 새 값으로 바뀐다. 「자세히 보기」·「표 비우기」·「엑셀 내려받기」.
- **`page.tsx`** — 주소로 연 지난 조회에도 간략표를 먼저 둔다. 긴 설명은 화면 머리의
  「?」(PageHelp)로 옮겼다.

### 서버 (`apps/api`)

- **`keywords/channels.py` 새로 만듦** — 주소 하나를 채널 이름으로. 모르는 host 는 억지로
  분류하지 않고 `OTHER`.
- **`keyword_documents` 새 표 + 마이그레이션 `20260917docs`** — 문서수는 검색량과 **같은
  칸에 안 넣는다**(네이버 세 가족을 갈라 둔 것과 같은 이유).
- **`service.py`** — 블로그 검색으로 문서 건수와 상위 열 자리를 잰다. **전체 20초 상한**을
  뒀다 — 없으면 키워드 20개짜리 조회에서 호출이 20번 더 붙어 화면 쪽 60초를 넘기고,
  그러면 잘 잰 검색량까지 함께 버려진다.
- **`schemas.py`** — 비율(문서 ÷ 총합)은 `CALCULATED` 로 낸다. 나누는 쪽이 없거나 0 이면
  값이 **없다** — 0 이나 무한대로 적지 않는다.
- **`export.py`** — 엑셀·CSV 에 문서 관련 7칸 추가.
