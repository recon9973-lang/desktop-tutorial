## §1. 「요금제」는 업체를 대야 한다 (오류 197)

```
GitHub   무료 + 비공개 → 「필수 검사」 기능이 **없다**   [실측 2026-09-10 · 403]
SerpAPI  Starter 월 1,000 → 한도를 올릴지               [실측 2026-09-11 · 잔여 501]
AI 다섯  무관 — 토큰 셈
```

계산도 틀려 있었다 — 구글 AI 오버뷰가 질문당 SerpAPI **2회**인데 1회로 셌다.
질문당 **3회**이므로 월 수요는 1,100~1,300 이 아니라 **1,650~1,980**.
관문 `money-says-whose` 가 대장에서 「요금제」 줄마다 업체 이름을 요구한다.

## §2. 검색 끔은 남긴다

끔을 없애도 **SerpAPI 는 1도 안 준다** — 그 몫을 쓰는 셋은 애초에 끔이 없다.
아끼는 돈은 월 $25~35 [계산]이고, 잃는 것은 「AI 가 학습한 것만으로 우리를 아는가」라는
AEO 상품의 절반이다. 처방이 갈리는 유일한 축이다.

## §3. 구글이 직접 주는 것 (조사 2026-09-10)

- **공식 AI Overview API 는 없다.** SerpApi·Apify·Scrapingdog 전부 비공식 파싱.
- Search Console 「생성형 AI 실적」 2026-08-31 전 세계 롤아웃 — **무료·공식·1차 자료**.
  그러나 **API 가 없고**(type 이 생성형 AI 값을 거절) 질의어·클릭도 없다.
  무엇보다 **자기 사이트만** 본다 → 경쟁사 언급률은 원천적으로 못 잰다.
- 결론: SerpAPI 는 **대체 대상이 아니라 유지 대상**. 우리 열쇠도 없다(B-14).

## §4. 진짜 원인 — 엔진이 아니라 **종류**였다

```
run_kind_for()   정기 체크 안 켬 → MANUAL 이라고 올바로 답한다 (시험 8건)
_persist()       그 답을 버리고 prompt_set_row.kind 를 베꼈다
PromptSet.kind   발행된 집합은 SCHEDULED 가 기본
                 → **체크를 안 켠 판까지 전부 정기로 저장**
```

2026-08-23 지시가 **함수에서는 지켜지고 행에서는 안 지켜졌다.** 함수만 시험하고
**저장된 값을 보는 시험이 없어서** 몰랐다. 그래서 AI 하나만 고른 판이 정기 집계의
자가 됐다 — 사장님이 보신 「정기 판 9/10 16:49」이 그것이다.

## §5. 전부 일곱 — 고르는 길 자체를 없앴다

사장님 오더: *「정기진단은 계약된 거래처 관리, 일반은 계약을 위해 확인 — 갯수를
줄이면 의미가 없음」*. 2026-09-10 고침은 **기본값**만 바꾸고 고르개를 남겼는데,
그 길로 돌린 판이 문제의 그 판이었다. 기술적 편의를 남겼다가 제품의 뜻을 놓쳤다.

- 서버 `engine_choices_of` 가 고른 값을 **거절**(422)
- 진단·즉석 확인 화면에서 스위치·엔진·모델·검색모드 고르개 **전부 제거**
- **호출 횟수 셈도 틀려 있었다** — 「모드 수만큼 곱한다」가 아니라 **엔진마다 다르다**
  (끌 수 있는 넷 2회 · 끌 수 없는 셋 1회 = 질문당 11칸). 실제보다 적게 셌다.
