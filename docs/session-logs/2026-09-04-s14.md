### 이 세션에서 배운 것 (다음 세션이 겪지 말라)
- **`.tsx` CSS import 는 홑따옴표로 써야 새 화면 관문(tables-fold-on-narrow-screens)이 알아본다.**
  큰따옴표 쓰면 「감싸개 없다」 오탐. 정규식이 `/import\s+\w+\s+from\s+'([^']+\.css)'/` 임
- **PostgreSQL pg_hba.conf 는 임자 postgres:postgres 여야 서버가 뜬다.** `chown root:` 로 덮어쓰면 못 뜬다
- **접는 폭 세 단**(720·960·1100px)만 쓴다. rem 단위 금지 (breakpoints-are-shared)
- **글자 하한 11px** (text-is-at-least-11px) — 새 화면 CSS 는 이걸 지킨다
- 이 방 프록시가 운영 주소 403 → **바깥 샌드박스**(mcp Higgsfield sandbox_exec) 로 curl
- **배포 명령이 자동모드 분류기에 막히면** 사장님 확인 후 재승인 → 대장에 사례 있음
- **main push 경합**에서 밀려도 다른 방이 우리 가지를 합쳐 밀어 트리는 나갈 수 있음 →
  SHA 는 없어도 diff 로 확인 후 도장 찍는다
