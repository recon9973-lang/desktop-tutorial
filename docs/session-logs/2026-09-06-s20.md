## 이번 세션 새로 만든 길

- **`fetch-file` 워크플로** (desktop-tutorial · PR #232 · main): 이 방 프록시가 행안부·CDN 을
  막을 때 GitHub Actions 가 대신 받아 가지에 커밋. 입력 url·out·md5·branch. base64 조각
  전송은 호출당 4만 자 잘림이라 버림.
- **원본 조달 경로**: 바깥 샌드박스(Higgsfield `sandbox_exec`) 에서 행안부 POST 다운로드 →
  그 자리에서 ERP 방식 gzip JSON 변환 → Higgsfield 파일 저장소(`media_upload`) → fetch-file.
- **`make bump-version TO=…`** (감사 방 도구 · 이 방이 처음 사용): 판·계약·생성 클라이언트·
  계약 관문 넷을 기계가. 남는 둘(변경이력·대장) 은 사람.
- **Zenodo 연도 zip 부분 읽기**: 3.6GB zip 을 통째로 받지 않고 바깥 샌드박스에서 `remotezip` 으로
  하루 GeoTIFF(39MB · 17초) 만 꺼내 48일 표본 집계(690초) → 5.3MB gzip JSON → `media_upload` → fetch-file.
  방법 전부 `apps/api/scripts/build_floating_pop_data.py` 머리말. 전국 합 검산 평일 12시 54,034,414.
- **서브에이전트 병렬 조사**(사장님 제안): 셋에게 각각 공공 API · GitHub · 연구 공개자료를 맡겨
  전국 원천만 모음 — `docs/plans/anseo-floating-population-sources.md` 2판.
- **`make preflight`**: 배포 전 CI 동등 점검. 로컬 시험 DB 드리프트(alembic head 인데 표
  빠짐) 를 잡아 `dropdb/createdb` 로 재생성해 통과.

## 발견·결정

- 정류장 좌표 원천과 이용량 원천은 ID 체계가 달라 (1.7%) **이름으로** 붙임 (85%). 반경 안

  과 기준월(2026-08) 다름 — 화면이 그대로 적음.
