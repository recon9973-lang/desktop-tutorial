## 관문 설계 메모
- BASELINE 방식: 관문 이전의 예외를 파일별 **개수**로 적고, 늘면 실패·줄어도 실패(숫자를 같이 내리게) — 목록이 실제와 같게.
- 접는 폭 세 단 720·960·1100px 의 근거: 720 이 가장 많이 쓰이던 값(14곳) + 960 = 상단 메뉴 접힘(60rem) + 1100 = 반쪽 PC.
- 표 관문은 파일이 부르는 클래스의 규칙 본문에서 `overflow(-x): auto|scroll` 을 찾는다. `@/` 는 src.
- 장치는 CI 에 안 넣는다(브라우저·글꼴·시간). Playwright 는 `import('playwright')` → 실패 시 `PLAYWRIGHT_MODULE`.
  이 환경: `PLAYWRIGHT_MODULE=/opt/node22/lib/node_modules/playwright`. 글꼴 폴더 `test/rwd/fonts/` 는 저장소 밖(있으면 되돌림).
