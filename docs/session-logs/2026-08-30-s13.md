## 배포 절차 (ANSEO 방에서 — 사장님 안내용)

```
cd veo-platform
git fetch origin claude/anseo-console-port
git checkout claude/anseo-console-port && git pull
git log --oneline -1        # 8cd84d4 (v0.3.390) 확인
VEO_DEPLOY_ORDER="<사장님 오더 원문>" make deploy
```
make deploy가 preflight(이상유무 전수 확인)→후보 가지 CI→main→운영 도달 확인까지 자동.
배포 후 https://veo-platform-production.up.railway.app/api/health 의 version이 0.3.390이면 끝.
