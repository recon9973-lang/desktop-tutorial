## 나간 자리

### v0.3.602 — 재 본 자리 탭·승격 (커밋 `a364d7fe`)

1. `CustomerTabs` — 거래처 · 테스트 자리 · 휴지통을 탭 한 줄로. 제목 옆 단추 셋을 거둠.
   탭마다 곳 수, **못 읽으면 «—»**(0 아님 · ADR 0002).
2. 「거래처로 올리기」 — 등록 폼이 **잰 그 주소를 채운 채** 열린다(`?url=`). 같은 주소면
   `createCompany` 의 `TAKEN` 갈래를 타 **새로 안 만들고 진단 이력째** 올라간다.
   업체명은 일부러 안 채운다 — 호스트에서 딴 이름이라 도메인이 상호로 앉는다.
3. 「마지막 진단」 칸 — `listCompanyPage` 로 읽어 거래처 목록과 같은 규칙. 200줄 한도에
   걸리면 **걸렸다고 적는다**.
4. **머리줄 실종 수정(실측 버그)** — `isCustomerScopePath` 가 `tests`·`trash` 를 거래처
   상세로 오인해 `ConsoleBar` 가 통째로 `null` 이었다. 두 화면에서 위 메뉴가 안 그려지고
   있었다. **2026-09-02(업체 등록 화면)과 같은 자리가 두 번째.** 예외를
   `CUSTOMER_LIST_SEGMENTS` 로 뽑고 시험이 `customers/` 실제 폴더와 맞댄다.

### v0.3.604 — 하루 배포 상한 해제 (커밋 `beec0eec`)

- `DEPLOY_LIMIT_PER_DAY` 기본 **2 → 0(안 셈)**. 자리는 안 없앰 —
  `VEO_DEPLOY_LIMIT_PER_DAY=2` 한 낱말이면 되걸린다.
- 세고 안 세고를 **날짜가 아니라 숫자**가 가른다. 날짜로 가르던 때는 그날이 지난 뒤
  **되걸 길이 없었다**(환경변수를 줘도 날짜 갈래에 안 들어왔다).
- `preflight.sh` 가 상한을 **`deploy.sh` 에서 읽는다.** 원천이 하나여야 안 갈린다.
- 세는 대상을 배포와 맞춤: 모든 실행 → **후보 가지의 채점**. `--limit 20` 이라 스무 건에서
  **눈금이 찼다** — 화면의 «20건» 은 «스무 건» 이 아니라 «스무 건까지 세다 말았다» 였다.
- 대장 자동 줄이 0 을 「하루 **0회**」로 적던 것 — 푼 것을 가장 센 제한으로 읽히게 한다.
  「**없음**(안 셈)」으로 적는다.

배포 기록에 그대로 찍혔다:

## 발견한 문제·결정사항

### 내가 틀렸던 것 (기록으로 남긴다)

1. **「등록 안 된 진단은 저장 안 된다」고 말했다 — 틀렸다.** BFF(`api/scan/route.ts`)가
   자동으로 자리를 만들어 **저장되고 이력도 쌓인다.** 서버(`seo/router.py`)만 보고
   화면 쪽을 안 봤다. 그 오해로 고치려던 문구는 **거짓이었고, 커밋 전에 되돌렸다.**
2. **판 번호를 미리 잡았다** — 변경이력·`__init__.py`·대기 표가 어긋나 `claim_version` 이
   「이미 그 번호를 쓰는 항목이 있다」로 [1/4] 에서 섰다.
3. **`git add -A` 로 충돌 자국을 커밋에 담았다** — `docs/DEPLOY-ORDER-LOG.md` 에
   `<<<<<<<` 가 딸려 들어갔다. 점검 ⑥이 잡아 안 나갔다.
4. **내가 쓴 시험이 내 주석을 코드로 세어 우연히 통과했다** — 상한 시험이 주석에 인용해 둔
   옛 문구(«다시 정하십시오»)로 초록이 됐다. 주석을 걷어내고 재게 고쳤다(`_without_notes`).
