## 발견·결정
- **egress**: 작업 컨테이너는 vercel.app 라이브 접근이 프록시 정책으로 차단(403) → 라이브 확인 불가. 소스 기준 Playwright + `index.html` no-cache(새로고침 즉시 반영)로 우회 검증.
- **캐시**: GEO 도구 변경은 `index.html`(no-cache)이라 `?v=` 불필요. seo-engine.js 변경 시에만 `?v=` 올림(현재 v2.1.8).
- **실측 소스 일관성**: GEO 실측 파트와 관리자 AI 매트릭스가 동일 `_INSIGHTS?type=aeo&engine=` 경로 사용 → 두 곳 수치 정합.
