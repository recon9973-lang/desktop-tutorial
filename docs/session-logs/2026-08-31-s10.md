## 결정·판단 기록

- Lovable 스택(TanStack+Tailwind) → 실물(Next+CSS Modules+--veo- 토큰) **번역 이식**.
  시안 점선(사분면 십자·스파크 천장)은 사장님 «실선» 확정 우선으로 실선.
- StageFlow 단계 분류는 검사가 아니라 **명세 범주 단위**(SEO s1_blocked·연동→1 /
  identity·meaning·compete·click·hygiene·offpage→2 / observability→4; GEO access→1 /
  entity·sd·freshness→2 / extract·evidence·verifiability→3). 명세 밖 검사는 None
  («분류 없음» 줄 — 지어 붙이지 않음). 새 범주는 커버 관문이 잡음.
- 실행 큐의 상승폭·품·담당·기한 열은 실물에 측정이 없어 **싣지 않음**(산정은 별도 판).
- S1 잔여: 커버리지 와플(⑩ — «측정 N장/수집 N장» 서버 집계 필요), 실행 큐 gain 산정.
- S3 잔여 충돌 1건 보고 대상: 시안 KPI 4장 펼침 vs 사장님 확정 «요약은 ?표시로 접기».
- 발행본 도달 예상(goalEta)은 **발행 불변**으로 제외 — 예측을 굳힌 문서에 넣지 않음.
