## 1. 무엇이 새고 있었나

이 제품에는 경계가 **둘**이다.

- **조직 경계**(대행사끼리) — 구조가 튼튼했고 **한 군데도 안 샜다.**
- **거래처 경계**(같은 대행사 안에서 병원끼리) — **넷이 샜다.**

걸리는 계정은 `CLIENT_VIEWER` 하나만 가진 것, 곧 **병원이 직접 쓰는 포털 계정**이다.

| 자리 | 샌 것 |
| --- | --- |
| 키워드 창구 다섯 | 같은 대행사의 **다른 병원 키워드** |
| 인용 사이트 집계 | 어느 매체가 어느 병원을 인용했는지 통째로 |
| 진단 회차 셋 | `scan_run_id` 를 둘째 벽이 안 풀어 **남의 회차** |
| 실험 지출 | 대행사의 **이번 달 AI 지출 총액** |

**뿌리는 둘.** ① `tenant_select` 가 거래처 칸 없는 표를 만나면 **말없이 통과**시켰다
→ 이제 **선다**(`TenantIsolationError`). 못 좁히는 표는 **왜 그래도 안전한지**를
표에 적어야 통과한다. ② 둘째 벽이 `scan_run_id` 를 몰랐다 → `Scan.project_id` 로 푼다.

**robots 되짚기** — 별 11개에 **18.314초**(CPU 한 코어, GIL 안 놓음). 정규식을 없애고
선형 훑기로. 옛 구현과 **2,981,704 짝**(규칙 2,728 × 경로 1,093)을 통째 대조해 같음 확인.

**관문 둘이 한 자리만 보고 초록불** — 비밀키 관문은 파일 하나만, 신원 관문은 손으로
적은 목록만 봤다. 각각 `APIRouter` 든 파일 30개 전부 / `create_app()` 이 실제로 매단
창구를 반영으로 캐도록.

## 2. 사장님이 정하신 것 — 실험 금액은 최고관리자만

| 누구 | 보는 것 |
| --- | --- |
| 최고관리자 | 금액 전부 |
| 실험 돌리는 사람(분석가) | 금액 없음. 「한도에 걸렸다」는 사실만 |
| 병원 포털 | 아무것도 — `monthly_spend` 를 부르지도 않는다 |

가운데를 남긴 까닭: **분석가가 실제로 실험을 돌린다.** 이유까지 지우면 버튼이 말없이
실패하고 화면이 이유를 지어낸다. 못 보는 사람에겐 `0` 이 아니라 **`null`** —
`0` 은 「한 푼도 안 썼다」는 거짓말이다. **진짜 0원이면 줄이 보인다**(시험이 구별을 잰다).

## 5. 내가 틀린 것 · 배운 것

1. **검증이 얕았다.** 첫 검증에 `pnpm -r typecheck` 가 빠져 형 어긋남 둘을 놓쳤다
   (화면 시험의 부품 입력 · 금액 형이 `null` 을 못 받던 것). **`vitest` 도
   `next build` 도 시험 파일의 형은 안 본다 — `tsc` 만 본다.** 배포 전 점검이 잡았고,
   그 사이 다른 방이 같은 자리를 똑같이 고쳐 뒀다(`c762d638`).
2. **내 관문이 처음엔 헐거웠다.** `Evidence` 를 허용표에서 빼도 아무 시험이 안 깨졌다.
   코드를 훑어 대조하는 관문을 더 넣어 잡히게 고쳤다.
3. **보고서에서 두 번 틀렸다.** 「robots 은 무인증으로 부를 수 있다」(→ 공개면이
   기본 꺼짐이라 인증된 대행사 계정) · 「`geo/robots.py` 의 매칭을 재사용하면 된다」
   (→ 첫 별에서만 갈라 `/a*b*c` 를 틀리게 답한다).
4. **사장님이 «무슨 말인지 모르겠네» 하셨다.** A/B 표에 전문 용어를 얹어 드렸다.
   **선택지 나열 말고 추천 하나를 평범한 말로** 드린다 — 이 방의 상시 규칙.
5. **가지에 남기면 안 되는 것이 있다.** 내가 대기 표에 넣은 줄을 main 이 이미
   지웠는데 가지에 남겨 두면 나중에 합칠 때 **되살아난다.** 걷어냈다.
6. **힘으로 미는 것은 관문이 막는다.** 이력을 지우는 대신 **합쳐서** 같은 결과를 냈다.
