### 4. 오더 4 → 파일 올리기 화면 폭발 원인 확정 · v0.3.500 배포

**진단** (사장님 파일 A `984836b2-...20251031.csv` 20MB 로컬 시험):
- 파일도 서버 로더도 정상 (넣음 227,053행 · 뺌 12행 성공)
- 원인 = **Next.js 서버 액션 request body 상한이 기본 1MB** 인데 파일은 20MB → 서버 액션 도달 전에 프론트가 throw → React error boundary 가 「화면을 표시하지 못했습니다」

**고침**:
- `next.config.ts` 에 `experimental.serverActions.bodySizeLimit: '50mb'` (백엔드 상한과 맞춤)
