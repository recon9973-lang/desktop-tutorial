## 만든 것 (ANSEO · 판 0.3.626)

```
화면   「상권」 탭 «지도 첫 페이지» 줄 — 대표 키워드 1개로 지도 셋 순위 · 1페이지 열 곳
```

**정한 것**(다시 묻지 않는다)
- **주소는 후보를 만드는 데만 쓴다.** 주소만으로는 「마산」이 안 나온다 — 통합시(창원시
  마산회원구)일 때만 구 어간 앞 두 글자를 후보로 더 낸다. 「동대문구」에는 안 쓴다.
- **고르는 것은 사람.** 검색수를 하나도 못 쟀으면 추천하지 않는다.
- **아홉 자리에서 잰다**(중심+여덟 방위). 한 자리로 상권을 말하지 않는다.
- **못 잰 자리도 줄로 남긴다.** 빼면 분모가 줄어 성적이 조용히 좋아진다.
- 이름이 비슷하기만 하면 `AMBIGUOUS` — 순위로 안 센다([실측] 온담한의원 → 1위가 백세온담한의원).
