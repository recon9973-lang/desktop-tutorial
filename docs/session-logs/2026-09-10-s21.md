## §1. 숫자가 달랐던 진짜 까닭 — 화면 탓이 아니었다

겉보기 차이는 네 겹(재는 값·분모·범위·출처)이었지만, 그 밑에 **결함**이 있었다.

```
엔진 고르는 자리가 둘이었다
  정기 진단  schedule.py 의 configured_engines  → 설정에 적힌 전부(일곱)
  수동 진단  폼이 보낸 engine (단수)            → 기본 ChatGPT 하나
판 종류(정기/일회)는 체크박스에서 따로 왔다
  → 「AI 하나만 물은 **정기 판**」이 만들어질 수 있었다
```

그렇게 쌓인 판이 주간·월간 합산에 **분모 구분 없이** 섞였다.

## §2. 모든 숫자가 제 범위를 말한다 (v0.3.559)

`visibility-scope.ts` 하나로 통일 — 한 판이면 「9/9 12:24 정기 판」, 여러 판이면
「이번 주 합산 · 9/2~9/8 · 판 3개」. 진단 탭 도장도 정직해졌다: 「이 판이 부른 AI n종 ·
그중 n종만 답했습니다 · ○○는 이 판에서 안 물었습니다」. 관문 11건.

## §3. 정기든 일회성이든 **일곱을 다 부른다** (v0.3.559)

- 서버 `engine_choices_of()` — 안 고르면 **설정의 전부**를 쓴다.
- 「정기인데 엔진 지정」은 **422 로 거절**한다.
- 폼에서 엔진 하나만 고르는 길은 「즉석 확인」으로만 남기고 기본은 일곱.
- 관문 6건(`test_engines_default_to_all.py`)이 **두 길을 맞대 본다**.

**왜 시험이 못 잡았나.** 정기 길 시험은 정기 길만, 수동 길 시험은 수동 길만 봤다.
각각 제 안에서 옳으니 전부 초록이었다. 2026-08-24 에 같은 종류를 한 번 지적받고
세운 관문(`test_an_engine_never_drops_out_silently.py`)조차 **정기 길만** 봤다.

## §4. 「미완료 조사 → 순서대로」

1. **잔여 경고가 사라질 뻔했다** — 일곱을 부르게 한 바로 그날. 잔여를 「고른 엔진 하나」로만
   찾고 있었는데, 안 고르면 그 자리가 목록 첫째(중개를 안 쓰는 엔진)로 남는다. 고침.
2. **합산이 섞인 것을 말한다** — 주간·월간이 엔진 구성이 갈린 판을 더하면 그렇게 적는다.
3. **`gh` 없는 방** — 배포 [3/4]에서 죽던 것(오류 127)을 REST 흉내로 고침(`gh_fallback.sh`).
4. **CI 필수검사** — 사장님께 한 달 넘게 올려 뒀던 부탁이 **애초에 불가능**이었다(§5).

## §5. 돈 이야기 — 업체를 대야 한다

| 업체 | 무엇이 걸리나 | 성격 | 실측 |
|---|---|---|---|
| GitHub | 무료 + 비공개라 「필수 검사」 기능이 **없다** | 사야 생기는 기능 | 2026-09-10 · 403 |
| SerpAPI | 월 한도를 얼마로 둘지 | 이미 세팅하신 것 | 2026-09-02 · Starter 월 1,000 |
| AI 다섯 | **무관** | 토큰 셈 | — |

**계산도 틀려 있었다** — 구글 AI 오버뷰가 질문당 SerpAPI **2회**(1차 검색 + 2차 요약)인데
1회로 셌다. 네이버 1회를 더해 **질문당 3회**이므로 월 수요는 1,100~1,300 이 아니라
**1,650~1,980**. 게다가 v0.3.559 로 모든 판이 일곱을 부르므로 수요가 여기까지 올라온다.

**더 나쁜 것.** `scripts/deploy.sh` 머리말이 **2026-08-04 에 이미 그 403 을 적어 뒀는데도**
대장 §5 와 `RESUME.md` 는 한 달 넘게 「Settings → Branches 에서 지정하십시오」를
사장님 몫으로 올려 뒀다. **못 하는 일인 줄 알면서 시킨 셈이다.**

**관문.** `money-says-whose.test.ts` — 대장에서 「요금제·플랜」을 말하는 줄마다 **업체 이름이
같은 줄에** 있어야 통과. 세우자마자 세 줄이 걸려 GitHub·Neon·GitHub 으로 고쳤다.

**사장님 결론(15번 답).** GitHub 구독 **안 하셔도 된다** — `make deploy` 가 이미 CI 초록불에서만

(`veo.seokorea.org/console/dashboard` 맨 아래 「사용량 · 한도 — 관측 창구」 첫 줄).
