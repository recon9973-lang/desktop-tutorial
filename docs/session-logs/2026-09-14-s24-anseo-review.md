## 내가 틀린 것 (여섯)

1. **검수 권고가 틀렸다 — 「같은 모양」으로 묶은 셋의 책임이 달랐다.** 구조화 데이터
   필수 속성을 해당 없음으로 옮기라고 적었는데 `AmusementPark` 가 그 권고를 깬다
   (리치 결과 목록엔 없어도 `LocalBusiness` 하위 타입). **판정은 두고 사유만 고쳤다.**
2. **「GEO 에 관문이 없다」가 아니었다.** 띠는 넷 있고 **곱셈이 없었다** — 그 파일에
   `# Gates never change the numeric score` 라고 적혀 있었다.
3. **「`is_gate: true` 한 줄」 권고대로 하면 사고가 난다.** 관문 산식이 **심각도를 안 본다**
   — `content_visible_without_js`(MAJOR) 하나로 JS 사이트가 0 점이 된다. 띠를 올리는 넷만 담았다.
4. **`git add -A` 로 선 배포의 부분 판 물림을 커밋에 쓸어담았다.** 판은 나갈 때 물린다.
   되돌리고 커밋을 고쳐 썼다(원격 전이었다).
5. **`ls | tail` 의 사전순에 속아 1.9.2 를 최신으로 착각**하고(실제 1.12.0) 그걸 베껴
   **이미 발행된 `1.10.0.yaml` 을 덮어썼다.** 발행본은 불변(ADR 0012). git 에서 되돌렸고
   커밋 전에 잡았다. 판 목록은 `available_specs()` 로 본다.
6. **전후 비교를 두 열 모두 새 수집기로 돌려 차이가 0 으로 나왔다.** 산식을 바꾼 것은
   명세가 아니라 수집기다 — 수집기를 갈아서 다시 쟀다.

## 표에서 손대려다 멈춘 것

**조치 문구(「연결하면 잴 수 있다」)** — 문구만 고칠 자리가 아니다. 문구가 명세의
`availability` 별로 정해지고 값이 셋뿐이라, 네이버처럼 **열쇠를 받아도 못 재는** 자리를
가리킬 이름이 없다. `ProviderState.NOT_AVAILABLE` 이 그 사실을 알지만 `CheckOutcome` 이
싣고 다니지 않아 평가기가 못 본다. 명세 개정이거나 계약 개정 — 판을 올리는 일이다.

**`previous_indexed`** — 더 앞에서 막혀 있다. 서치콘솔 자료를 진단 맥락에 넣는 곳이
**아무 데도 없다**(`search_console_payload`·`search_console_for` 가 자기 모듈 밖에서
불리지 않는다). 지난 수치를 이어도 달라지는 것이 없다.
