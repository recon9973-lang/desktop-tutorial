```
apis.data.go.kr  살아 있음    api.odcloud.kr  살아 있음
www.data.go.kr   200 ← 포털 화면이 열린다(2026-09-18 기록과 다르다)
kosis.kr 200 · sgisapi.kostat.go.kr 200
```

포털이 답을 셋으로 가른다 — **이 구분이 핵심이다.**
`-3 등록되지 않은 서비스` = 주소가 틀렸다(내 일) ·
`-4 등록되지 않은 인증키` = 주소는 맞고 활용신청이 안 됐다(사장님 일) · `200` = 받아진다.
