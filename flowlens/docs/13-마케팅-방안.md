# FlowLens 마케팅 방안 (v1 · 2026-07-19)

운영사 주식회사 베놈(병원마케팅 대행사)의 강점을 살린 실행 중심 계획.

---

## 0. 한 줄 전략
> **"베놈이 직접 써서 만든 사례로, 동료 대행사와 병원에 파는 개인정보 안전한 한국형 히트맵."**

작은 회사·저예산이므로 **유료광고보다 도그푸딩 → 사례 → 직접영업 → 콘텐츠(SEO/AI검색)** 순으로 간다.

---

## 1. 타깃 & 포지셔닝
- **1차 타깃**: 마케팅 대행사(특히 병원·의료 대행사 — 베놈의 네트워크). 화이트라벨로 자기 브랜드 리포트를 고객에 제공.
- **2차 타깃**: 중소 쇼핑몰·병원·랜딩 운영자(직접 가입).
- **포지셔닝 문장**: "고객사 사이트에 한 줄 설치 → 방문자 행동을 한국어 리포트로. 개인정보는 안 모으고, 대행사 브랜드로 공유."

## 2. 경쟁사 대비 차별점 (세일즈 포인트)
| 항목 | Microsoft Clarity | Hotjar | 뷰저블(Beusable) | **FlowLens** |
|---|---|---|---|---|
| 가격 | 무료 | 비쌈($) | 비쌈(국산) | **무료~합리적(19,800~88,000)** |
| 언어·리포트 | 영어 중심 | 영어 중심 | 한국어 | **한국어 + 자동 개선과제** |
| 개인정보 | 데이터 해외·불안 | 해외 | 국내 | **개인정보 미수집 설계 + DPA·사전동의·국외이전 문서 완비** |
| 대행사용 | 약함 | 약함 | 약함 | **화이트라벨·공유링크·다중 사이트** |
> ★ 방금 갖춘 **개인정보 3종(방침·DPA·사전동의)**이 병원 등 민감업종 영업에서 그대로 무기가 된다. 경쟁사가 못 내세우는 지점.

## 3. Go-To-Market 단계
### 단계 A (0→1, 지금 1~2개월): 도그푸딩 + 사례 3개
- 베놈 **자사 랜딩·사이트**에 FlowLens 설치 → "히트맵으로 CTA 위치 바꿔 전환 X% 개선" 자체 사례.
- **병원 고객 2곳**에 설치(동의 하에) → 개선 전후 리포트 = 실제 사례.
- 사례를 랜딩 "고객 사례" 섹션 + 영업자료(PDF)로.

### 단계 B (1→10, 2~4개월): 동료 대행사 직접 소개
- 베놈 네트워크의 대행사에 **1:1 소개**(화이트라벨·공유링크 강조 — "고객에게 당신 브랜드로 리포트 제공").
- 제안: 첫 3개월 할인 또는 에이전시 요금 체험.

### 단계 C (병행·상시): 콘텐츠·SEO·AI검색(GEO)
- 키워드: "히트맵", "전환율 개선", "웹 행동분석", "이탈률 줄이기", "병원 홈페이지 개선".
- 블로그/가이드 → 구글·네이버 SEO + ChatGPT/Perplexity 인용(GEO). (사내 `ai-content-writer`·`seo-audit` 스킬로 표준 생산 가능)
- **무료 진단 도구(랜딩)를 리드 마그넷**으로: "내 사이트 주소 넣으면 무료 히트맵 데모" → 가입 유도.

### 단계 D (검증 후): 유료 광고
- 사례·전환율이 검증되면 네이버 검색광고·메타 리타겟팅 소액 테스트. (그 전엔 지출 최소화)

## 4. 채널별 실행 요약
- **랜딩(flow.seokorea.org)**: 무료진단 훅 + 사례 섹션 추가(단계 A 후).
- **직접영업**: 대행사·병원 대상 1:1 데모 + 영업 PDF.
- **콘텐츠**: 월 2~4편 심층글(SEO/GEO), 무료진단 CTA 삽입.
- **레퍼럴**: 대행사가 소개 시 인센티브(요금 할인) — 화이트라벨 특성상 확산 유리.

## 5. 가격·전환 퍼널
```
무료진단(가입 전) → 무료체험 14일 → 그로우 19,800 → 에이전시 88,000
```
- 전환 유도: 체험 만료 알림, 사례 기반 ROI 메시지("월 2만원으로 전환 X% 개선").
- 대행사는 에이전시 요금(30사이트)로 다수 고객 커버 → 객단가↑.

## 6. 핵심 지표(KPI)
- 무료 가입 수 / 주
- **무료 진단 → 가입 전환율**
- **설치 완료율**(가입 후 실제 스크립트 설치까지)
- 무료체험 → 유료 전환율
- 사이트당 월 세션(활성도), 이탈(해지)율

## 7. 지금 당장 할 3가지 (우선순위)
1. **베놈 자사 사이트에 FlowLens 설치** → 2주 뒤 첫 사례 데이터 확보.
2. **랜딩에 "고객 사례" 자리 + 무료진단 CTA 강화**(사례 나오면 채움).
3. **콘텐츠 1편 발행**("히트맵으로 전환율 올리는 법" 등) — SEO/GEO 리드 유입 시작.

## 8. 블로그 콘텐츠 운영 (2026-07-19~)
- **채널**: FlowLens `/blog`(Next.js, `content/blog/*.md` + 동명 `.jsonld`). 첫 글: "히트맵으로 홈페이지 전환율 올리는 법".
- **콘텐츠 원칙(사용자 지정)**: 매 글에 **① FlowLens 사용법 + ② 매출(전환) 올리는 법을 섞는다.** 순수 이론이 아니라 "이렇게 FlowLens로 보고 → 이렇게 고쳐 매출을 올린다"의 실전 흐름.
- **작성 스킬**: `ai-content-writer`(E-E-A-T·GEO·FAQ·JSON-LD). 과장 수치·가짜 사례 금지(실측 전까지 "예시/흔한 패턴"으로 표기).
- **다음 글 후보**: 스크롤맵으로 첫 화면 개선해 이탈 줄이기 / 병원 홈페이지 전환 점검(의료광고법 유의) / 장바구니 이탈 줄이기.

### SEO 엔진(구현 완료 2026-07-19)
- **기술 SEO**: `app/sitemap.ts`(공개페이지+글 자동), `app/robots.ts`(비공개경로 차단+sitemap 선언), `metadataBase`+글별 canonical/OpenGraph, `app/icon.svg` 파비콘.
- **구조화데이터**: 글마다 Article+FAQPage JSON-LD(sidecar `.jsonld`), 발행자 Organization에 sameAs(카카오채널)·contactPoint.
- **내부링크**: 관련 글 자동(`getRelatedPosts`, 카테고리·키워드 기준) + 본문 상호링크. **외부 출처**: 권위 도메인(nngroup·Google) 인용(새 탭).
- **검증**: `venom-wordpress/preview/seo/seo-engine.js`로 채점 시 E-E-A-T 16/16. **주의**: Next.js **dev 서버 HTML은 엔진이 SPA로 오판(renderSuspect)**해 title·메타·canonical 등이 거짓 "보류"로 뜬다(실제 HTML엔 존재). **정확한 점수는 배포(production) HTML 또는 PSI로 재측정**할 것.
