## 1. 한 줄 요약

**FlowLens** — 웹사이트 방문자의 클릭·마우스이동·스크롤을 분석해 **무엇을 고쳐야 하는지** 알려주는 행동 분석 SaaS.
**대행사(에이전시)가 여러 고객사를 관리**하는 구조. 개인정보(IP·입력값)를 수집하지 않는 것이 설계 원칙.

## 3. 기능 구성

### 대시보드 (대행사)
- **개요** — 세션·이탈률·모바일 비중·전환
- **히트맵 (5종)** — 클릭맵 / 무브맵 / 셀렉터 / 스크롤맵 / 제스처
  - 배경 = **실제 사이트 화면**(기기별 자동 캡처), 기간 필터(전체/7/30/90일)
  - 진하기 슬라이더 · 집중(딤) 모드
- **퍼널 · 세션 리플레이 · 전후 비교 · 개선 제안 · 설치/공유 · 데이터 관리**

### 랜딩 (잠재고객)
- **무료 진단** — URL 입력 → 페이지 점검 + **실제 화면 위 데모 히트맵** + **플랫폼 자동 감지**

### 시각화 규칙 (리서치 근거: Clarity/Hotjar/Crazy Egg)
- **클릭맵 = 컬러** 열지도 (파랑→초록→노랑→빨강)
- **무브맵 = 블랙** 궤적(곡선) + 체류 점
- 배경은 **원색 유지** (블러·무채색 안 씀), 가독성은 **오버레이 투명도**로 조절

## 5. ⚠️ 반드시 알아야 할 함정 (하드코딩된 교훈)

이 프로젝트에서 **실제로 사고가 났던** 것들. 잊으면 또 당합니다.

### ① GTM은 `data-site` 속성을 지운다
GTM 맞춤HTML로 넣으면 `data-*` 속성이 **제거**되어 추적이 조용히 실패.
→ **GTM에서는 반드시 `?site=KEY`** 형태를 쓸 것. (`t.js`는 data-site / `window.FLOWLENS_SITE` / `?site=` 3경로 지원)

### ② 사이트에 실제 붙어있는 GTM 컨테이너를 확인할 것
good-tour.kr은 `GTM-PVL5HQDD`가 아니라 **`GTM-NGPZ4BF2`** 였음. 엉뚱한 컨테이너에 넣으면 아무 일도 안 일어남.
→ 확인법: 페이지 소스에서 `GTM-` 검색.

### ③ Vercel 함수 기본 리전은 미국(iad1)
DB가 싱가포르인데 함수가 미국이면 **요청마다 태평양 왕복** → 704ms.
→ `vercel.json`에 **`"regions": ["sin1"]`** 지정 → **121ms (6배 개선)**.
→ 진단법: `x-vercel-id` 가 `엣지::함수리전::id` 형식 (`icn1::sin1::...`).

### ④ 마우스 이동을 낱개 이벤트로 저장하면 적자
90ms 샘플링 = 세션당 400건 → **세션당 150KB** → 에이전시 30곳이면 **월 $400**.
→ **세션·페이지별 "경로 1줄"**(`MovePath`, `"x,y|x,y|…"`)로 저장 → **8KB (19배↓)**, 월 $10.

### ⑤ `prisma db push`가 파괴적 변경을 요구할 때 `--accept-data-loss`를 쓰지 말 것
unique 인덱스 변경·추가 시 발생. 그 플래그를 빌드에 넣으면 **이후 모든 배포에서 데이터가 조용히 날아갈 수 있음**.
→ **Neon SQL로 수동 실행** 후 배포(그러면 db push가 in-sync로 통과). 전례:
```sql
-- Screenshot에 device 추가 시 실제로 사용한 SQL
ALTER TABLE "Screenshot" ADD COLUMN IF NOT EXISTS "device" TEXT NOT NULL DEFAULT 'DESKTOP';
DROP INDEX IF EXISTS "Screenshot_siteId_path_key";
CREATE UNIQUE INDEX IF NOT EXISTS "Screenshot_siteId_path_device_key" ON "Screenshot"("siteId","path","device");
```

### ⑥ 일부 한국 사이트는 해외 IP의 일반 fetch를 WAF로 차단
good-tour.kr은 우리 서버(싱가포르)의 `fetch`에 **빈 페이지를 200으로** 반환 → 진단이 "분석도구 없음·33점"이라는 **틀린 결과**를 냄.
(헤드리스 크롬은 통과, 일반 fetch는 UA를 바꿔도 차단 — TLS 지문 차이 추정)
→ **틀린 점수 대신 정직한 실패**로 처리 중.

### ⑦ Prisma `Bytes`는 `Uint8Array<ArrayBuffer>` 요구
`Buffer`를 그대로 넣으면 TS 에러 → `Uint8Array.from(buf)`.

### ⑧ 캐시된 이미지는 `onLoad`가 안 뜬다
기기 전환 시 배경 비율이 갱신 안 돼 **이미지 아래 빈 스크롤**이 생김.
→ `useEffect([bgUrl])`에서 `img.complete`면 `naturalWidth/Height`를 직접 읽어 재계산.

### ⑨ `meta` 필드는 300자로 잘린다
보안상 allowlist + 길이 제한. 큰 데이터(좌표 경로 등)는 **전용 컬럼/테이블**로.

## 6. 2026-07-17 세션 작업 내역

### 저장·비용
- **마우스 이동 저장 구조 최적화** — 세션당 150KB → **8KB** (`MovePath` 모델). 적자 → 흑자.
- **스크린샷 WebP 전환** — 1,786KB → **309KB** (5.8배↓)
- **롤업(집계 스냅샷)** — 보관기간 지난 원시데이터를 격자 카운트로 압축 후 삭제. 히트맵은 계속 표시됨.

### 성능
- **함수 리전 sin1 이동** — DB 조회 704ms → **121ms**

### 기능
- 히트맵 **실제 화면 배경**(기기별 자동 캡처) · 진하기 · 집중모드
- **무브맵** 신규 (블랙 궤적 + 곡선 보간)
- **전후비교 시각화**, **세션 리플레이 실제 화면**
- **기간 필터**, **사이트 등록 UI**(없었음), **비밀번호 변경**
- **플랫폼 자동 감지** (워드프레스/카페24/아임웹/윅스 등) → 전용 설치 안내

### 사업
- **요금제 확정 + 코드에 제한 전면 구현**
- 수익성 분석 (`07-수익성-분석.md`), 설치 매뉴얼 (`06-설치-매뉴얼.md`)

### 보안 (감사 후 수정)
| 발견 | 조치 |
|---|---|
| 🔴 **결제 우회** — 누구나 `plan=AGENCY` 전송으로 전 기능 무단 사용 | 유료 전환 차단(다운그레이드만 셀프) |
| 🔴 **히트맵 무단 열람** — 공개된 siteKey만으로 `/api/overlay` 조회 가능 | 인증 필수 + 본인 대행사 사이트만 |

## 8. 개발 참고

```bash
cd flowlens
npm run dev          # 로컬 (SQLite, http://localhost:4311)
npm run build        # 배포 전 반드시 확인
npx vercel@latest --prod   # 배포 (vercel-build가 sqlite→postgres 전환 + db push)
node scripts/cleanup.mjs   # 보관기간 초과분 롤업+삭제 (크론이 할 일)
```

- **로컬은 SQLite / 운영은 Postgres** — `vercel-build`가 sed로 provider 전환
- 스키마 변경 시 파괴적 경고가 뜨면 → **위 5-⑤** 방식으로
- 문서: `docs/01~08`
