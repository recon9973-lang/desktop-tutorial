## 1. 사업 개요

FlowLens는 웹사이트 운영자(특히 **마케팅 대행사** 및 중소 쇼핑몰·병원/상담·랜딩페이지 사업자)가 자신 또는 고객사의 웹사이트에 **추적 스크립트 한 줄**을 설치하면, 방문자의 클릭·스크롤·체류·좌절클릭·모바일 제스처 등 **행동 데이터**를 수집·분석하여 히트맵·리포트·개선 제안을 제공하는 **월 구독형(SaaS) 도구**입니다.

- 핵심 가치: "방문자가 어디서 망설이고 이탈하는지"를 시각화하고 개선 과제를 한국어로 제안.
- 개인 식별이 목적이 아니며, **개인정보 최소 수집**을 설계 원칙으로 합니다.
- 유사 서비스: Microsoft Clarity, Hotjar, Mouseflow, 뷰저블(Beusable), Amplitude 등.

### 사업 모델
- 요금제: Free(무료) / Starter / Growth / Pro / Agency (월 구독).
- 결제: **토스페이먼츠(PG) 연동** 예정. 카드정보는 PG가 처리하며 FlowLens는 카드번호를 저장하지 않음.

## 2. 데이터 주체(정보주체)는 두 종류입니다 — **구분이 핵심**

| 구분 | 대상 | 관계 |
|---|---|---|
| **가) 서비스 회원** | FlowLens에 가입한 대행사/사업자(직접 계약자) | FlowLens와 직접 계약 |
| **나) 방문자** | 회원(또는 그 고객사)의 **웹사이트를 방문한 일반 이용자** | FlowLens와 직접 관계 없음, 웹사이트 운영자를 통해 데이터 발생 |

> 법적으로 가장 중요한 쟁점: **나) 방문자 행동 데이터**에 대해 FlowLens가 "수탁처리자"인지, "제3자 제공받는 자"인지, 동의 획득 의무가 누구에게 있는지입니다. (→ 6장·9장 참고)

## 3. 수집하는 데이터 (정확한 목록)

### 가) 서비스 회원(가입 사업자)
- 이메일, 이름, 대행사/회사명
- 비밀번호: **평문 미저장**, scrypt 해시(salt 포함)로만 저장
- 요금제, 가입일시
- 로그인 세션: 서명된 쿠키(HMAC, 사용자 ID 서명값). 별도 추적 아님.
- 결제정보: **토스페이먼츠가 처리**. FlowLens 서버는 카드번호·유효기간 등을 저장하지 않음(결제 승인 결과의 주문번호·금액·승인시각 정도만).

### 나) 웹사이트 방문자(행동 데이터)
수집 이벤트 종류: `page_view, click, rage_click(좌절클릭), dead_click(무반응클릭), scroll, pointer_sample(마우스 이동 샘플), form_focus, form_submit, cta_view, cta_click, conversion, session_end, double_tap, zoom, swipe`

각 이벤트에 저장되는 필드:
- 이벤트 종류, 페이지 URL·경로
- **좌표: 문서 대비 상대값(0~1)** — 절대 픽셀 미저장
- 뷰포트 크기(가로/세로 px), 스크롤 도달률(%)
- 클릭 대상 라벨(`targetLabel`): 버튼/링크의 짧은 텍스트 — **전송 전 마스킹 처리**(아래)
- 제스처 방향(줌 in/out, 스와이프 상하좌우) 등 부가정보(JSON)
- 발생 시각

세션 단위 정보:
- 세션키: 브라우저 `sessionStorage`에 저장되는 **임의 난수**(30분 무활동 시 만료). 개인 식별자 아님, 쿠키 기반 크로스사이트 추적 아님.
- 디바이스 종류(모바일/데스크톱/태블릿), 유입 경로 대략 분류(직접/검색/광고/소셜/추천), 최대 스크롤 도달률, 페이지 수, 이탈 여부

### ★ 수집하지 **않는** 데이터 (설계상 원천 차단)
- **폼 입력값**(이름·전화·이메일·주소 등)과 **비밀번호**: 코드 경로에 존재하지 않음(value에 접근하지 않음)
- **원본 IP 주소**: 저장하지 않음
- **절대 픽셀 좌표**: 상대값(0~1)만 저장
- **화면 녹화/DOM 스냅샷**: 세션 "리플레이"는 DOM을 녹화하지 않고 수집된 이벤트를 시간순 재생하는 방식 → 화면에 표시된 개인정보가 캡처되지 않음

### ★ 민감정보 자동 마스킹
클릭 대상 라벨 등 텍스트에 대해 **전송 전(클라이언트)** 정규식으로 이메일·전화번호·카드번호·주민등록번호 패턴을 `***`로 치환. 비밀번호 입력 영역 근처의 이벤트는 좌표·라벨 모두 미수집.

### ★ 봇 제외
`navigator.webdriver`가 감지되면 수집 중단.

## 4. 데이터 처리 흐름

1. 웹사이트 운영자가 자신/고객사 사이트에 추적 스크립트(`t.js`)를 설치(HTML 삽입 또는 워드프레스 플러그인 등).
2. 방문자가 페이지를 이용하면 스크립트가 이벤트를 모아 주기적으로 FlowLens 수집 서버(`/api/collect`)로 전송(HTTPS).
3. 서버가 사이트 식별키(siteKey)로 사이트를 확인하고 이벤트를 데이터베이스에 저장.
4. 회원(대행사)이 대시보드에서 히트맵·리포트·개선 제안을 조회.
5. 회원은 **읽기 전용 공유 링크**(토큰 기반, 로그인 불필요)를 생성해 고객에게 리포트를 공유할 수 있음. 공유 리포트에는 **집계 지표와 개선 제안만** 표시(개별 개인정보 없음).

## 6. 위탁·제3자 제공·국외 이전

- **클라우드 인프라**: [ ] (예: 국내/해외 클라우드) — 데이터 저장 위탁. 해외 리전 사용 시 **국외 이전** 이슈.
- **결제대행**: 토스페이먼츠(결제정보 처리).
- **AI 리포트(선택, 현재 미활성)**: 향후 LLM API로 리포트 문장을 다듬는 기능을 붙일 수 있으며, 이 경우 처리 내용·수탁사·국외이전 여부를 별도 고지 예정. **현재는 룰 엔진(자체 서버 내 결정론적 로직)만 사용하며 외부 AI에 데이터를 보내지 않음.**
- 그 외 제3자 제공 없음(법령 근거·동의 예외 제외).

## 7. 현재 적용 중인 보호조치

- 전송 구간 HTTPS
- 폼 입력값·비밀번호 원천 미수집, 민감정보 **클라이언트 + 서버 2중 마스킹**(이메일·전화·카드·주민번호)
- 원본 IP 미저장, 좌표 상대값(0~1)만 저장
- **URL query/hash 제거**(SDK·서버 2중), **referrer는 호스트명만** 저장
- **수동 전환 meta는 allowlist(dir만)** 로 제한하고 민감 키 차단
- **민감영역 수집 제외**: 고객이 `data-fl-ignore`/`.fl-sensitive` 지정 시 해당 영역 이벤트 미수집, `data-fl-label`로 안전 라벨 지정 가능
- **수집 API 도메인 검증**: Origin/Referer 호스트가 등록 도메인과 불일치하면 조용히 무시
- 비밀번호 scrypt 해시 저장, **운영 시크릿 강제**(기본값 사용 시 서버 기동 실패), 로그인 쿠키 **Secure(운영)**
- 멀티테넌시 격리: 모든 조회를 로그인 회원의 소속(대행사) 범위로 제한
- 공유 리포트는 집계값만 노출·읽기전용·**추측 불가 랜덤 토큰**·**기본 30일 만료**
- **보관기간 초과 이벤트 자동 삭제 스크립트**(cron 등록 필요)
- 봇 트래픽 제외(`navigator.webdriver`)

- **추적 거부 신호 존중**: GPC(Global Privacy Control)·DNT·방문자 opt-out(`window.flowlens.optOut()`, localStorage) 감지 시 수집 완전 중단
- **방문자 데이터 삭제 도구**: 기간·경로·세션키·전체 단위로 즉시 삭제(삭제요청 대응). 사이트별 `/데이터 관리` 탭
- **감사 로그**: 로그인·데이터 삭제·공유링크 생성·요금제 변경·가입을 시각과 함께 기록

> 위 항목은 별도 법무 검토 의견서(구현 5장)의 즉시 보완 권고를 반영해 구현·검증한 것입니다. 잔여 과제: 삭제요청 **접수 창구/신원확인 절차** 설계(현재는 운영자가 세션키로 삭제), 고위험 업종(의료·금융·법률) 설치 **정책·약관 분리**, CMP "동의 전 스크립트 미로드" 옵션, 감사로그 **보존기간·열람권한** 정책.

## 9. 법무 검토 요청 쟁점 (질문 리스트)

아래는 전문가께 판단을 요청드리는 항목입니다.

1. **개인정보 해당성**: 상대좌표+임시세션키+디바이스+유입경로+URL의 조합으로 수집되는 방문자 행동 데이터가 개인정보/가명정보/익명정보 중 무엇에 해당하는지? (개인 식별 목적 없음, IP·입력값 미수집 전제)
2. **동의 주체·요건**: 방문자 행동 데이터 수집에 대해 동의가 필요한지, 필요하다면 **동의 획득 의무가 웹사이트 운영자(회원)에게 있는지 FlowLens에게 있는지**? 쿠키/행태정보 동의 수준(맞춤형 광고 목적은 아님)?
3. **계약 형태**: FlowLens와 회원(웹사이트 운영자)의 관계가 개인정보 **처리위탁(수탁자)**인지, 제3자 제공인지, 공동처리인지? 표준 위탁계약/DPA 필수 여부와 필수 조항?
4. **국외 이전**: 해외 클라우드/향후 해외 LLM API 사용 시 고지·동의·문서화 요건?
5. **민감정보/특수업종**: 병원·상담 등 **의료 관련 사이트**에 설치될 때 추가 보호조치나 사용 제한이 필요한지? 금융·법률 사이트는?
6. **미성년자**: 만 14세 미만 대상 사이트에 대한 제한·법정대리인 동의 이슈 처리 방향?
7. **세션 리플레이**: 화면(DOM)을 녹화하지 않고 이벤트만 재생하는 방식이 개인정보/민감정보 노출 리스크를 충분히 낮추는지에 대한 확인.
8. **공유 링크**: 로그인 없이 열람 가능한 읽기전용 집계 리포트(개인정보 미포함)의 적정성 및 권고 보완사항.
9. **해외 규제**: EEA/UK/미국 방문자를 서비스 대상에 포함할 경우 GDPR/UK GDPR/CCPA 대응(사전 동의, GPC 등) 필요 범위.
10. **보관·삭제**: 요금제별 보관기간 정책의 적정성과, 방문자 삭제요청 처리 절차 요건.
