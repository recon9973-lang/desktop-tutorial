# FlowLens 설치 매뉴얼

> **소요 시간: 5~10분 · 코딩 지식 필요 없음**
> 이 문서는 고객사에게 그대로 전달해도 됩니다.

---

## 설치가 뭔가요? (1분 설명)

FlowLens는 방문자가 **어디를 클릭하고 어디까지 읽는지**를 알려줍니다.
그러려면 사이트에 **작은 코드 한 줄**을 넣어야 합니다. 이걸 "설치"라고 합니다.

```html
<script async src="https://flow.seokorea.org/t.js" data-site="사이트키"></script>
```

- 사이트가 느려지지 않습니다 (아주 작고, 뒤에서 조용히 실행)
- 방문자에게는 아무것도 안 보입니다
- **개인정보는 수집하지 않습니다** (이름·전화번호·입력값·IP 저장 안 함)

---

## 시작 전에 — 내 코드 받기

1. FlowLens 로그인 → **대시보드 → 사이트 선택 → "설치 · 공유" 탭**
2. 거기 있는 **내 코드를 복사** (사이트마다 코드가 다릅니다)
3. FlowLens가 **사이트 종류를 자동으로 알아내서** 딱 맞는 방법을 열어줍니다

> ❓ **내 사이트가 뭘로 만들어졌는지 모르겠어요**
> 괜찮습니다. 설치 화면이 자동으로 알려줍니다. 아니면 아래에서 화면이 비슷한 걸 찾으세요.

---

## 방법 1. 워드프레스 — ⭐ 가장 쉬움 (3분)

**코드 편집 전혀 없음.** 플러그인 파일만 올리면 끝.

1. 설치 탭에서 **"워드프레스 플러그인 다운로드"** 클릭
2. 받은 파일을 **압축(zip)** 합니다
   - Mac: 파일 우클릭 → "압축하기"
   - Windows: 우클릭 → 보내기 → 압축(zip) 폴더
3. 워드프레스 관리자 → **플러그인 → 새로 추가 → 플러그인 업로드**
4. zip 파일 선택 → **지금 설치** → **활성화**

✅ 끝났습니다. 코드는 이미 안에 들어 있습니다.

---

## 방법 2. 카페24 (5분)

1. 카페24 관리자 → **디자인 → 디자인(스마트) 편집**
2. 왼쪽에서 **공통 레이아웃** 파일 열기
3. `</head>` 라고 적힌 줄을 찾습니다 (Ctrl+F 로 검색)
4. **그 바로 위 줄에** 복사한 코드를 붙여넣기
5. **저장**

```html
   ... 기존 내용 ...
   <script async src="https://flow.seokorea.org/t.js" data-site="내코드"></script>  ← 여기에
</head>
```

---

## 방법 3. 아임웹 (3분)

1. 아임웹 관리자 → **사이트 관리 → 고급 → head 태그 삽입**
2. 칸에 복사한 코드를 붙여넣기 → **저장**

## 방법 4. 식스샵 (3분)

1. 관리자 → **설정 → 고급 설정 → head 스크립트**
2. 붙여넣기 → **저장**

## 방법 5. 윅스(Wix) (3분)

1. **설정 → 사용자 지정 코드 → 코드 추가**
2. 코드 붙여넣기, 위치는 **head**, 적용 범위는 **모든 페이지** → **적용**

---

## 방법 6. Google Tag Manager (GTM) (7분)

⚠️ **GTM은 주의할 점이 있습니다.** 반드시 **`?site=` 가 붙은 코드**를 쓰세요.
(GTM이 `data-site` 부분을 자동으로 지워버려서 작동하지 않습니다)

```html
<script async src="https://flow.seokorea.org/t.js?site=내코드"></script>
```

1. https://tagmanager.google.com → **내 사이트의 컨테이너** 선택
   - ⚠️ 컨테이너가 여러 개면, **사이트에 실제로 설치된 것**을 골라야 합니다
   - 확인법: 사이트에서 마우스 우클릭 → "페이지 소스 보기" → `GTM-` 으로 검색
2. 왼쪽 **태그 → 새로 만들기**
3. **태그 구성** 클릭 → **맞춤 HTML** 선택 → 위 코드 붙여넣기
4. **트리거** 클릭 → **All Pages(모든 페이지)** 선택
5. 이름을 `FlowLens 추적` 으로 저장
6. 🚨 오른쪽 위 **제출 → 게시** — **이걸 눌러야 실제 반영됩니다**

---

## 방법 7. 직접 만든 사이트 (개발자에게 전달)

모든 페이지의 `<head>` 안에 아래 한 줄을 넣어주세요.

```html
<script async src="https://flow.seokorea.org/t.js" data-site="내코드"></script>
```

React/Next.js/Vue 등도 동일합니다. (공통 레이아웃의 head)

---

## 방법 8. 사전 동의가 필요한 사이트 (해외·의료 등)

해외(EEA/UK) 방문자나 병원·의료·금융처럼 **동의를 먼저 받아야 하는 사이트**는, 방문자가 동의하기 전까지 아무것도 수집하지 않도록 설정할 수 있습니다.

```html
<!-- 동의 전에는 수집 안 함 -->
<script async src="https://flow.seokorea.org/t.js" data-site="내코드" data-fl-consent="required"></script>
```

그리고 사이트의 **동의 배너에서 "동의" 버튼**을 눌렀을 때 아래 한 줄을 실행하면 그때부터 수집이 시작됩니다.

```html
<button onclick="window.flowlens && window.flowlens.grantConsent()">동의</button>
```

- 한 번 동의하면 이후 방문에도 기억됩니다(브라우저에 저장).
- 동의를 철회하려면 `window.flowlens.revokeConsent()` 를 실행하면 즉시 수집이 멈춥니다.
- GTM으로 넣을 때는 `?consent=required` 를 코드 URL에 붙이세요: `.../t.js?site=내코드&consent=required`

> 참고: 이 옵션을 켜지 않아도 기본적으로 GPC·DNT(브라우저 추적거부 신호)와 방문자 opt-out은 항상 존중합니다. 사전 동의 모드는 "동의 전 아예 수집 안 함"이 필요한 사이트를 위한 것입니다.

## 설치 확인하기

1. 설치 후 **내 사이트를 한 번 방문**합니다
2. FlowLens **"설치 · 공유" 탭**을 새로고침
3. **"● 설치 확인됨"** 이 뜨면 성공 ✅

> ⏱ **바로 안 보여도 정상입니다.** 데이터가 서버에 도착하는 데 몇 초~1분 걸립니다.

---

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| "아직 이벤트 없음" 이 계속 뜸 | 설치 후 **사이트를 실제로 방문**했나요? 본인 방문도 잡힙니다 |
| GTM에 넣었는데 안 됨 | ①**게시(Publish)** 했나요? ②`?site=` 코드를 썼나요? ③사이트에 실제 설치된 **컨테이너가 맞나요?** |
| 코드를 어디 넣을지 모르겠음 | 사이트 만든 업체/담당자에게 **이 문서를 그대로 전달**하세요 |
| 히트맵이 비어 있음 | 방문자 클릭이 쌓여야 색이 보입니다. **며칠** 기다려 주세요 |

## 자주 묻는 질문

**Q. 사이트가 느려지나요?**
아니요. 코드가 아주 작고 `async`(뒤에서 로드)라 화면 표시를 막지 않습니다.

**Q. 개인정보가 수집되나요?**
아니요. 클릭 **위치**와 스크롤 **깊이**만 저장합니다.
이름·전화번호·비밀번호 같은 **입력값은 수집하지 않고**, **IP도 저장하지 않습니다**.
클릭한 버튼 이름에 이메일/전화번호가 섞여 있으면 **자동으로 가려서** 보냅니다.

**Q. 방문자에게 알려야 하나요?**
개인정보처리방침에 **"행동 분석 도구(FlowLens) 사용"** 문구를 넣는 것을 권장합니다.

**Q. 나중에 빼고 싶으면?**
- 워드프레스: 플러그인 비활성화
- 그 외: 넣었던 코드 한 줄 삭제

---

## 도움이 필요하면

설치가 어려우면 **담당자에게 이 문서를 전달**하거나, FlowLens에 문의해 주세요.
사이트 종류만 알려주시면 그 화면 기준으로 안내해 드립니다.
