# 이메일 알림 연동 (온보딩·체험만료) — 활성화 안내

작성일: 2026-07-19

FlowLens에 **트랜잭션 이메일**(가입 환영 · 무료체험 만료 리마인드) 발송 기능이 들어가 있습니다.
다만 실제 발송에는 **외부 메일 서비스(Resend) + API 키**가 필요합니다. **키가 없으면 아무 것도 보내지 않고(no-op) 앱은 정상 동작**합니다.

## 지금 구현된 것
- **가입 환영 메일**: 회원가입 시 발송(설정된 경우). `signup` 라우트에서 fire-and-forget.
- **체험 만료 리마인드**: 매일 크론(`/api/cron/cleanup`)이 무료체험 3일 이내 대행사의 OWNER에게 1회 발송. 중복 방지는 감사로그(`TRIAL_REMINDER`)로 처리(스키마 변경 없음).
- 발송 모듈 `lib/email.ts` — 별도 패키지 없이 Resend REST API를 `fetch`로 호출. `RESEND_API_KEY` 없으면 no-op.

## 활성화 방법 (약 10분)
1. **Resend 가입**: [resend.com](https://resend.com) 무료 티어(월 3,000통 등).
2. **도메인 인증**: `seokorea.org`(또는 사용할 발신 도메인)을 Resend에 등록하고 안내대로 DNS(SPF·DKIM) 레코드를 추가.
3. **API 키 발급**: Resend 대시보드 → API Keys.
4. **Vercel 환경변수 설정**(Production):
   - `RESEND_API_KEY` = 발급받은 키
   - `EMAIL_FROM` = 예) `FlowLens <onboarding@seokorea.org>` (인증한 도메인 주소여야 함)
5. **재배포**: `npx vercel@latest --prod`

설정 후 가입하면 환영 메일이, 체험 만료 3일 전이면 리마인드가 자동 발송됩니다.

## 안전장치
- `RESEND_API_KEY` 미설정 시: 발송을 시도하지 않고 조용히 넘어감(가입·크론 정상).
- 리마인드는 발송 **성공 시에만** 감사로그를 남겨 중복 방지 → 키를 나중에 넣어도 그때부터 정상 동작.
- 가입 환영 메일은 `await` 없이 발송해 가입 응답을 지연시키지 않음.
