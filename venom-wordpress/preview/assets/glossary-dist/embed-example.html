VENOM 용어사전 — 타 사이트 임베드 예제

두 가지 사용 방식을 한 페이지에서 보여줍니다. 원하는 방식만 골라 복사하세요.

방식 A · 위젯 임베드 (가장 간단)

glossary.js 한 줄이면 검색·초성·카테고리·상세 모달까지 완성됩니다. 자체 CSS 주입 — 의존성 0.

<div id="glossary-root"></div>
<script src="https://venom-new-site.vercel.app/assets/glossary.js"></script>
<script>Glossary.mount('glossary-root');</script>

방식 B · 데이터(JSON)만 가져와 직접 렌더링

glossary-data.json(723개 용어)을 fetch 해서 원하는 UI로 그립니다. 아래는 20줄짜리 미니 렌더러 데모입니다.

const res = await fetch('https://venom-new-site.vercel.app/assets/glossary-dist/glossary-data.json');
const { terms } = await res.json();
// terms[i] = { ko, en, def, category, dict, abbr, detail, example, related[], sources[] }
