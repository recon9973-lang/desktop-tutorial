# 의료광고심의 도우미 챗봇 — 기획서 (v2, 확정)

> 작성 2026-07-03 · 위치: VENOM 사이트 부속 모듈(`preview/chatbot/`) · 최종목표: **의료광고·의료광고심의 도우미 챗봇**

## Context (왜 만드는가)

병원 마케팅에서 의료광고는 **의료법 제56조(금지광고)·제57조(사전심의)** 와 **표시광고법**의 규제를 동시에 받는다. 위반 시 행정처분·형사처벌 위험이 크고, 심의기준은 매체·진료과목별로 상이하며 자주 개정된다. 실무자가 광고 문구·소재의 위반 소지를 **사전에** 진단하고 근거와 함께 대안을 받도록 돕는 것이 목표다.

핵심 판단: 오더의 "무한 반복 딥러닝 학습" 의도(계속 똑똑해지는 시스템)는 유지하되, 규제 도메인에서 실효적·안전한 **RAG(근거 인용형 생성) + 자동 평가·개선 루프**로 구현한다. 근거 인용 가능·환각 최소화·기준 개정 즉시 반영·저비용이 이유다.

## 오더 3단계 → 구현 매핑

| 오더 | 구현 |
|---|---|
| 1. 의료광고·심의·의료법 반복 학습 | **지식베이스 구축**(청킹·인덱싱) → 매 답변마다 근거 검색·인용 |
| 2. 질문 10,000개 생성·학습 | **평가셋 + 합성 Q&A 코퍼스**(자동 채점·검색강화·few-shot용, 모델 학습 아님) |
| 3. 통합 무한 반복(질문-답변-검토-진단-수정) | **LLM-as-Judge 자동 평가·개선 루프**(가중치가 아닌 검색·프롬프트·룰 개선) |

## 아키텍처 (RAG)

```
원천 자료 ─build.js─▶ 지식베이스(청크+메타) ─▶ 하이브리드 검색(키워드+벡터)
                                                      │
사용자 질문 ─▶ [오케스트레이터(LLM)] ─ 근거검색 ─▶ 근거기반 답변 + 조항·사례 인용 + 디스클레이머
                     │
                     └─▶ 문구 자가진단(forbidden-rules + 교육맥락 휴리스틱)
                                                      │
                        [평가·개선 루프] 10,000 질문셋으로 야간 채점→개선
```

- 스택: Vercel 서버리스(Node, CommonJS) + KV(Upstash). 기존 VENOM 인프라 재사용.
- LLM: `lib/openai-client.js` 재사용 가능. 법률추론 정확도상 Claude 사용도 권장(선택).

## 데이터 전략

- **확보(승인)**: 복지부 사례집 2판 → 지식베이스 시드(본 모듈 `data/`에 빌드 완료).
- **보강(예정)**: 의료법 조문 전문(law.go.kr API), 3개 협회 심의기준·서식, 심의 FAQ·반려/승인 사례.
- **Q&A 10,000**: 실데이터(FAQ·반려사례) 우선 수집 + 카테고리 템플릿 증강, 각 질문에 정답·근거조항·난이도 라벨, 홀드아웃 평가셋 분리.

## 로드맵

| Phase | 산출물 | 상태 |
|---|---|---|
| 1. 데이터 파이프라인 | 지식베이스·Q&A시드·룰·역색인 + 검색 검증 | ✅ 완료(본 커밋) |
| 2. 데이터 보강·임베딩 | 조문 전문·협회기준·FAQ, `embed.js` 벡터 | ⬜ |
| 3. 챗봇 API | `api/chatbot.js` RAG 응답(근거 인용) | ⬜ |
| 4. 웹 위젯·자가진단 UI | 사이트 임베드, 문구 하이라이트 | ⬜ |
| 5. 평가 루프·운영 | 10,000 질문 채점·개선, 모니터링 | ⬜ |

## 리스크 & 대응

- 오답의 법적 파장 → 근거 인용 강제 + "참고용" 디스클레이머 + 저신뢰 시 심의기구 확인 권고.
- 기준 개정 잦음 → 문서 교체형(RAG) 즉시 반영 + 개정 모니터링.
- 저작권 → 조문은 공공저작물, 협회자료는 인용+출처 원칙(대량복제 회피).
- 개인정보 → 사용자 업로드 소재 비식별·동의 처리.

## 추가 제안

문구 자가진단(하이라이트+대안), 매체·업종 선택 UX, 신뢰도 신호등, 개정 모니터링 봇, 실무자 피드백 루프(승인/반려 결과→평가셋 성장), 감사 로그, 면책·컴플라이언스 표준 문구.
