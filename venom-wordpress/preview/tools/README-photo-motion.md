# 사진 한 장 → 움직이는 GIF · WebP · 동영상 (자막 포함)

**주소**: https://venom-new-site.vercel.app/tools/photo-motion.html
(파일을 컴퓨터로 내려받아 두 번 눌러 열어도 됩니다 — 설치할 것이 없습니다.)

## 무엇을 하나
사진 한 장을 올리면 **카메라가 움직이는 것처럼**(천천히 다가가기·확대·훑기·숨쉬듯 반복·손떨림 등 9가지)
짧은 반복 영상을 만들고 **자막**을 얹어 세 가지 파일로 내려받습니다.

| 파일 | 언제 쓰나 | 특징 |
|---|---|---|
| **움직이는 WebP** | 홈페이지·카카오톡·인스타 | 가장 가볍고 색이 안 깨짐(권장) |
| GIF | 어디서나 열려야 할 때 | 무거움(256색) |
| 동영상 MP4/WebM | 인스타 릴스·유튜브 쇼츠 | 브라우저 녹화 기능으로 만듦 |

## 어떻게 만들어지나 (가볍게)
- 외부 라이브러리 없이 **HTML 파일 하나**입니다. 사진은 컴퓨터 밖으로 나가지 않습니다.
- 움직이는 WebP: 브라우저가 한 장씩 WebP로 만든 것을 애니메이션 상자(ANIM/ANMF)에 직접 담습니다.
- GIF: 256색 뽑기(중앙 분할) + 색 부드럽게(오차 확산) + LZW 압축을 직접 구현했습니다.
- 동영상: 브라우저 녹화(MediaRecorder). 크롬·엣지는 MP4, 그 외는 WebM.
- 자막: 여러 줄이면 「한꺼번에」또는「한 줄씩 차례로」, 서서히·떠오르기·한 글자씩 나타나기, 자리·크기·색·바탕 선택.

## AI 도우미 (이것만 AI 회사 토큰을 씁니다)
「AI에게 추천받기」를 누르면 **줄인 사진 한 장(640px)** 과 쓰임새·말투를 보내
**자막 문구 3개 · 어울리는 움직임 · 주인공 위치**를 받아 옵니다. 문구는 의료광고(의료법 제56조)
기준으로 쓰도록 지시합니다(효과 보장·전후 비교·최상급 금지).
- 기본 경로: 베놈 서버 `api/photo-motion-ai.js` → Vercel 환경변수 `ANTHROPIC_API_KEY`(우선) 또는 `OPENAI_API_KEY`.
  모델은 `ANTHROPIC_MODEL`(기본 `claude-opus-5`) / `OPENAI_VISION_MODEL`(기본 `gpt-4o-mini`)로 바꿀 수 있습니다.
- 서버 키가 없거나 파일을 컴퓨터에서 직접 열었다면 화면의 「AI 연결 설정」에 본인 키를 넣으면 브라우저가 바로 부릅니다(키는 그 브라우저에만 저장).
- 한 주소당 시간당 30번으로 제한합니다.

## AI 로 「말하는 영상」 → 자막 · 반복 WebP (2026-09-28 추가)
사장님 결정: **MiniMax 로 뽑고, 소리는 빼고, 자막으로 처리하고, GIF 처럼 끝없이 도는 웹최적화 파일(움직이는 WebP)** 로 만든다.

1. **영상 뽑기** — 두 길.
   - **화면에서 바로(2026-09-29 추가)**: 사진을 올리면 「이 사진으로 AI 말하는 영상 만들기」 상자가 나온다(서버에 키가 있을 때만). 대사·길이(6/10초)를 적고 누르면
     `api/photo-motion-video.js` 가 영상 AI 를 불러 1~3분 뒤 영상이 자동으로 올라오고 대사가 자막에 들어간다.
     **서버 키(Vercel 환경변수)가 필요하다** — `HIGGSFIELD_API_KEY` = `키ID:키비밀` (https://cloud.higgsfield.ai 에서 발급 · **사용량 과금, 사이트 구독 크레딧과 별도**)
     또는 `MINIMAX_API_KEY` (https://platform.minimax.io). 둘 다 있으면 Higgsfield 우선. 값은 코드에 절대 넣지 않는다.
     쓰는 모델: Higgsfield 경로 `/minimax/hailuo-2.3/standard/image-to-video`(`HIGGSFIELD_VIDEO_PATH` 로 변경 가능) / MiniMax `MiniMax-Hailuo-2.3`.
     ⚠ 실제 API 호출은 작업 컨테이너가 외부 통신을 막아 **흉내 낸 서버로만** 검사했다. 키를 넣고 처음 누를 때 API 가 항목 이름을 거부하면 화면에 그 오류가 그대로 뜬다 → 다음 세션에서 그 문구대로 고친다.
   - **클로드에게 시키기**: 사진 + 대사를 주면 클로드 세션(Higgsfield MCP)이 `minimax_h3_max` 로 카메라 고정·8초(20 크레딧 ≈ 1달러) 영상 주소를 준다. 1,000 크레딧 = 49달러.
2. **자막·반복 WebP 만들기** — 두 길 중 하나:
   - **화면에서**: 이 도구에 MP4 를 올린다(15초까지). 소리는 자동으로 빠지고, 「끝과 처음을 겹쳐 섞기」(기본 0.6초)로 이음새 없이 반복된다. 자막은 여러 줄이면 「한 줄씩 차례로」가 기본. 움직이는 WebP / GIF / MP4 로 내려받는다.
   - **GitHub 워크플로로**: `.github/workflows/video-to-webp.yml` 을 「Run workflow」 → 영상 주소·파일이름·자막(줄은 ` | ` 로 나눔)·가로·초당 장수·겹침 초 → `images/motion/<이름>.webp` 로 커밋되어
     `https://venom-new-site.vercel.app/images/motion/<이름>.webp` 에서 바로 쓴다. 실제 일은 `tools/video-to-webp.py`(ffmpeg) 가 한다.

## 지원 브라우저
크롬·엣지·삼성인터넷·웨일: 세 가지 전부. 파이어폭스·사파리: GIF·동영상은 되고 움직이는 WebP는 안 될 수 있습니다(화면에 안내가 뜹니다).

## 확인한 것 (2026-09-28, 헤드리스 크롬)
영상 모드: 2.5초 MP4 → 0.6초 겹침 → 1.9초·12장/초 = 23장 WebP 674KB · GIF 2.3MB, 자막 3줄 차례로 표시 확인.
736×1308 사진 · 4:5 · 가로 480 · 2.5초 · 초당 12장 → WebP 800KB(30장) · GIF 2.6MB(30장) · MP4 164KB. 세 파일 모두 열려서 30장으로 읽혔습니다.
실제 AI 호출은 작업 컨테이너가 외부 통신을 막아(403) 흉내 낸 응답으로만 확인했습니다 — 배포 뒤 화면에서 한 번 눌러 보면 됩니다.
