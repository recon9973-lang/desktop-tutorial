# 베노미(Venomi) — 병원명 한 줄 진단 카카오톡 봇 기획서 (v2, 방향 확정)

> 제품명 **"베노미(Venomi)"** — 베놈 컨설턴트의 AI 코워커.
> 작성 2026-07-10 (v2 갱신) · 위치: VENOM 사이트 부속 모듈(`preview/hospital-bot/`)
> 한 줄 정의: **카카오톡 채팅방에 "병원명"만 넣으면, SEO·GEO·네이버 플레이스·광고를 한 번에 진단해 컨설턴트에게 제안서 초안까지 돌려주는 AI 코워커.**

## ✅ v2 확정 사항 (오더 반영)
- **운영 방향: 내부 우선** — 1차 사용자는 베놈 컨설턴트·영업팀(트랙 B). 대외 리드젠(트랙 A)은 후순위 확장.
- **제품명: 베노미(Venomi)**.
- **무료 한도: 변동(유연)** — 내부 도구이므로 하드 캡 없이 비용 모니터링 기반 소프트 조절.
- **카톡 연동 등급: 일반 채널 챗봇(오픈빌더 스킬 서버)로 충분** — 알림톡·비즈메시지 불필요(고객 발송용). 내부 전용이므로 **발신자 카카오 ID 화이트리스트**로 직원만 응답 게이팅. (v2 신규 권고)

## 0. 이 기획서의 한 문장 요약

자비스M이 *키워드 → 검색량·CPC* 단건 조회기라면, 베놈 닥터봇은 **병원명 → 전방위 마케팅 건강검진**을 수행하는 **에이전트형 진단 봇**이다. 자비스M을 "리드 유입 미끼(무료 툴)"로, 그 뒤에 베놈의 SEO/GEO/광고 컨설팅 수주를 연결하는 **성장 깔때기(growth funnel)** 로 설계한다.

---

## 1. 벤치마크 — 자비스M(M-자비스) 해부

| 항목 | 자비스M | 베놈 닥터봇 (본 기획) |
|---|---|---|
| 입력 | **키워드** | **병원명**(+지역 자동/수동) |
| 명령 | `키워드*`(성·연령) `키워드@`(CPC) `키워드&`(상위 블로거) `키워드/`(연관어) | 병원명 단독 → 종합 진단. 추가로 `병원명 seo` `병원명 geo` `병원명 광고` `병원명 vs 경쟁사` 등 |
| 출력 | 검색량·CPC 숫자 | **진단 점수 + 문제 진단 + 개선 처방 + 컨설팅 제안** |
| 성격 | 조회 도구 | **컨설턴트/코워커** |
| 수익 모델 | 무료(브랜드 노출) | **무료 진단 → 상담 전환(리드젠)** + 내부 컨설턴트 생산성 도구 |
| 기술 | 검색량 API 단순 래핑 | **RAG + 다중 데이터 소스 오케스트레이션 + LLM 리포트 생성** |

핵심 차별점: 자비스M은 "숫자를 준다". 베놈 닥터봇은 **"그 숫자가 당신 병원에 무슨 의미인지, 지금 무엇이 문제고, 무엇을 해야 하는지"**를 준다. 이것이 병원 원장(비전문가)에게 훨씬 강력한 리드 미끼다.

> 참고: 자비스M 실제 명령 체계 확인 — 키워드 뒤 `*`=성별·연령, `@`=파워링크 순위별 CPC, `&`=상위 TOP5 블로거, `/`=연관 검색어. (카톡 채널 무료 챗봇, 설치 불필요)

## 2. 문제 정의 & 기회

**병원 원장의 현실**
- 자기 병원이 네이버/구글/AI검색에서 **어떻게 보이는지 모른다.** 대행사 말만 믿는다.
- SEO·GEO·플레이스·파워링크가 뭔지 용어부터 낯설다.
- 대행사 견적이 비싼지 싼지, 지금 잘 되고 있는지 **객관적 기준이 없다.**

**베놈의 기회**
- 이미 보유: 네이버 검색광고 API(검색량·CPC), 키워드 리서치, SEO 점수기, GEO/AEO 점수기, 의료광고 심의 RAG 챗봇, 의료광고 검증기, PSI(속도), 콘텐츠 생성기.
- 이 자산들을 **"병원명 하나"로 오케스트레이션**하면, 원장이 카톡 한 줄로 자기 병원 건강검진을 받는 경험을 만들 수 있다.
- 진단 결과의 "빨간 신호"가 곧 베놈의 **영업 포인트**가 된다. (예: "GEO 노출 0건 → AI 검색 대응 시급")

## 3. 타깃 & 운영 모드 (내부 우선 · 확정)

### 트랙 B — 내부 코워커 (Internal, **우선순위 1 · 확정**)
- 대상: **베놈 컨설턴트·영업팀·대표**.
- 용도: 신규 미팅 전 30초 만에 대상 병원 **풀 진단서** 뽑기 → **제안서/견적 자동 초안** → 미팅 화력.
- 채널: 카카오톡 채널 챗봇 + **내부 직원 화이트리스트**(발신자 ID 검증). 상담원이 팀 채팅에서 병원명만 던지면 응답.
- 출력: **컨설턴트용 풀리포트**(수치·근거·경쟁표·처방 액션 전부) + 웹 상세 + 제안서 초안. (원장용 요약보다 상세도 높음)
- 무료 한도: **변동/유연** — 하드 캡 없이 GEO 프로빙 비용만 모니터링해 소프트 조절.

### 트랙 A — 대외 리드젠 봇 (Public, 우선순위 2 · 후속 확장)
- 대상: **병원 원장·실장** (비전문가).
- 용도: 무료 진단 경험 → 상담 신청/DB 확보(자비스M식 바이럴). 내부 엔진이 안정화된 뒤 **동일 엔진 + 원장용 쉬운 요약 출력**으로 개방.
- 톤: 쉬운 말, 과장 금지(의료광고법).

> 두 트랙은 **같은 진단 엔진**을 공유하고, 출력 상세도(컨설턴트 풀리포트 vs 원장용 요약)만 다르게 한다. **먼저 내부(풀리포트)를 완성**하면 대외(요약)는 출력 포맷만 얹으면 된다.

## 4. 핵심 기능 — "병원명" 하나로 돌리는 6대 진단

입력: `강남 OO치과` 또는 `OO치과 서울 강남` (지역 미입력 시 네이버 플레이스로 자동 보정)

### 4-1. 🔎 SEO 진단 (홈페이지 검색 최적화)
- 병원 공식 홈페이지 자동 탐지(네이버 플레이스/구글 검색) → URL 진단.
- 항목: title/meta, 모바일 대응, 페이지 속도(PSI), 구조화 데이터(LocalBusiness/FAQ), robots/sitemap, HTTPS, 내부링크, 이미지 alt.
- 산출: **SEO 100점 스코어 + 상위 3개 시급 개선항목.**
- 재사용: `lib/psi.js`, `api/seo-proxy.js`, 사이트 SEO 점수기 로직.

### 4-2. 🤖 GEO/AEO 진단 (AI 검색 노출) — **최대 차별점**
- "이 지역 OO과 추천", "OO 잘하는 병원" 등 **환자 의도 프롬프트 10~15개**를 생성.
- ChatGPT·Perplexity·Gemini(가능 시 네이버 Cue:)에 질의 → **병원명이 언급/인용되는가** 측정.
- 지표: **인용률(Citation Rate), 답변 내 점유율(SoV), 감성(긍/중/부).**
- 산출: **GEO 노출 등급(A~F) + "AI가 당신 병원을 아는가/모르는가"** 한 줄 판정.
- 근거: GEO 진단은 핵심 쿼리셋을 AI에 넣어 브랜드 언급·인용을 기록하는 방식이 업계 표준. (SoV·Citation Rate·Sentiment)

### 4-3. 📍 네이버 플레이스·블로그·뷰 진단 (로컬)
- 네이버 플레이스: 등록 여부, 리뷰 수·평점, 사진 수, 예약/톡 연결, 소식 최신성.
- 블로그/카페: 병원명·핵심 키워드 상위 노출 개수, 최신 포스팅 빈도.
- 뉴스/PR: 언론 노출(백링크·E-E-A-T) 유무.
- 재사용: PlayMCP `NaverSearch-search_local / search_blog / search_cafearticle / search_news`.

### 4-4. 💰 광고 컨설팅 (검색량·CPC·채널·예산)
- 병원 진료과목·지역에서 **핵심 키워드 세트** 자동 추출 → 월 검색량·경쟁도·**파워링크 CPC**.
- 채널 조합 추천(파워링크/파워컨텐츠/브랜드검색/플레이스광고) + **적정 월 예산 밴드**.
- "지금 이 키워드는 CPC ₩X, 월 예산 ₩Y면 상위 노출 가능" 식 실행 가능한 제안.
- 재사용: `lib/naver-searchad.js`, `lib/keyword-research.js`, 사이트 `pg-services` 채널 가이드 표.

### 4-5. ⚔️ 경쟁사 비교 (`병원명 vs 경쟁사` 또는 지역 자동)
- 같은 지역·진료과 상위 3개 병원과 **SEO·GEO·플레이스·광고 노출**을 나란히 비교.
- 산출: **"동네 순위표"** — 원장에게 가장 강력한 자극.

### 4-6. ⚖️ 의료광고법 리스크 스캔
- 병원 홈페이지·블로그 문구에서 **금지 표현(최고·유일·100%·전후사진 등)** 자동 탐지 → 위반 소지 + 안전 대체어.
- 재사용: 이미 구축된 `lib/medical-ad-validator.js`(금지어 46 + 대체어) + `chatbot/`의 의료광고 심의 RAG(청크 122, 근거조항 94).

## 5. 명령어 문법 (자비스M 계승 + 확장)

| 입력 | 동작 |
|---|---|
| `강남 OO치과` | **종합 진단**(6대 요약 카드) |
| `강남 OO치과 seo` | SEO 상세 리포트 |
| `강남 OO치과 geo` | GEO/AI검색 노출 상세 |
| `강남 OO치과 광고` | 키워드·CPC·예산 컨설팅 |
| `강남 OO치과 플레이스` | 네이버 로컬 상세 |
| `강남 OO치과 vs 신사 △△치과` | 1:1 경쟁 비교 |
| `강남 OO치과 심의` | 광고 문구 리스크 스캔 |
| `임플란트@` (키워드 조회) | 자비스M 호환 — 키워드 CPC 단건(하위 호환) |
| `상담` / `견적` | 진단 결과 기반 베놈 컨설팅 연결(리드 전환) |

> 원장이 기호를 못 외워도 되게 **병원명만 넣으면 기본 종합 진단**이 나오고, 카드 하단 **버튼(오픈빌더 quickReplies)** 으로 "SEO 자세히 / GEO 자세히 / 광고 제안 / 무료 상담"을 탭하게 한다. (자비스M보다 UX 우위)

## 7. 시스템 아키텍처

```
카카오톡 채널(원장)
      │ 발화 "병원명"
      ▼
카카오 i 오픈빌더 (챗봇 빌드)
  · 폴백 블록 → 스킬(Skill) 서버 호출 (HTTP POST, JSON)
      │
      ▼
Vercel 서버리스  api/hospital-bot.js  ← 신규 (오케스트레이터)
      │  ├─ 플레이스/홈페이지 탐지  (NaverSearch search_local)
      │  ├─ SEO 진단              (lib/psi.js, seo-proxy)
      │  ├─ GEO 프로빙            (신규 lib/geo-probe.js → LLM 다중질의)
      │  ├─ 로컬 진단             (NaverSearch blog/news/local)
      │  ├─ 광고 컨설팅           (lib/naver-searchad, keyword-research)
      │  ├─ 광고법 스캔           (lib/medical-ad-validator + chatbot RAG)
      │  └─ 리포트 합성           (lib/anthropic-client → 카톡 카드 JSON)
      │
      ├─ 캐시/DB: Upstash KV (병원별 진단 24h 캐시, 리드 로그)
      └─ 웹 풀리포트: /hospital-bot/report/:id (상세 링크)
```

- **오픈빌더 5초 타임아웃 대응**: 즉시 "진단 중… 20초 내 결과 전송" 응답 → 완료 시 **카카오 채널 메시지 API(콜백/푸시)** 로 결과 전송. (동기 스킬 응답 한계 회피)
- 기존 VENOM 인프라(Vercel + Upstash KV + lib/*) **그대로 재사용**, 신규 코드는 오케스트레이터·GEO 프로버·카톡 포맷터 3개뿐.

→ **신규 개발은 사실상 GEO 프로버 + 카톡 오케스트레이터 2개.** 나머지는 조립.

## 9. 스코어링 로직 (초안)

- **SEO 100점**: 기술(40) + 콘텐츠(30) + 로컬/구조화(30). 기존 점수기 승계.
- **GEO 등급**: 인용률로 A(≥60%)~F(0%). 프롬프트 12개 중 언급 횟수 기준. SoV = 자병원 언급 / (자+경쟁 언급).
- **종합등급**: SEO·GEO·플레이스·광고효율 가중합 → A~F + **동네 백분위**(경쟁 비교).
- 모든 점수에 **"이 점수의 의미"** 자연어 한 줄 동봉(원장 이해도 우선).

## 11. 컴플라이언스 & 리스크

- **의료광고법**: 봇 출력에 전후사진·효과보장·최상급·환자경험담 인용 금지(CLAUDE.md 규칙 준수). 진단은 "사실·데이터"만, 처방은 "권고"로.
- **면책 문구 고정**: "공개 데이터 기반 참고용 진단이며 실제 성과·심의를 보장하지 않습니다."
- **타 병원 정보**: 경쟁 비교는 공개 검색 데이터만, 비방·허위 금지. 경쟁사명은 원장이 직접 입력하거나 익명화(△△치과) 옵션.
- **LLM 환각**: GEO 프로빙 원문·SEO 수치는 **실측 캡처/스냅샷** 보관, 리포트 문장만 LLM 생성(수치 창작 금지).
- **개인정보**: 리드 DB(전화·병원명)는 동의 기반 수집·베놈 CRM 이관.
- **비용·레이트리밋**: GEO 프로빙(LLM 다중 호출)이 최대 비용원 → 병원별 24h 캐시, 무료는 1일 N회 제한, 상세는 상담 후.

## 13. 비즈니스 모델 & KPI
