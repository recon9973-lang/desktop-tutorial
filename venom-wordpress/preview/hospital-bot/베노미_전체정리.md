# 🩺 베노미(Venomi) — 카톡 병원 진단봇 전체 정리 · 파일 지도

## 1. 이게 뭔가
- **베노미** = 병원마케팅 대행사 **베놈(VENOM)**의 **사내 카카오톡 진단 챗봇**.
- 직원이 카톡에 **`지역 병원명`**(예: `대구 수성구 범어5층치과의원`)을 넣으면
  → **업체 확인 카드 + 항목 버튼**이 나오고, 버튼을 눌러 **하나씩 정확히** 진단.
- 진단 항목: **네이버 로컬 · 의료광고법 · 광고 기회 · SEO · GEO(AI검색) · 동네 순위 · 제안서**.
- 내부 직원 전용(화이트리스트). 카카오 채널 `_LxcrQxb`(관리자센터 기준).

## 2. 어디서 도는가 (배포)
- **Vercel 서버리스**, 프로덕션: `https://desktop-tutorial-lemon-gamma.vercel.app`

- 작업 브랜치: `claude/hospital-seo-geo-chatbot-4wqobs`.

## 3. 핵심 파일 지도 (repo 경로는 `venom-wordpress/preview/` 기준)

### 진입점 · 스킬 서버
| 파일 | 역할 |
|---|---|
| `api/hospital-bot.js` | **카카오 스킬 서버 + 진단 API**. 발화 파싱→지역 게이트→confirm/뷰 라우팅, 5초 타임아웃 대응, GET 상태. |

### 봇 코어 (`hospital-bot/lib/`)
| 파일 | 역할 |
|---|---|
| `diagnose.js` | **진단 오케스트레이터**. `diagnose()`(전체), `resolvePlace()`(업체확인 경량), `diagnoseLocalOnly()`(로컬 전용), `computeBase()`(6대 진단·24h 캐시), `parseInput()`(지역·URL 파싱), `classifyHomepage()`(블로그/SNS/site), `keywordRanks()`/`coreKeywords()`(키워드 순위), `diagnoseSeo()`(온페이지+PSI), `diagnoseAdLaw()`(의료광고법+위치), `diagnoseSearchConsole()`(GSC). |
| `kakao-format.js` | **카톡 렌더**. `parseCommand()`(발화→뷰), `renderConfirm()`(업체확인+버튼), `renderAskRegion()`, `renderSeo/Local/Ads/Geo/Law/Compete/Proposal`, `viewQuickReplies(name,region)`(지역 포함 버튼), `renderMyId/Help/Refusal/Slow`. |
| `naver-openapi.js` | 네이버 검색 OpenAPI(local/blog/news) 래퍼 + `findHospital()`(이름매칭 confidence). |
| `naver-place.js` | **pcmap best-effort 스크래핑**: `findHomepage()`(자동 홈페이지 탐색·현재 비활성), `fetchPlaceReviews()`(리뷰 수), `extractReviewCounts()`, `isSiteUrl()`(잘린 URL 거부). |
| `onpage-lite.js` | **의존성 0 온페이지 SEO 스코어러**(linkedom 없을 때 폴백, 15항목·100점). |
| `whitelist.js` | 직원 화이트리스트(`VENOMI_WHITELIST`) 체크. |
| `geo-probe.js` | GEO(AI검색) 프로빙(스텁/실측). |
| `compete.js` | 동네 순위(경쟁사 비교). |
| `proposal.js` | 진단→제안서 초안 생성. |

### 재사용 자산 (`lib/` — 봇이 require)

| `lib/naver-searchad.js` | 네이버 검색광고(검색량·CPC). env `NAVER_AD_*`. |

| `lib/cache.js` | KV 24h 캐시(설정 시). |
| `seo/seo-engine.js` | **온페이지 SEO 정밀 엔진**(화면·크론·봇 공용). linkedom+PSI. |

## 4. 데이터 흐름 (한 요청)
```
카톡 발화 → api/hospital-bot.js
  parseCommand(발화) → {view, hospital}
  지역 없으면 renderAskRegion
  view=confirm → resolvePlace() → renderConfirm(업체+버튼)
  view=local   → diagnoseLocalOnly() → renderLocal(키워드순위·리뷰)
  view=seo/ads/geo/law/... → diagnose()(computeBase 캐시) → render○○
```

## 5. 환경변수(키) — `config`에 on/off 노출
| env | 용도 | 없으면 |
|---|---|---|
| `NAVER_CLIENT_ID/SECRET` | 네이버 검색 OpenAPI | 로컬·블로그·플레이스 진단 불가 |
| `VENOMI_WHITELIST` | 직원 접근키(쉼표 구분) | open 모드(누구나) |
| `PSI_KEY` | 성능·CWV | 온페이지 SEO는 되고 성능만 생략 |
| `GSC_SERVICE_ACCOUNT_JSON`(또는 `GSC_CLIENT_EMAIL`+`GSC_PRIVATE_KEY`)+`GSC_SITE_URL` | 구글 실측(관리고객) | GSC 항목 미노출 |
| `NAVER_AD_API_KEY`/`NAVER_ACCESS_LICENSE` | 검색광고 CPC | 광고 "미설정" |
| `PERPLEXITY/OPENAI/GEMINI/ANTHROPIC` 중 1 | GEO 실측 | GEO "미설정" |
| `VENOMI_SITE_BASE` | 웹 리포트 링크 노출 | 링크 카드 숨김 |
