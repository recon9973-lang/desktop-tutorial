## 1. 한눈표 — 5개 화면이 각각 무엇을 팔고, 검산에서 무엇이 나왔나

| 장 | 화면 | 파는 것 | 검산·분해에서 나온 것 |
|---|---|---|---|
| **1** | 모니터링 (프라이머) | 측정 그 자체 — 질문별 %·모델별 응답·참조 출처 35개 | 정수와 % 는 **분모가 다르다**(역산으로 확정) · 웹서치 켬/끔을 나눠 잰다 · `utm_source=openai` 로 인용 링크를 수거한다 |
| **2** | 현황 분석 / 학습 데이터 발행 | 전략과 처방 — 기회 점수 80점, 자동 생성 글 3편 | 처방 논리 = **경쟁사가 안 쓴 사실 하나**(지분율 명시) · 두 개의 문(학습데이터/실시간검색)을 gpto.kr 원문으로 확인 · 자동 생성 글에 검증 안 된 숫자("287건")가 박혀 나간다 |
| **3** | 성과 — 안산 치과 | before → after: 10.8% → 42.2% | 회사 대표 홍보 수치의 원본이 이 한 건 · "8주" 표기 vs 실측 63일(9주) · 검색계 엔진(40% 출발)과 순수 LLM(0% 출발)이 갈린다 · 실패 줄(9%→9%)을 남겼다 |
| **4** | 포트폴리오 — 패션·박람회 | 업종 넓이 (B2C·B2B) | **상위 3개 질문만 골라 실었다**(질문평균 46% vs 전체 21.1%) · 기준선 낮을수록 배수 화법(9.6배)이 좋아진다 · 주간 변동성 실재(솟았다 꺼진 봉우리) |
| **5** | 글로벌 — 일·영·중 | 언어 넓이 ("18개국") | 상위 3개 노출 재확인(60% vs 40.4%) · **22% 출발이 통산 5회** → 작은 분모 격자(≈9칸) 확정적 · 중국어 의료관광 질문이 "IT 제조업" 라벨과 불일치 |
| 공통 | — | **상태가 아니라 변화(+N%p)** | 분모·오차·측정시각이 **한 화면에도 없다** |

**한 문장 요약:** GPTO 는 *AI 답변을 검색순위처럼 재고 → 경쟁사가 비운 사실을 찾아 →
AI 가 인용하던 채널 유형에 그 언어로 되쏘고 → 다시 재서 선을 그려 → 그 선을 판다.*

## 2. VEO 와 나란히 놓기

| 항목 | GPTO (화면·공개자료 기준) | VEO (코드·DB 실측 기준) |
|---|---|---|
| 측정 엔진 | 10대 LLM (글로벌5+중국5) | 5 엔진 (OpenAI·Anthropic·Gemini·Perplexity·xAI) + 네이버 AI 브리핑 |
| 웹서치 켬/끔 분리 | 진단 화면에는 있음 · **성과 화면에선 합산** | **켬/끔을 조건으로 저장**(`search_mode`, 75/60건 실측) — 성과에서도 가를 수 있음 |
| 질문 규모 | 50~200개 / 주 1회 | 5개 · 수동 1회 완료(08-15 첫 관측) · 정기 주 3회는 켜기 전 · 반복 3회 |
| 호출 비용 | (비공개) | **실측 호출당 $0.0195** — 200개×10모델도 월 $169 수준으로 성립 확인 |
| 지표 정의 | SMR — 분모 비공개 | 분모·잰 시각·근거 등급 병기 규칙 + 신뢰구간 문서 보유 |
| 비용 추적 | (비공개) | 호출별 `cost_usd`+`cost_basis`, 못 잰 호출 별도 집계 |
| 측정 조건 기록 | (비공개) | 모델판·검색모드·**추론강도**·locale·계정상태를 조건으로 저장(ADR 0014) |
| 콘텐츠 발행 | 자동 생성 → **500+ 채널 자동 배포** | 없음 (진단·측정까지) |
| 의료 검수 | **안 보임** (범용 파이프라인) | seo-medical-expert · 의료광고법(제56조) 검수 체계 |
| 다국어 | 18개국 언어 상품화 | `locale` 칼럼 존재(ko-KR) · 질문세트/발행은 없음 |
| 성과 리포트 | before→after 완성형, 업종 4개 사례 | **추이 부품은 이미 있음**(주별 추이선·업체별 6회 막대 — 0.3.130/0.3.114 미배포) · 없는 것은 **기준선 대비 헤드라인**(기존→현재 한 줄) |
| 고객 확보 | 도입사 100+ · 해시드 투자 · 데모데이 | 파일럿 측정 단계 |

## 3. 우리가 우위인 부분

| # | 우위 | 근거 |
|---|---|---|
| 1 | **측정의 정직함 — 분모·시각·근거 등급** | GPTO 는 5개 화면 어디에도 분모가 없고, 전체 언급률이 어떤 평균과도 안 맞으며(3·4·5편 검산), 기간 표기가 달력과 어긋난다(8주 vs 9주). 우리는 병기 규칙 + `GEO_PROMPT_SAMPLING_AND_CONFIDENCE.md` 보유 |
| 2 | **비용의 투명성** | 호출별 실제 청구값과 `cost_basis`(계산/제공자보고/못잼 사유 7종)를 저장. "가격을 알 수 없어 못 잰 호출 N건" 을 따로 보고하는 구조는 GPTO 쪽 어디에도 근거가 없다 |
| 3 | **조건의 완전 기록** | GPTO 성과 화면은 켬/끔이 합산되어 "검색 경로 효과인지 AI 기억 효과인지" 고객이 알 수 없다. 우리는 추론강도까지 조건으로 저장 — 같은 리포트를 **가른 채로** 낼 수 있다 |
| 4 | **의료 도메인 검수** | GPTO 질문 문구("잘하는"·"안 아프게"·"시술 경험 많은")를 콘텐츠로 만들면 의료법 제56조 지뢰밭. 자동 생성 글이 검증 안 된 숫자를 500 채널에 뿌리는 구조에 검수 관문이 안 보인다. 안산 5번 질문(수면마취·무통)이 9%→9% 로 못 오른 것도 이와 무관치 않아 보인다[추정]. **범용 파이프라인이 병원에서 막히는 지점 = 우리가 서는 지점** |
| 5 | **직접 비교 가능한 실측 보유** | 마산 치과 측정(`2026-08-11-chamsarang-masan-measurement.md`)이 이미 있다 — 같은 업종·같은 방법론의 우리 데이터 |

## 4. 우리가 벤치마킹해야 할 부분

| # | 벤치마킹 | 어느 화면 | 우리의 현재 |
|---|---|---|---|
| 1 | **변화를 판다 — before→after 리포트 양식** | 3·4·5편 전부 | 지금 상태만 보여줌 (UX-RENEWAL 원인 진단 그대로). 계약 시점 스냅샷을 기준선으로 박고 "기존→현재" 한 줄을 최상단에 |
| 2 | **브랜드명 없는 니즈 질문 + 속성 질문 설계** | 1편(투자 조건) · 3편(공휴일 진료) · 4편(가품 이슈 없는) · 5편(중국어 서비스) | 질문 3제작법 문서에 유형 추가: 운영 정보형 · 속성 조건형 · 외국어 서비스형 |
| 3 | **빈 질문(0%) 우선 전략** | 3·4·5편 — 0% 출발 질문이 가장 크게·빨리 오름 | 기회 점수에 "현재 0% = 삽입 난이도 최저" 가중을 반영 |
| 4 | **인용 출처 수거 → 배포 목표화** | 1편 `utm_source=openai` · 2편 채널 7유형 | 관측 때 인용 URL 을 수거는 하되 유형 분류·실행 목록화가 없음 — 출처 목록을 "여기에 실려야 한다" 처방으로 바꾼다 |
| 5 | **진단→처방→발행→재측정의 닫힌 고리** | 2편 | 우리는 진단·측정까지. 발행(콘텐츠 프로그램)이 열려 있음 — 단 의료 검수 관문을 반드시 끼워서 |
| 6 | **측정 규모** | 1편 (질문 50~200) | 질문 5개. 비용 실측상 확장 성립 — 반복 3회 완화 검정(기존 135건으로 가능)부터 |
| 7 | **경쟁 브랜드 무료 수집** | 1편 (답변에서 30개 자동 추출) | **등록한 브랜드끼리 비교는 있음**(브랜드 식별·비교 화면). 답변 속 **미등록 브랜드 자동 추출**이 있는지는 미확인 — 확인 후 없으면 추가 |

## 5. 시사점 — 판단 셋

**① 시장 신호: 우리 방향이 맞다, 그리고 시간이 있다.**
GPTO 가 병원(안산)·의료관광(중국어 필러 질문)까지 이미 데모한다 — 시장은 실재한다.
동시에 그들의 약점(분모 없음·검수 없음·켬끔 합산)은 전부 **정직한 측정으로 이길 수 있는
자리**다. 저가 모방이 아니라 "검증되는 GPTO"가 우리 포지션이다.

**② 제품 격차의 우선순위: 리포트 양식 > 질문 규모 > 발행.**
비용 실측으로 규모의 벽은 낮다는 게 확인됐다(월 $42~169/거래처). 진짜 격차는
**성과를 파는 화면**(before→after)이 없다는 것 — UX-RENEWAL 원칙 3(변화량)과 같은
결론이 경쟁사 분해에서 세 번째로 나왔다. 화면이 먼저다.

**③ 병원 특화 + 의료관광이 차별화의 끝단이다.**
GPTO 는 18개국·전 업종으로 넓게 간다. 우리는 병원 하나를 깊게 — 의료광고법 검수를
관문으로 박은 콘텐츠 발행, 그리고 (법 확인 후) 외국인 환자 유치 GEO 까지. 넓은 GPTO 가
따라 들어오기 가장 비싼 자리가 여기다.

## 6. 이 비교의 한계

* GPTO 쪽 근거는 **강연 화면 5장 + 공개 웹페이지**다. 내부 구현·실제 분모·검수 유무는
  화면에 안 보였을 뿐 존재할 수 있다. "안 보인다"와 "없다"는 다르다.
* VEO 쪽 근거는 2026-08-15 실측(호출 135건·하루치)이다. 규모 환산은 `[계산]` 이다.
* GPTO 성과 수치(10.8→42.2 등)는 검증 불가능한 자기 보고다 — 이 문서는 그 수치의
  사실 여부가 아니라 **화면 구성과 산식의 정합성**만 검산했다.
