## 2. 좌측 — 현황 분석 / 전략 설계

### 2-1. 지표 카드 3개

| 카드 | 값 | 화면의 정의 (원문) |
|---|---|---|
| 👤 **브랜드 언급률** | 매우 높음 | *"현재 AI가 특정 브랜드를 언급하는 비율"* |
| ✅ **자사 언급 가능성** | 매우 높음 | *"우리 브랜드를 자연스럽게 언급시킬 수 있는 가능성"* |
| 📊 **종합 기회 점수** | **80점** | *"언급률과 언급 가능성을 종합한 투자 가치"* |

계산 구조:

```
브랜드 언급률   이 질문에 AI가 브랜드를 얼마나 꺼내는가   → 시장이 있나
언급 가능성     그중 우리를 끼워 넣기 쉬운가              → 뚫을 수 있나
              ↓ 둘을 합쳐
기회 점수 80점  이 질문에 돈을 쓸 값어치가 있나           → 할까 말까
```

[추정] SEO 의 「검색량 × 키워드 난이도 = 기회점수」를 옮긴 것으로 보인다.
근거는 두 입력의 성격(수요 크기 / 진입 난이도)과 산출물 이름(*"투자 가치"*)뿐이다.
**GPTO 문서에 이 식은 없다.** [인용 확인] gpto.kr 은 *"'기회 점수', '언급 가능성',
'삽입 난이도' 같은 구체적 지표명은 제시되지 않습니다"* — 화면에만 있는 이름이다.

**세 번째 칸 이름이 「투자 가치」인 것이 핵심이다.** 질문 50~200개를 다 잡을 수 없으니
**어디에 예산을 넣을지 고르는 화면**이고, 곧 대행 계약의 견적 근거가 된다.

### 2-2. 경쟁 브랜드 63개

[실측] `경쟁 브랜드 63개` + 배지 `경쟁 높음` + 펼침(∨).

1편 화면에서 읽힌 것은 29개 남짓이었다. 63개인 것은
[추정] ⓐ 1편이 상위만 보였거나 ⓑ 질문 4개 합산이다. 두 장만으로는 못 가른다.

**배지가 날숫자를 등급으로 바꾼다.** 카드 3개가 「매우 높음 / 매우 높음 / 80점」인 것과
같은 처리 — 숫자를 감추고 판정을 준다.

### 2-3. 종합 분석 (원문)

> *"전반적으로 프라이머는 질문의 특정 조건에 가장 부합하는 브랜드로 여러 AI 모델에서 이미
> 언급되어 있어, 높은 언급 가능성과 **낮은 삽입 난이도**를 보입니다. 경쟁 브랜드 수가
> 많지만, 프라이머의 '**명확한 투자 조건**'과 '**오랜 경험**'이라는 차별화된 강점을
> 활용하여 전략적으로 콘텐츠를 제작한다면 매우 유리한 위치를 점할 수 있습니다."*

**「삽입 난이도」** 는 카드 2번(언급 가능성)의 뒷면이다
= 이 질문의 AI 답변 안에 우리 문장을 밀어 넣는 게 얼마나 부자연스러운가.

### 2-4. 최적화 전략 방향성 (5개 중 3개 보임)

세 항목이 **완전히 같은 3단 구조**다.

| | ① AI가 지금 뭐라 하나 | ② 우리만 다른 것 | ③ 처방 |
|---|---|---|---|
| 1 | *"대부분의 AI 모델은 '1억 원 지분 10%'라는 구체적인 조건에 대해 **고정된 정찰제가 아님을 강조**하며, 각 투자사의 일반적인 시드 투자 범위와 지분 희석율을 제시하는 데 집중"* | 프라이머는 조건이 명확함 | *"'프라이머'의 고유한 강점을 부각할 수 있는 기회"* |
| 2 | *"많은 액셀러레이터와 초기 전문 VC들이 언급되고 있으나"* | *"프라이머처럼 '1억 원에 지분 10% 내외'라는 투자 조건을 **명시적으로 밝히는 곳은 드뭅니다**"* | *"'명확하고 투명한 투자 조건'을 제공하는 **업계 리더로 포지셔닝**"* |
| 3 | *"경쟁 투자사들의 경우, **투자 금액 범위는 언급되지만 지분율에 대한 구체적인 언급은 적습니다**"* | 지분율을 밝히는 유일한 곳 | *"초기 창업가들에게 **예측 가능성과 안정감**을 줄 수 있다는 점을 강조"* |

**여기가 GEO 와 SEO 가 갈리는 자리다.**

```
SEO   경쟁사보다 잘 쓴다      같은 주제, 더 길고 더 깊게
GEO   경쟁사가 안 쓴 걸 쓴다   답변에서 우리를 "구별할 이유"를 만든다
```

[추정] 왜 그런가에 대한 내 해석 — LLM 이 *"국내 시드 투자사 알려줘"* 에 답할 때는
후보를 나열하고 각각을 한 줄로 **구별**해야 한다. 63개 중 62개가 지분율을 안 밝히면,
밝히는 한 곳은 **모델이 문장을 만들기 쉬운 브랜드**가 된다.
빈칸을 채우는 게 아니라 **모델에게 우리를 쓸 문법을 쥐여주는 것**이다.
**이 설명은 GPTO 문서에 없다.** 답변 3단 구조가 전부 「경쟁사가 안 하는 것 → 우리만
하는 것」으로 짜인 데서 역산했다.

산다. 1편의 추이 그래프가 그 영수증이다.

> *"**두 경로 모두에 브랜드가 자리잡아야** ChatGPT 답변에 안정적으로 등장합니다."*

| | 학습 데이터 경로 | 실시간 검색 경로 |
|---|---|---|

[추정] 3~6개월은 모델 재학습 주기가 아니라 **검색 색인·인용 축적이 도는 시간**에 가깝다.

**정리 —** 「학습 데이터 발행」이라는 이름은 왼쪽 문을 가리키지만, 주 단위로 추이를
밀어 올리는 것은 오른쪽 문이다.

### 4-2. 왜 글이 3편인가 — 채널이 답이다

[인용] *"GPTO가 운영하는 **500+ 학습 채널**은 다음 카테고리로 분류됩니다:
**산업·시장 리포트 / 기술 블로그·미디엄·브런치 / 위키형 설명 페이지 / 비교·리뷰 사이트 /
디렉토리·인덱스 / 컨퍼런스·발표 자료 / 도서·논문 인용**"*

**1편에서 읽은 인용 출처 35개와 겹쳐보면 포개진다:**

| 1편의 인용 출처 | 위 카테고리 |
|---|---|
| `startuprecipe.co.kr/archives/invest-newsletter/…` | 산업·시장 리포트 |
| `bummblog.com/스타트업…` | 기술 블로그 |
| `slideshare.net/slideshow/ss-259836723` | **컨퍼런스·발표 자료** |
| `thevc.kr/smart-collections/…` | **디렉토리·인덱스** |
| `kr.linkedin.com/company/cnttech` | 디렉토리·인덱스 |

**GPTO 는 「AI 가 실제로 인용하더라」고 관측된 채널 유형에 그대로 되쏜다.**
관측(1편 ④) → 처방(이 화면 우측) → 배포 → 재관측. 고리가 닫힌다.

[추정] 글이 3편인 이유 — 리포트체·가이드체·논설체는 채널 유형이 다르다.
같은 사실을 각 채널의 문법으로 갈아 끼워야 500개에 뿌릴 수 있다.

**AI 답변을 검색순위처럼 재고, 경쟁사가 비워둔 사실 하나를 찾아,
AI 가 인용하던 채널 유형에 되쏘고, 다시 재서 선을 그린다.**

## 5. 위험 지점 — 자동 생성 글에 박힌 숫자

생성된 1번 글에 **"287건 이상의 시드 투자 실적"** 이 들어 있다. [실측, 화면 판독]

[실측] 검색 대조:

| 출처 | 값 |
|---|---|
| 나무위키 | *"설립일부터 현재까지 약 **195개 스타트업**에 투자"* |
| 검색 요약 | 초기 표준 조건 = 기업가치 5억 / 5천만 원 / 지분 9.09%, **Post-Value 10억 원** |
| ZDNet (2022-11-30) | *"프라이머, 스타트업 투자액 **최대 1억5000만원으로 상향**"* |

**모순이라고 단정하지 않는다.** "287건"(투자 **건수**, 후속 투자 포함 가능)과
"195개"(투자받은 **기업 수**)는 단위가 다르다. Post-money 10억 · 1억 원 조건은
2022년 상향 이후와 들어맞는다.

**짚을 것은 구조다** — 이 파이프라인은 고객사에 관한 구체적 숫자를 자동 생성해
500개 채널에 뿌린다. 숫자가 틀리면 틀린 사실이 AI 학습·인용 경로에 **굳는다.**
원래 글 수정보다 되돌리기가 훨씬 어렵다. **화면 어디에도 사람의 검수 관문이 보이지 않는다.**

| **처방을 「경쟁사가 안 쓴 것」에서 뽑는다** | VEO 는 "우리 페이지에 뭐가 없나"를 본다. **"경쟁사 답변에 뭐가 없나"** 는 안 본다 |
| **관측된 인용 채널 유형 = 배포 목표** | 1편 ④의 출처 목록을 유형으로 묶으면 그대로 실행 목록이 된다 |

**반대로 우리가 이길 자리 — 숫자 검수.**
GPTO 화면은 「매우 높음 / 매우 높음 / 80점」으로 근거를 감추고, 생성 글의 사실 확인
단계가 안 보인다. VEO 는 분모·잰 시각·근거 등급을 붙이는 규칙이 이미 있고, 의료 분야라
검수 관문이 필수다. **같은 파이프라인에 검수 한 칸을 더 넣는 것**이 차별점이 된다.
