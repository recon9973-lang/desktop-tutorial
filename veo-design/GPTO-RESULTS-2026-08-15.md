## 1. 이 화면이 무엇인가 — 왜 우리에게 특별한가

파이프라인의 마지막 칸, **성과 리포트**다. GPTO 가 파는 "before → after" 그 자체.

그리고 **사례가 안산 치과다.** 앞의 두 화면(프라이머·투자사)은 스타트업 사례였는데
성과 화면은 **병원 마케팅**이다 — VEO 가 겨냥하는 바로 그 시장.

교차 확인 둘:

* [계산] 추이 곡선 마지막 점 **3/2** ↔ 1편 화면의 측정 시각 **2026-03-03 12:41**.
  하루 차이 — 같은 데모 세트의 같은 시점 자료로 앞뒤가 맞는다.
* [실측] 머니투데이 보도(2026-04-30, 해시드 데모데이)의 *"5대 주요 LLM의 평균 언급률을
  10.8%에서 42.2%로"* — **회사 대표 성과 수치가 바로 이 안산 치과 한 건이다.**
  대외 헤드라인 숫자의 원본 화면이다.

## 2. 화면 4구역 분해

### ① 좌측 — 모니터링 질문 5개, 질문마다 before → after

| 질문 | 기존 → 현재 | 변화 |
|---|---|---|
| 안산에 **라미네이트** 잘하는 치과 알려줘 | 19% → 55% | +36p |
| **공휴일이랑 일요일에 진료**되는 안산 치과 추천해줘 | **0% → 55%** | **+55p** |
| 안산에 **임플란트** 잘하는 임플란트 전문 치과 알려줘 | 19% → 46% | +27p |
| 안산 치과들 중에 **임플란트 시술 경험 많은 곳** 추천해줘 | 9% → 40% | +31p |
| 안산에 **수면 마취** 잘하거나 **무통 임플란트** 되서 임플란트 안 아프게 할 수 있는 치과 있어? | **9% → 9%** | **0** |

읽히는 것 셋:

1. **질문이 환자의 말 그대로다** — "지역 + 시술 + 생활 조건(공휴일·일요일, 안 아프게)".
   1편 프라이머 사례와 같은 원칙: 브랜드명 없는 니즈 질문.
2. **0% 질문이 가장 크게 올랐다.** [추정] AI 가 인용할 문서가 웹에 없던 "빈 질문"은
   문서를 넣는 순간 즉시 잡힌다 — 2편의 「삽입 난이도」가 낮은 자리. 경쟁 콘텐츠가
   이미 두꺼운 라미네이트·임플란트(+27~36p)보다 빈 질문(운영 정보)이 더 빨리 오른다.
3. **9% → 9% 실패 줄을 지우지 않고 그대로 뒀다.** [추정] ⓐ 진짜 못 올렸거나(수면마취·
   무통은 §5 의 의료광고법 지뢰밭이라 콘텐츠를 못 만들었을 수 있다) ⓑ 일부러 남겼거나.
   어느 쪽이든 **실패 줄 하나가 나머지 넷의 신뢰도를 올리고, 동시에 다음 계약 거리가 된다.**

### ② 우측 상단 — 전체 대시보드 · 주차별 전체 언급률

[실측] `질문: 5 · 모니터링 기간: 8주` · Y축 3% / 26% / 49% ·
X축 12/29 · 1/5 · 1/12 · 1/19 · 1/26 · 2/9 · 2/16 · 2/23 · 3/2

곡선의 모양 [실측, 화면 판독]:

```
10% 근처 출발(12/29) → 1월 완만한 상승·출렁임 → 2월 26~30% 정체
→ 마지막 구간(2/23→3/2) 42% 급등
```

[추정] 1월 상승 = 검색 색인이 잡히기 시작(2편의 "오른쪽 문") · 2월 정체 = 쉬운 질문
소진 · 막판 급등 = 늦게 색인된 콘텐츠 묶음이 한꺼번에 잡혔거나 — 영상 촬영 직전
회차라는 점은 적어만 둔다.

### ③ 중앙 — 전체 언급률 한 줄

```
전체 언급률:  10.8%  (+31.4%p)  →  42.2%
```

10.8 + 31.4 = 42.2 — 표기 자체는 정합. 검산은 §3.

### ④ 우측 하단 — AI 모델별 언급률 (레이더 + 표)

| 모델 | 기존 | 현재 | 변화 |
|---|---|---|---|
| ChatGPT | **0.0%** | 30.0% | +30.0p |
| Gemini | **0.0%** | 40.0% | +40.0p |
| Claude | **0.0%** | 30.0% | +30.0p |
| Grok | **40.0%** | 50.0% | +10.0p |
| Perplexity | **40.0%** | **80.0%** | **+40.0p** |

**이 화면에서 가장 원리적인 표다.** 출발선이 두 패로 갈린다:

```
검색이 본체인 엔진   Grok 40% · Perplexity 40%   ← 이미 웹에 있던 치과라 처음부터 잡혔다
LLM 이 본체인 엔진   ChatGPT·Gemini·Claude 0%    ← 웹에 있어도 "AI 기억"엔 없었다
```

이 치과는 **웹 존재감은 있는데(검색계 40%) AI 존재감은 0인(순수 LLM 0%)** 상태에서
출발했다 — 2편 "두 개의 문" 원리의 실물 증거. 8주 뒤 검색이 본체인 Perplexity 가
80% 로 가장 높다. **콘텐츠를 뿌리는 전략은 검색 경로가 있는 엔진에서 먼저, 크게 듣는다.**

[추정] 0% 였던 셋이 8주 만에 30~40% 가 된 것은 모델 재학습이 아니라 **그 모델들의
웹서치 변형이 잡기 시작한 것**으로 읽는 게 자연스럽다. 순수 LLM 의 "머릿속"이 8주에
바뀌지는 않는다. 이 표가 켬/끔 합산이라면 1편 화면에서는 나눠 보여줬던 구분이 성과
화면에서 뭉개진 것이다.

## 3. 숫자 검산 — 실행한 계산 [계산, python 으로 검산]

### 3-1. 전체 언급률 10.8 / 42.2 는 어느 평균과도 안 맞는다

| 평균 방법 | 기존 | 현재 |
|---|---|---|
| 질문 5개 평균 | 11.2% | 41.0% |
| 모델 5개 평균 | 16.0% | 46.0% |
| **화면 표기** | **10.8%** | **42.2%** |

모순은 아니다 — [추정] 전체 언급률은 질문×모델×반복의 **전체 격자**에서 직접 센 값이고,
질문별·모델별 % 는 각자의 부분 격자라 반올림·가중이 다르다. 1편 §3-3(정수와 % 의 분모가
다르다)과 같은 현상. **다만 이번에도 분모는 화면 어디에도 없다.**

### 3-2. 기간 표기가 달력과 어긋난다

* [계산] 12/29 → 3/2 = **63일 = 9.0주**. 화면 표기는 **"8주"**. 구간(9개)을 셌는지
  회차(10개)를 셌는지에 따라 다를 수 있으나, 표기와 달력이 한 주 어긋난다.
* [실측] X축에 **2/2 가 없다**(1/26 다음이 2/9). 눈금 생략인지 그 주 측정이 빠진 건지
  이 화면으로는 못 가른다.

## 4. 3부작이 완성한 고리

```
① 기준선(12/29)   질문 5개 × 5모델 → 10.8%        = Diagnostics (2편 좌측)
② 발행            질문별 겨냥 콘텐츠 → 500+ 채널     = 2편 우측 「학습 데이터 발행」
③ 주 1회 재측정    같은 질문·같은 모델 반복 호출      = 1편 「모니터링」
④ 점을 선으로      8~9주 쌓아 42.2%                = 이 화면
⑤ 안 오른 질문     9% → 9%                        = 다음 사이클의 일감
```

**이 화면이 파는 것은 42.2% 가 아니라 +31.4%p 다.** 상태가 아니라 변화 —
`UX-RENEWAL:220` 그대로. 레이더가 주황(기존) 위에 초록(현재)을 겹치는 것도 같은 문법:
**면적이 커지는 그림**을 고객에게 준다.

## 5. 이 화면의 약점 — 검산했으니 보이는 것

| | 무엇 | 왜 문제인가 |
|---|---|---|
| 1 | **분모가 어디에도 없다** | 10.8/42.2 는 어떤 평균과도 안 맞고, 질문별 19%·9% 의 분모(반복 × 모델)도 없다. 검증 불가능한 성과 숫자다 |
| 2 | **기간 표기가 달력과 어긋난다** | "8주" vs 실측 63일(9.0주), X축 2/2 실종 |
| 3 | **켬/끔 구분이 성과 화면에서 사라졌다** | 진단(1편)에는 있던 구분이 합산 — 성과가 검색 경로 효과인지 AI 기억 효과인지 고객이 알 수 없다 |
| 4 | **급등이 마지막 회차다** | 2/23→3/2 한 구간이 상승분의 큰 몫. 한 회차 변동인지 지속 수준인지 모른다 |

## 6. VEO 관점 — 셋 중 가장 직접적인 화면

### ① 시장이 겹쳤다

안산 치과 = 지역 병원 마케팅. GPTO 가 우리 앞마당에서 이미 성과 리포트를 팔고 있다.
우리에게는 같은 종류의 실측이 이미 있다 —
`veo/docs/research/2026-08-11-chamsarang-masan-measurement.md` (마산 치과 측정).
**직접 비교 가능한 자료가 양쪽에 존재한다.**

### ② 질문 5개는 그대로 우리 질문 세트의 본보기다

"지역+시술+생활조건" 구조. 특히 **운영 정보 질문(공휴일 진료)이 가장 크게 오른다**는
관찰은 질문 설계 연구(`2026-08-12-three-ways-to-make-questions.md`)에 바로 얹을 수 있다.

### ③ 의료광고법 — 여기가 갈림길이다

이 화면의 질문 문구를 그대로 콘텐츠로 만들면:

| 문구 | 걸리는 자리 |
|---|---|
| *"임플란트 **잘하는**"* · *"시술 경험 **많은** 곳"* | 비교·최상급 표현, 치료경험 광고 — 의료법 제56조가 제한하는 자리 |
| *"**안 아프게**"* · *"무통 임플란트"* | 치료효과 보장으로 읽힐 소지 |

2편 §5 에서 "사람의 검수 관문이 안 보인다"고 적었는데, **병원 사례에서는 그것이 품질
문제가 아니라 법 위반 위험이 된다.** 5번 질문(수면마취·무통)이 9%→9% 로 못 오른 것도
[추정] 이 문구로는 심의를 통과할 콘텐츠를 만들기 어렵다는 것과 무관하지 않을 수 있다.

**GPTO 의 범용 파이프라인이 병원 시장에서 막히는 지점 = VEO(의료 검수)가 서는 지점.**

### ④ 분모·시각 규칙

§5 의 약점 넷은 전부 "분모 없음 · 시각 없음 · 구분 소실"이다. 우리 규칙(분모 · 잰 시각 ·
근거 등급 병기)을 지키면서 같은 before→after 문법을 쓰면 **팔리는 화면이면서 검증되는
화면**이 된다 — `UX-RENEWAL` 원칙 3 이 말한 자리.
