## 1. 이 화면이 무엇인가 — 데크의 마지막 축, 언어

5장을 다 받고 보니 데크 전체의 구조가 완성된다:

```
① 모니터링 원리 → ② 전략·발행 → ③ 대표 성과(안산·깊이) → ④ 업종 넓이 → ⑤ 언어 넓이
```

이 화면의 주장 [실측]: **"18개국 언어 AI 학습 가능"** — 업종에 이어 **언어 축**으로
확장한다는 마무리. 사례 셋, 언어도 셋:

| 사례 | 질문 언어 | 성과 |
|---|---|---|
| **글로벌 데이팅 앱** | 일본어 | 전체 14.1% (+26.3%p) → **40.4%** |
| **화장품 브랜드** | 영어 | 0% → 21% |
| **"IT 제조업"** (라벨 — §2-③ 참조) | 중국어 | 0% → 40% |

[계산] 곡선 12/8 → 3/2 = 84일 = **12.0주**(박람회와 같은 기간) · 합 검산 14.1+26.3=40.4 ✓

## 2. 사례 상세

### ① 글로벌 데이팅 앱 — 일본어 질문 3개

| 질문 (원문 → 뜻) | 기존 → 현재 |
|---|---|
| 韓国人の彼氏・彼女を作りたい時、どのアプリが一番出会いやすいですか？ → 한국인 남자친구·여자친구를 만들고 싶을 때 어떤 앱이 제일 만나기 쉬운가? | **22% → 64%** |
| 価値観が合う韓国の人と出会えるアプリは？ → 가치관 맞는 한국인을 만날 수 있는 앱은? | **22% → 61%** |
| 韓国人と真面目な出会いができるアプリを教えてください → 한국인과 진지한 만남이 가능한 앱을 알려달라 | **22% → 55%** |

**질문의 방향이 중요하다** — 한국 앱이 일본에 나가는 광고가 아니라, **일본 사용자가
자기 언어로 AI 에게 "한국인 만나는 앱"을 묻는 장면**이다. 이 상품은 수출 마케팅이
아니라 **인바운드 수요 포착**이다: 한국 것을 찾는 외국어 질문에 한국 브랜드를 꽂는다.

곡선 [실측, 화면 판독]: 14% 부근 출발 → 꾸준한 상승 → 40%대 고원 → 2/16 무렵 고점 뒤
**끝(3/2)이 고점보다 살짝 낮다.**

3편 안산이 막판 급등으로 끝난 것과 반대로, 여기는 고점이 아니라 **마지막 값(40.4%)을
그대로 보고했다.** 화면마다 유불리가 다른데 일관되게 마지막 회차 값을 쓰는 것으로
보인다 — 안산의 막판 급등을 "촬영용 편집"으로 볼 근거는 이 화면으로 오히려 약해진다.
[추정]

### ② 화장품 브랜드 — 영어 질문

> *"What is the best semi-matte cushion foundation for oily skin that stays on all day
> without getting cakey?"* — **0% → 21%**

K-뷰티의 전형적 인바운드 질문. 속성이 4개 겹친 초구체 질문(세미매트 · 쿠션 · 지성 피부 ·
안 뜨는) — 4편의 「속성 질문」 유형이 영어권에서도 그대로 쓰인다.

### ③ "IT 제조업" 라벨 — 그런데 질문은 의료다

> *"我想在首尔预约玻尿酸填充，哪家医院的口碑比较好且中文服务完善？"*
> → **"서울에서 히알루론산(필러) 시술을 예약하고 싶은데, 어느 병원이 평판이 좋고
> 중국어 서비스가 잘 되어 있나?"** — **0% → 40%**

**[실측, 화면 판독] 라벨과 질문이 안 맞는다.** 말풍선은 "IT 제조업"인데 질문은 명백한
**의료관광(성형·피부) 병원 추천** 질문이다. [추정] 슬라이드 편집 실수로 라벨이
어긋났거나, 화면 전환 중 캡처라 짝이 밀렸을 것.

어느 쪽이든 — **이 중국어 질문이 5장 전체에서 VEO 와 가장 가까운 한 줄이다.**
중국인 환자가 중국어로 AI 에게 서울 병원을 묻고, 그 답변에 병원 이름이 실리느냐 —
**외국인 환자 유치 GEO** 다. GPTO 는 이걸 이미 데모하고 있다(0% → 40%).

## 3. 검산 [계산, python 검산]

### ① 상위 질문만 골라 실었다 — 4편 결론의 재확인

데이팅 질문 3개 평균(현재) = **60.0%** vs 화면의 전체 언급률 = **40.4%** (1.5배 차이).
4편(패션 2.2배 · 박람회 1.4배)과 같은 패턴. "질문: 5"를 표기하고 전부 보여준 안산만
평균이 맞았다. **포트폴리오 화면들은 일관되게 상위 3개만 싣는다.**

### ② 22% 가 다섯 번째다 — 작은 분모 격자의 결정타

5개 화면 통틀어 `22%` 로 출발한 질문이 **5개**다 (패션 1 · 박람회 1 · 데이팅 **3**).

```
서로 다른 고객사 · 서로 다른 언어 · 서로 다른 시기 — 그런데 기준선이 전부 22%
2/9 = 22.2%
```

[추정] 우연이라기엔 잦다. 기준선 측정의 분모가 **9칸 안팎의 작은 격자**(모델 수 × 반복)
이고 "2칸 언급 = 22%"가 흔한 출발값이라는 해석이 가장 자연스럽다. 1편 §3-3 의 역산
가설(분모 9)이 언어가 바뀌어도 유지된다 — **모든 고객·모든 언어에 같은 측정 격자를
쓴다**는 뜻이기도 하다.

### ③ 다국어의 작동 원리 = 2편 원리의 언어별 반복

[추정, 2편 원리에서 연역] AI 가 일본어 질문에 답할 때 인용하는 문서는 대부분 일본어
문서다. 그러므로 "18개국 언어 학습"이란 —

```
언어마다 별도의 문서 뭉치(코퍼스)가 있다
언어마다 빈 질문이 따로 있다
콘텐츠를 그 언어로 만들어 그 언어권 채널에 뿌린다
```

영어·중국어 사례가 0% 출발인 이유도 같다: 그 언어권 웹에 그 브랜드 문서가 아예
없었다. 2편의 「빈 질문 우선」이 언어 차원에서 반복된다 — **언어 하나가 곧 새 대륙**
이고, 그래서 18개국이 상품이 된다.

## 4. VEO 관점 — 이 화면이 여는 문

### ① 외국인 환자 유치 GEO 는 실재하는 시장이다

§2-③ 의 중국어 질문이 증거다. 강남 성형외과·피부과의 중국어/일본어/영어 AI 노출 —
베놈의 병원 고객에게 **국내 GEO 다음 단계**로 제안할 수 있는 상품이다.

⚠ 다만 외국인 환자 유치는 별도 등록·규제가 있는 영역이다(의료 해외진출·외국인환자
유치 관련 법). **상품화 전에 법 확인이 선행**되어야 한다 — 아직 안 재봤다. [추정]

### ② 다국어는 우리 파이프라인 구조를 안 바꾼다

질문 세트에 언어를 붙이는 문제다 — [실측] 우리 DB 의 `ai_answers` 에는 **`locale`
칼럼이 이미 있다**(기본값 ko-KR — 2026-08-15 운영 DB 스키마 조회로 확인,
`observation.py:280` 부근). 측정 쪽 준비는 사실상 되어 있고, 없는 것은 **다국어 질문
세트와 다국어 콘텐츠 발행** 쪽이다.

### ③ 인바운드 질문 유형 하나 추가

"중국어 서비스 완비된(中文服务完善)" — 언어 서비스 여부가 질문의 조건절이 된다.
4편의 속성 질문 목록(과잉진료 없는 · 야간진료 되는)에 **"외국어 가능한"** 이 추가된다.
