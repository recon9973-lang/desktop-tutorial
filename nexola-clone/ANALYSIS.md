# 레퍼런스 분석 & 재구현 설계 노트

> 원본(Nexola, 상용 Framer 템플릿)을 **화면 녹화 프레임으로 관찰**하여 디자인·인터랙션·구조를 분석한 문서.
> 결과물은 원본 자산/코드를 복제하지 않고, 관찰한 **패턴을 바탕으로 새로 작성한 오리지널**이다.
> (플레이스홀더 브랜드: **MERIDIAN®** · 오픈라이선스 시스템 폰트 스택 · 자체 제작 플레이스홀더 이미지)

---

## 1. 사이트 정체성
- **유형:** 크리에이티브 웹디자인 / 브랜딩 스튜디오 원페이지 + 프로젝트 상세페이지
- **톤:** 미니멀 · 에디토리얼 · 하이엔드. 라이트(오프화이트) 본문 + 다크(블랙) 섹션 교차
- **핵심 무기:** 초대형 네오그로테스크 디스플레이 타이포, 넉넉한 여백, 시네마틱 흑백 사진

## 2. 레이아웃 시스템
- **그리드:** 4컬럼, 컬럼 사이 **헤어라인(1px)** 세로 규칙이 보임 → 스위스 그리드 감성
- **거터/마진:** 큰 외곽 여백. 콘텐츠는 그리드 셀에 정렬(헤딩은 2번째 컬럼부터 시작하는 비대칭 배치)
- **섹션 리듬:** 큰 헤딩 → 여백 → 콘텐츠. 다크/라이트 교차로 스크롤 대비 형성

## 3. 타이포그래피
- **디스플레이:** 헬베티카 계열 네오그로테스크, `font-weight:800~900`, **음수 자간**, `line-height≈0.95`
- **투톤 헤드라인:** 블랙 + 미드그레이 조합 (예: "An Ambitious Team / for Your Vision.")
- **라벨:** 소문자 + 괄호 표기 `(Links) (Socials) (Contact) (Phone)`, `letter-spacing` 넓게
- **본문:** 소형 그로테스크, 중성 그레이, 1.5 행간

## 4. 컬러 토큰(관찰 근사값)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#F4F3F1` | 라이트 본문 배경(약간 웜) |
| `--ink` | `#0B0B0B` | 텍스트/다크 섹션 |
| `--muted` | `#8A8A8A` | 보조 텍스트 |
| `--line` | `#E3E2DE` | 헤어라인 |
| `--dark` | `#0A0A0A` | 다크 섹션 배경 |
| `--on-dark` | `#F4F3F1` | 다크 위 텍스트 |

## 5. 컴포넌트
- **알약 버튼:** 라운드 풀(pill), 다크필+화이트텍스트 / 고스트 화이트. 우측 소형 아이콘(원·화살표·달력)
- **회전 뱃지:** 히어로 우측 작은 원형 회전 요소(스크롤 큐)
- **프로젝트 카드:** 풀블리드, 좌측 이름/분야, 우측 화살표. 호버 시 이미지 리빌
- **스탯 블록:** 초대형 숫자(3x/2x/5k/6x) + 소형 캡션
- **아코디언:** 우측 정렬 질문 리스트 + `+` 토글
- **뉴스레터 폼:** Name/Email + Subscribe 풀 버튼

## 6. 인터랙션 (관찰된 모션)
| 인터랙션 | 관찰 | 재현 방식 |
|---|---|---|
| 히어로 이미지 리빌 | 로드 시 어두운 실루엣→밝기·스케일 진입 | CSS keyframes(brightness+scale) |
| 스크롤 리빌 | 헤딩/블록이 아래서 페이드업 | IntersectionObserver + transform |
| 스티키 헤더 | 상단 고정, 스크롤 시 배경/상태 변화 | scroll 방향 감지 토글 |
| 메뉴 오버레이 | 햄버거 → 풀스크린 메뉴 | overlay + stagger 링크 |
| 프로젝트 호버 리빌 | 카드 호버 시 이미지 등장 | opacity/clip 트랜지션(데스크탑 한정) |
| 마그네틱 버튼 | 커서 근접 시 버튼 미세 이동 | pointermove translate |
| 회전 뱃지 | 무한 회전 | CSS rotate infinite |
| 아코디언 | 높이 확장 + 아이콘 회전 | grid-rows/height 트랜지션 |
- **접근성:** `prefers-reduced-motion` 존중, 포커스 링 유지

## 7. 구조(라우트)
```
/                 홈(원페이지: 히어로→인트로→프로젝트→스탯→후기→FAQ→컨트랙트→뉴스레터/푸터)
/projects/<slug>  상세(대형 히어로→스탯→풀블리드 이미지→공용 푸터)
```

## 8. 폴더 트리(재구현)
```
nexola-clone/
├─ index.html            홈
├─ projects/velora.html  상세 예시
├─ assets/
│  ├─ css/styles.css      디자인 토큰 + 전 컴포넌트
│  ├─ js/main.js          전 인터랙션
│  └─ img/                플레이스홀더(README)

└─ README.md
```

## 9. 원본 대비 의도적 차별점(저작권 안전)
- 브랜드/카피/이미지/코드 **전부 신규 작성** (원본 텍스트·사진·Framer 코드 미사용)
- 폰트는 **시스템 네오그로테스크 스택**(헬베티카/Arial)으로 라이선스 프리
- 이미지는 **CSS 듀오톤 플레이스홀더**로, 실제 촬영/생성 자산으로 교체하는 슬롯 구조
