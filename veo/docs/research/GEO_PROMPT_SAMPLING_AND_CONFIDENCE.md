# 프롬프트 표본과 신뢰도 설계

## 프롬프트 우주

프롬프트를 URL에서 자동 생성하는 것만으로 끝내지 않는다. 다음 층을 함께 구성한다.

- 퍼널: 문제 인식 / 정보 탐색 / 비교 / 추천 / 구매·방문 / 사후지원
- 의도: 정의 / 방법 / 최고·추천 / A 대 B / 가격 / 지역 / 신뢰·안전
- 주체: 브랜드명 포함 / 비브랜드 / 경쟁사 포함 / 카테고리 포함
- 사용자: 초보 / 실무자 / 의사결정자 / 지역·업종별 페르소나
- 언어·지역: 한국어·영어, 국가, 도시, 통화·법규 맥락

각 프롬프트에 사업 중요도와 예상 수요를 0~1로 부여하되, 추정치와 실제 검색량 데이터를 구분한다.

## 실행 단위

반드시 저장할 필드:

`prompt_id, prompt_text, intent, funnel, locale, engine, model/version, search_mode, account_state, timestamp, run_id, raw_answer, citations, mentioned_entities, errors`

## 반복 측정

- 탐색 진단: 프롬프트×엔진당 최소 3회
- 비교 보고: 5회 이상 권장
- 변동이 큰 질문 또는 중요 질문: 표본을 늘려 비율의 불확실성을 축소
- 모든 반복은 같은 날 한꺼번에 몰지 말고 시간대를 분산할 수 있도록 설계

비율 지표에는 Wilson 구간 같은 이항 신뢰구간을 표시한다. 표본이 작으면 소수점 정밀도를 줄이고 `방향성`으로 표기한다.

## 공정한 경쟁 비교

동일한 프롬프트 집합, 엔진, 모델·검색 모드, 지역·언어, 기간, 반복 횟수를 적용한다. 브랜드 별로 유리한 질문만 선택하지 않도록 표본 생성 규칙과 제외 사유를 기록한다.

## 변경 효과 검증

1. 변경 전 기준선 수집
2. 변경 URL·내용·배포 시각 기록
3. 크롤러 재방문·색인 반영 확인
4. 동일 표본으로 재실행
5. 가시성 변화와 변동성을 함께 비교
6. 계절성·모델 변경·검색 결과 변화 등 외부 요인을 표시

단순 전후 차이를 인과효과로 단정하지 않는다. 가능하면 미수정 URL/주제를 비교군으로 둔다.
