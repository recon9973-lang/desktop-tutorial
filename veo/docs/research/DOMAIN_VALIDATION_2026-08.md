# 실도메인 8개 검증 — VEO 1.8.0 실측과 구글 대조 (2026-08-01)

v3 구현에 들어가기 전, 발행 명세 1.8.0 과 실코드 파이프라인을 실제 도메인 8개로
검증했다. 사용자가 지정한 도메인이며, VEO 는 전체 크롤(상한 100장) + PageSpeed
실험실 상위 5장, 구글은 Lighthouse(= PSI 웹 UI 그 점수) 랜딩 1장 기준선이다.

측정 자료 원본: 세션 스크래치패드 `results/`·`results_lighthouse/` (JSON, 검사
단위 판정 포함). 이 문서의 모든 숫자는 그 파일에서 나왔다.

## 2. 알고리즘 완성도 — 검증 3종

표본 8개로 지도학습식 ML 은 수학적으로 무의미하다(0-C: 과적합·기준 정답 부재).
대신 성립하는 검증을 돌렸다.

### A. 재현성 — 8/8 완전 일치

저장된 검사 판정을 실코드 평가기에 다시 넣으면 **소수점 여섯째 자리까지 같은 점수**가
나온다. 점수가 결정적(deterministic)이라는 계약의 실측 확인.

### B. 교차 구현 — 독립 구현 2벌의 일치

같은 판정을 v3 프로토타입(실코드와 별도로 작성된 참조 구현)에 넣었다.
8개 도메인 최대 차이 **0.005점** — 프로토타입이 점수를 소수 둘째 자리로 반올림해
생기는 표시 차이가 전부다. 산식 자체는 두 구현이 일치한다.

### C-1. 강건성 — 배점 ±25% 몬테카를로 교란 1,000회

배점이 "그 값이어야만" 성립하는 순위인지 검사했다. 49개 검사 배점 각각에
±25% 균등 잡음을 넣어 1,000회 재채점:

```
평균 Kendall tau      0.958   (1.0 = 순위 완전 보존)
순위 완전 동일         47%
가장 자주 뒤집힌 쌍    seo.co.kr ↔ venomad.com (428/1000회)
                      → 점수차 0.14점. 뒤집히는 게 정상인 동점 수준
```

**결론: 순위는 배점의 미세 조정에 강건하다.** 뒤집히는 쌍은 전부 점수차 2.3점
이하의 근접 쌍이고, 그 이상 벌어진 쌍은 1,000회 중 한 번도 뒤집히지 않았다.
배점 하나하나의 정밀도가 아니라 **구조(관문·단계·범위)가 순위를 결정한다**는 뜻 —
구글 근거 대조(§5.3, SEO_SCORING_V3_PAGES.md)에서 "다음 판 후보"로 남긴 배점
조정이 순위를 흔들 위험도 낮다.

### C-2. 구글과의 순위 상관 — ρ = 0.286, 그리고 그 숫자를 믿으면 안 되는 이유

Spearman 상관이 낮게 나왔다. 그러나 §4 의 측정 오염을 감안해야 한다 — 7개 중
3개(venomad·good-tour·markepick)의 구글 점수는 사이트의 성질이 아니라 **호스팅
봇 차단이 구글의 측정을 방해한 결과**였다. 오염을 빼면 표본 4개라 상관계수를
말하는 것 자체가 무의미하다(0-C). 이 숫자는 결론이 아니라 기록이다.

## 3. 구글 100점 대 VEO 76점 — #39 영업 논거의 실측 재확인

```
chamsarang1075.com   구글 SEO 100 (랜딩 1장·10항목)
                     VEO 76.4 (100장·59항목)
                       - canonical 문제      40/100장
                       - title 중복          55/100장
                       - 메타설명 품질        60/100장
                       - 고아 페이지          43/96장
seo.co.kr            구글 SEO 100
                     VEO 83.4 (고아 페이지 56/101장, h1 없음 60/104장)
```

**구글이 틀린 것이 아니라 본 페이지 수가 다르다** — 이 문장이 다시 실측으로
확인됐다. 구글은 랜딩 1장에서 10개 감사를 통과시켰고 실제로 그 1장은 깨끗하다.
나머지 99장의 문제는 구글 점수에 존재하지 않는다.

## 4. 구글 점수가 오염된 3개 도메인 — 73점의 정체

venomad·good-tour·markepick 세 도메인이 **똑같은 감사 3개**(meta-description ·
http-status-code · robots-txt)에서 실패하며 나란히 73점을 받았다. 우연이 아니다.
구글이 실제로 잰 최종 URL 에 단서가 있다:

```
venomad_com    → https://www.venomad.com/?ckattempt=3
markepick_com  → https://markepick.com/?ckattempt=2
good-tour_kr   → https://www.good-tour.kr/?ckattempt=3
```

`ckattempt` 는 호스팅의 쿠키 검사(봇 차단) 리다이렉트다. Lighthouse 가 차단
페이지를 잰 것이고, 세 감사의 실패는 그 차단 페이지의 성질이다. 직접 확인:
venomad 의 www robots.txt 는 200 text/plain 으로 멀쩡하다. VEO 크롤러는 정상
통과해 100장을 받았다.

**의미: 랜딩 1장 측정은 그 1회의 fetch 가 오염되면 점수 전체가 오염된다.**
100장 크롤은 한두 장의 fetch 실패가 coverage 로 희석된다. LIGHTHOUSE_COMPARISON
§5 가 문서로 지적한 "구글은 잴 때마다 흔들린다"의 세 번째 실측 사례.

## 5. grand1.co.kr — 구글은 침묵하고 VEO 는 진단했다

HTTPS 인증서가 자체 서명이라 모든 브라우저가 경고를 띄운다. 구글 Lighthouse 는
https 로도 http 로도 `lighthouseUserError` — **아무 점수도 내지 못했다.**

VEO: https 는 크롤 거부(정직한 502), http 로 진단하면 **31.5점 + 상한
`https_or_mobile_failure`(60) 적용** — https_valid FAIL(1/1), canonical 전 페이지
문제, 메타데이터 중복 105/106장, 모바일 뷰포트 없음 98/106장. 고객에게 건넬 조치
목록이 나온다. **측정 불능과 낙제점은 다르고, 후자가 팔 수 있는 진단이다.**

## 6. 이 검증이 드러낸 VEO 자신의 결함 — 구현 ① 의 실측 근거

8개 도메인 **전부** 크롤이 100장 상한에 잘렸다(`discovery_exhausted=False`).
그 상태에서:

```
crawl.no_broken_internal_links = PASS   ← 8개 도메인 전부
```

**본 것은 100장뿐인데 "깨진 내부 링크가 없다"고 단정했다.** 0-A 위반이 실제
데이터에 8건 나온 것이다 (다른 부재형 검사 3개는 이번 표본에서 위반이 '발견'되어
FAIL 이라 이 결함이 드러나지 않았을 뿐, 같은 경로를 쓴다).

v3 설계(SEO_SCORING_V3_PAGES.md §2)가 정확히 이 결함의 수정을 구현 1순위로
잡고 있다. 이 검증으로 그 우선순위가 이론이 아니라 실측이 됐다.

## 7. 하지 못한 것 (정직하게)

- **NEXT-T 진단 도구와의 직접 대조** — 로그인·유료 계정이 필요하고, 로그인 화면에
  비밀번호를 넣지 않는 것이 규칙이다. 대신 그들의 자사 사이트(next-t.co.kr)를 VEO
  로 쟀고(88.0), 이전 참사랑한의원 12항목 나란히 대조(세션 기록, 오탐/누락/얕은
  판정 3건 전부 VEO 우세)를 근거로 남긴다.
- **지도학습 ML 검증** — 표본 8개, 정답 순위 없음. 하면 그럴듯한 숫자가 나오고
  그 숫자는 거짓말이다. 몬테카를로 강건성·교차 구현 일치·재현성으로 대체했다.
- **Lighthouse 점수의 분산** — 랜딩 1장 1회 측정이다. 구글 실험실 점수는 실행마다
  흔들린다는 것을 우리가 먼저 문서화했으므로(1.00↔0.92), 위 구글 점수도 ±수 점의
  잡음을 가진 단일 표본으로 읽어야 한다.
