# §0. 목적 — 이 프로그램이 무엇인가

사장님 원문 (2026-08-09):

> **"SEO GEO AI대답 프로그램을 만들고 싶어. 할루시네이션이나 추측없이 실측으로
> 거래처에 서비스를 제공하는 프로그램을 만들고 싶어. 간단하자나.
> SEO GEO는 url기반으로 AI대답은 질문 기반이야. 그냥 그정도야."**

풀면 넷이다.

```
①  SEO      URL 을 받아 잰다
②  GEO      URL 을 받아 잰다
③  AI 답변   질문을 받아 잰다
④  전달      거래처가 볼 수 있게 낸다
```

**③ 의 질문은 하늘에서 오지 않는다** (사장님 2026-08-09):

> *"키워드에서 관련 질문이 나오고 키워드 마인드맵이 나오고 관련 PAA 지식iN 같은 곳에서
> 질문을 추출하게 만들고 싶었어."*

```
키워드 ──▶ 연관 키워드 ──▶ 마인드맵 ──▶ PAA·지식iN 질문 추출 ──▶ 질문 집합 ──▶ 관측
```

**그래서 키워드는 목적 밖이 아니라 ③ 의 앞단이다.** 한 번 목적 밖으로 잘못 갈랐다
(`CORRECTIONS.md` #23) — *"url 기반도 질문 기반도 아니다"* 라고 읽었는데, 그 문장은
**무엇을 재는가**를 말한 것이지 **무엇이 그 앞에 오는가**를 말한 것이 아니었다.

그리고 **넷 모두를 관통하는 하나** —

```
⑤  실측만 낸다.  재지 않은 것을 낸 값으로 만들지 않는다.
```

**⑤ 가 이 제품의 값이다.** ①~④ 는 경쟁사도 판다. ⑤ 를 지키는 곳은 업계 여덟 곳 중
한 곳뿐이다(`research/2026-08-09-geo-dashboard-benchmark.md` §4).

## 이 목적이 실제로 거절하는 것

| 하고 싶어지는 것 | 왜 안 되나 | 어디에 박아 뒀나 |
|---|---|---|
| 못 잰 값을 `0` 으로 | `0` 은 "쟀는데 없다" 다. 정반대 | ADR 0002 · 화면 전부 `—` |
| 보기 좋게 반올림 | 잰 값을 버리는 일 | `test_measurement_integrity.py` · `score-display.test.ts` |
| 조건이 다른 두 값을 나란히 | 우리가 자를 바꾼 일이 개선으로 읽힌다 | ADR 0010 · 거래처 화면 |
| 표본 3회짜리에 소수점 | 표본이 감당 못 하는 정밀도 | `sampling.py` Wilson 구간 |
| 이유를 지어내기 | 사실이 맞아도 이유가 거짓이면 거짓 | `CORRECTIONS.md` #7·#19·#22 |

# §1. 확정 — 다시 묻지 않는다

## 1-A. AI 답변 관측 설계

출처: `docs/observation-engine.md` §9 — *"확정된 운영 설계 (사장님 결정 2026-08-08)"*

```
주기      핵심 질문 주 1회 · 확장 질문 월 1회
기본값    핵심 5~8개 · 확장 20개 안팎
엔진      5개 동일 횟수. 비중 조절 금지
반복      3회 · 검색 켬 + 끔 (Perplexity 는 끔 없음)
수동측정  kind=MANUAL 별도 저장 · 추이에서 제외
모델      gpt-5 (gpt-4o 계열은 검색 호출 금액을 낼 수 없다)
```

**정밀도** [계산] `MoE = 1.96 × √(p(1−p)/n)`, `p = 0.5`:

| 보는 값 | n | 오차 폭 | 어떻게 읽나 |
|---|---|---|---|
| 핵심 5개 전체 언급률 | 150 | **±8.0pp** | 거래처에 보고해도 되는 값 |
| 핵심 8개 전체 언급률 | 240 | **±6.3pp** | 〃 |
| 질문 하나 | 30 | ±17.9pp | 방향만 |
| 질문 × 엔진 한 칸 | 6 | ±40.0pp | 이 칸으로 단정 금지 |

**비용**: 질문 1개 1회 = **854원** · 거래처 1곳 월 **2.8~4만** · 8곳 월 **22~32만**

## 1-B. 일하는 순서

*"진단 업체 등록 - 자동 진단 - 데이터 수집 - 업체별 대시보드에 수집 진단 결과
노출(이 단계에 출력 시스템 붙임)"* — 리포트 발행은 4단계에 붙는 것이지 독립 과제가
아니다.

## 1-C. 측정값 불가침

*"측정값은 절대 수정하거나 추측하면 안돼"* · *"모든 점수는 반올림이나 절삭 없다"* ·
*"모든 값 동일하게 자르기로"*

```
저장·API   잰 그대로 (round() 0곳)
화면       소수점 두 자리까지 자르기. 반올림 금지. 점수·비율·금액·횟수 전부
못 잰 값   0.00 이 아니라 —
```
