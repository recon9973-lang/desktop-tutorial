# §1. 확정 — 다시 묻지 않는다

## 1-A. AI 답변 관측 설계

출처: `docs/observation-engine.md` §9 — *"확정된 운영 설계 (사장님 결정 2026-08-08)"*

```
주기      핵심 질문 주 1회 · 확장 질문 월 1회
기본값    핵심 5~8개 · 확장 20개 안팎 (화면에서 수정)
엔진      5개 동일 횟수. 비중 조절 금지 — 구성비가 전체 언급률을 좌우한다
반복      3회
모드      검색 켬 + 끔 (Perplexity Sonar 는 끔이 없다)
수동측정  kind=MANUAL 로 별도 저장 · 추이 그래프에서 제외
모델      관측에는 gpt-5 (gpt-4o 계열은 검색 호출 금액을 낼 수 없다)
```

**정밀도** [계산] `MoE = 1.96 × √(p(1−p)/n)`, `p = 0.5`:

| 보는 값 | n | 오차 폭 | 어떻게 읽나 |
|---|---|---|---|
| 핵심 5개 전체 언급률 | 150 | **±8.0pp** | 거래처에 보고해도 되는 값 |
| 핵심 8개 전체 언급률 | 240 | **±6.3pp** | 〃 |
| 질문 하나 (전체 엔진) | 30 | ±17.9pp | 방향만. 소수점 못 붙인다 |
| 질문 × 엔진 한 칸 | 6 | ±40.0pp | 이 칸 하나로 "이 모델이 안 뜬다" 를 말하면 안 된다 |

**비용** (`observation-engine.md` §8-C): 질문 1개 1회 = **854원** · 거래처 1곳 월 **2.8~4만** ·
8곳 월 **22~32만**
