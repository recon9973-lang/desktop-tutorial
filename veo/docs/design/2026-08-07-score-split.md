# 점수 분리 — 기술 준비도와 연동·성과를 나눈다

**작성** 2026-08-07 · **상태** 승인됨 (사장님 지시) · **구현 전**
**결정** 지금 하나의 0~100 점에 섞여 있는 것을 둘로 나눈다.

---

# 1. 왜 나누는가 — 분모가 상황마다 바뀐다

## 1.1 실측한 것

SEO 명세의 영역 배점 합은 **150.0** 이다. 그런데 표시되는 점수는 늘 0~100 이다.
**채점에 성공한 영역의 배점 합으로 나눠 100 으로 환산**하기 때문이다.

```
[실측] 전부 통과일 때
   연동 3영역 빠짐   →  분모 130.0  →  100.00점
   연동 3영역 포함   →  분모 150.0  →  100.00점
```

같은 100 점인데 **잰 자가 다르다.**

## 1.2 지금은 사고가 안 난다. 곧 난다

```
[실측] 거래처 8곳 전부 서치콘솔 미연결 — 그래서 모두 같은 분모(130)를 쓴다
```

**한 곳이라도 연결하면 그날 깨진다.**

```
A병원  연결함    →  분모 150 으로 채점
B병원  미연결    →  분모 130 으로 채점

"A 가 B 보다 낫다" 고 말할 수 없다. 자를 바꿔서 쟀다.
```

그리고 그 전에 매긴 점수들과도 비교가 끊긴다.

## 1.3 명세가 이미 그러라고 적어 두었다

`score_meaning` 원문:

> 검색 순위 예측값이 아니며, **실제 검색 성과(노출·클릭·순위)는 별도 지표로 표시합니다.**

그래놓고 `관측·성과` 5점을 점수 안에 넣었다. **스스로 정한 원칙과 어긋난다.**

# 2. GEO 는 문제가 없다 — 손대지 않는다

```
[실측] GEO 1.3.0 · 최근 실행 (venomad.com)
   7개 영역 전부 SCORED · 채점에 쓴 배점 합 110.0 = 선언 합 110.0
   관문 영역 없음 · 총점 상한 0개
   '해당없음' 이유는 전부 "이 페이지엔 그런 게 없다" 유형
```

**분모가 흔들리지 않는다.** 유일한 외부 의존인 `외부 검증 가능성`(10점)도 채점되고 있고,
그 안의 참고 항목 하나만 N/A 다.

→ **이번 변경은 SEO 명세만 대상으로 한다.** GEO 를 같이 건드릴 이유가 없다.

# 3. 나누는 선

## 3.1 기술 준비도 — 0~100점 (주 지표)

사이트를 고쳐서 올릴 수 있는 것. **분모 고정.**

| 영역 | 배점 | 왜 여기인가 |
|---|---|---|
| 색인 차단 | 30.0 | 사이트가 검색에 존재하는가 |
| 대표 URL 혼란 | 21.4 | 사이트 구조 |
| 해석 불가 | 28.6 | 페이지 내용 |
| 경쟁력 | 28.6 | 속도·보안·링크 |
| 클릭·표현 | 14.3 | 검색 결과에서의 표현 |
| 위생 | 7.1 | 잔여 기술 항목 |
| **합계** | **130.0** | → 100점으로 환산. **항상 이 분모** |

## 3.2 연동·성과 — 점수가 아닌 별도 표시

**"연결하면 열리는 것"** 이지 사이트 품질이 아니다.

| 항목 | 지금 배점 | 바뀌는 표시 |
|---|---|---|
| 검색엔진 연동 (4항목) | 10.0 | **연동 상태** — `2/4 연결됨` |
| 관측·성과 (3항목) | 5.0 | **실제 성과** — 노출·클릭·색인 수 |
| 오프페이지 (3항목) | 5.0 | **외부 신호** — 도구 연동 시 표시 |

**성과는 점수로 만들지 않는다.** `노출 1,240회 · 클릭 87회` 가 `5점 만점에 3점` 보다
대행사에게도 거래처에게도 쓸모 있다.

## 3.3 화면에서 어떻게 보이나

```
┌───────────────────────────────┐
│  SEO 기술 준비도               │
│         82.1 점                │   ← 크게. 주 지표
│  59개 중 52개 측정 (88%)       │
└───────────────────────────────┘

  연동          ○○●●  2/4 연결됨      → 서치콘솔·네이버 연결 안내
  실제 성과     연동 후 표시됩니다
  외부 신호     도구 미연동
```

# 4. 무엇을 고치나

## 4.1 명세 (`veo.seo.readiness` → 2.0.0)

세 영역에 **점수에 넣지 않는다는 표시**를 단다. 삭제하지 않는다 —
판정은 그대로 하고, 총점 계산에서만 뺀다.

```yaml
categories:
  - id: search_engine_integration
    scoring: informational      # 새 값. 기본은 scored
  - id: observability_outcomes
    scoring: informational
  - id: offpage_entity
    scoring: informational
```

**왜 삭제하지 않는가** — 판정 자체는 값어치가 있다. "서치콘솔이 연결 안 됐다" 는 대행사가
해야 할 일이고, 이슈 목록·작업 큐에는 그대로 떠야 한다. 총점에만 안 들어갈 뿐이다.

## 4.2 채점기 (`scoring/evaluator.py`)

```
지금  effective_weight_total = 채점 성공한 모든 영역의 배점 합   ← 상황마다 바뀜
바꿈  effective_weight_total = scoring:scored 영역의 배점 합     ← 고정
```

`informational` 영역은 `ScoreResult` 에 **따로 담아** 화면·리포트가 쓸 수 있게 한다.

## 4.3 화면 (`console/seo`)

- 주 점수 아래에 측정 범위를 병기 — **이미 계산하는 값이다**
- 연동·성과·외부 신호를 별도 블록으로

## 4.4 리포트

```
이 진단은 기술 항목 52개로 채점했습니다. (59개 중 7개는 연동 대기)
```

# 5. 되짚어야 할 것

| 확인 | 방법 |
|---|---|
| 기존 점수와 비교 가능한가 | **아니다.** 분모가 130 으로 고정되면 숫자가 바뀐다 |
| 얼마나 바뀌나 | 지금 거래처 8곳은 이미 130 분모라 **변화 없음** [실측] |
| 명세 버전 | 2.0.0 (주 버전 올림 — 점수 의미가 바뀐다) |
| 지난 실행 | 1.9.0 으로 저장된 것은 그대로 둔다. 재채점하지 않는다 |

**거래처 8곳이 전부 미연결이라 지금 바꾸면 점수가 안 바뀐다.** 연결이 시작된 뒤에
바꾸면 그 시점에 전 거래처 점수가 흔들린다 — **지금이 가장 싼 시점이다.**

# 6. 순서

```
1  명세 2.0.0 초안 — 세 영역에 scoring: informational
2  채점기 — 분모를 scored 영역으로 고정 + informational 을 따로 담기
3  시험 — 되돌리면 깨지는 것으로. 특히 "연동 유무가 점수를 바꾸지 않는다"
4  화면 — 주 점수 + 측정범위 병기, 연동·성과 별도 블록
5  리포트 문구
6  판올림 · 배포 · 운영 확인
```
