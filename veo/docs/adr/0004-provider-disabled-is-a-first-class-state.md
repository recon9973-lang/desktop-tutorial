# ADR 0004 — 자격증명이 없으면 '비활성'이라고 말한다

- 상태: 채택
- 일자: 2026-07-28

## 배경

네이버 SearchAd, DataLab, Search Console, CrUX, OpenAI 자격증명은 개발 초기에 없다.
개발 편의를 위해 그럴듯한 값을 만들어 넣으면, 그 값이 데모와 스크린샷을 거쳐
제품 결과처럼 굳는다. 실제 데이터와 구분되지 않는 순간 진단 도구의 존재 이유가 사라진다.

## 결정

- `ProviderState.DISABLED_NO_CREDENTIAL`을 정식 상태로 둔다.
- 해당 제공자에 의존하는 검사는 `UNKNOWN`을 반환하고 사유를 남긴다. 실패가 아니다.
- `GET /api/providers`가 각 제공자의 상태와 그 의미를 한국어로 그대로 보고한다.
- 테스트는 `tests/fixtures`의 명시적 fixture만 사용한다. 실제처럼 보이는 가짜 응답을
  제품 코드 경로에 두지 않는다.
- 아직 만들지 않은 분석은 그럴듯한 결과를 반환하지 않고 `NotImplementedError`로 거절한다.

## 결과

- 초기 상태의 화면은 비어 보이지만 정직하다. `EmptyState`가 "아직 측정 데이터가 없습니다"를
  표시한다.
- 릴리스 체크리스트의 차단 조건에 "가짜 provider 결과"가 포함된다.
