# ADR 0011 — 이슈는 재측정으로 닫힌다. 클릭으로 닫히지 않는다

- 상태: 채택
- 일자: 2026-07-28

## 배경

이슈 추적기에서 가장 흔한 실패는 사람이 스스로 자기 발견을 닫는 것이다.
대시보드는 깨끗해지고 웹사이트는 그대로다.

## 결정

- 사람은 이슈를 `FIX_CLAIMED`(고쳤다고 주장함)로만 옮길 수 있다.
- `VERIFIED_RESOLVED`는 **해당 URL과 해당 check_id만 다시 측정한 결과가 통과일 때만**
  도달할 수 있다. 다른 경로는 상태 기계에서 거부한다.
- 재검증은 사이트 전체가 아니라 영향받은 URL만 다시 가져온다.
  하나의 이슈를 확인하려고 전체 크롤을 도는 것은 비용이 아니라 설계 실패다.
- 실패한 재검증은 조용히 `OPEN`으로 돌아가지 않고 `VERIFICATION_FAILED`가 된다.
  "고쳤다고 했는데 아니었다"는 "아직 안 고쳤다"와 다른 사실이다.
- 이슈 동일성은 `(check_id, 정규화된 영향 URL 집합)` 지문으로 판정한다.
  두 번의 스캔에서 같은 문제는 두 행이 아니라 이력을 가진 한 행이다.
  이걸 틀리면 재발 추적이 무의미해진다.
- 한 번 `VERIFIED_RESOLVED`였던 이슈가 다시 나타나면 `RECURRED`이며 횟수와
  각 주기의 시각을 보존한다. 세 번 재발한 문제는 한 번 발견된 문제와 다른 대화다.

## 결과

- "해결됨" 숫자가 실제로 무언가를 뜻한다.
- 대가: 재검증이 끝나기 전까지 이슈가 열려 있다. 보고서가 덜 예뻐 보이는 대신
  사실이다.
