# ADR 0015 — 프롬프트 집합은 감사 대상 산출물이다

- 상태: 채택
- 일자: 2026-07-28

## 배경

경쟁 비교를 조작하는 데 숫자를 위조할 필요가 없다. **질문만 고르면 된다.**

고객이 잘 나오는 "서초 임플란트 잘하는 곳"은 묻고, 잘 안 나오는 "임플란트 부작용"은
뺀다. 이후 모든 계산은 산술적으로 완벽하고 결론은 거짓이다. 그리고 이 실패는
데이터에 아무 흔적을 남기지 않는다.

## 결정

- 프롬프트 집합은 **버전이 있고 체크섬이 붙은 고정 산출물**이다. 비교에 들어간 두
  브랜드는 바이트 단위로 같은 질문을 받으며, 체크섬이 그걸 증명한다.
- **균형은 주장이 아니라 검사된다.**
  - 질문 최소 5개.
  - 한 의도가 전체의 50%를 넘을 수 없다 — "추천" 질문만 모으는 것이 전형적 조작이다.
  - **신뢰·안전(부작용·후기)과 비교 의도는 필수다.** 브랜드가 가장 빼고 싶어 하는
    질문이고, 빼면 노출률이 실제보다 높게 나온다.
  - 브랜드명이 들어간 질문이 50%를 넘을 수 없다. 브랜드를 직접 물으면 언급은 거의
    보장되므로 가시성이 아니라 재인지를 재게 된다.
- **질문을 빼려면 사유를 반드시 기록**해야 하고, 뺀 결과는 **다른 체크섬을 가진 다른
  집합**이다. 좁히는 것은 정당하지만 조용히 좁히는 것은 아니다.
- **사업 중요도는 분석가의 추정이며 그렇게 이름 붙인다.** 측정된 검색량과 같은 필드를
  절대 공유하지 않는다. 공유하면 추정치가 결국 데이터로 읽힌다.

## 결과

- 균형 잡힌 집합을 만드는 데 노력이 든다. 그게 이 산출물의 값이다.
- 고객이 "우리 불리한 질문은 빼주세요"라고 하면, 뺄 수는 있지만 보고서에 남는다.
