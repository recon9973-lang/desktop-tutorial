|---|---|---|

호출 **전에** 거절한다. 어느 엔진이 끌 수 있는지는 `/observations/engines` 가 알려주고,

## 4-A. 무슨 일이 있었나

사장님 지적:

세어 보니 **13건**이었고, 그중 **하나는 운영까지 나갔다.**

```
[실측] docs/CORRECTIONS.md
   총 13건 · 사장님이 잡은 것 5건 (38%) · 제품 반영 1건
   분류: 지어낸 설명 4 · 안 세고 단정 4 · 손계산을 실측으로 3 · 범위 밖 조언 2
```

**운영까지 나간 것(13번)** — GEO "복사해서 붙여넣으세요" 코드 안에:

```
"붓기는 보통 2~3일째 가장 심하고 5~7일 안에 대부분 가라앉습니다"   의학 서술
"국산 임플란트 100만원~ / 수입 150만원~ / 3~4개월"                비급여 진료비
"임플란트 10년 생존율 약 95% (대한구강악안면임플란트학회, 2024)"   없는 연구 + 실재 학회 인용
"환자 412명 대상 … 37명 제외"                                    하지 않은 조사
"들안로 209, 2층 · 053-000-0000"                                실재할 수 있는 주소
```

전부 출처가 없다. 병원이 그대로 올리면 우리가 지어낸 진료비를 게시하고, 하지 않은 조사를
자기 이름으로 발표하고, **없는 연구를 실재하는 학회가 발표한 것처럼 만든다.** 그리고 AI 가
그것을 인용한다 — 우리가 파는 것이 정확히 그것이다.

## 4-B. 왜 이렇게 되는가

**참인 문장 뒤에 이유를 붙이는 것은 자연스러운 다음 문장이고, 그럴듯한 이유를 만드는 것은
내가 특히 잘하는 일이다. 그리고 읽어서 아는 것과 내가 지어낸 것이 나에게는 똑같이
느껴진다.** 둘을 가르는 내부 신호가 없다.

그래서 "조심하겠다" 는 대책이 못 된다 — 조심할 대상을 내가 못 알아본다.

세 갈래로 다르게 생겼다:

| 분류 | 모양 | 예 |
|---|---|---|
| **지어낸 설명** | 사실은 맞는데 **왜**를 지어냄 | "3개로는 균형을 못 맞춘다" (실제로는 맞출 수 있음) |
| **안 세고 단정** | 한 곳만 보고 "없다" | "브랜드 화면이 없다" (있었음) |
| **손계산을 실측으로** | 눈으로 더한 값에 `[실측]` | "분모 130" (실제 100.0) |

# 6. 경쟁사 — GPTO (어크로스)

```
[그들 주장] gpto.kr
   "10대 LLM 매주 모니터링" · "주 1회 오토 사이클"
   "500+ 학습 채널 자동 배포" · "18+ 언어"
   고객 100곳 평균 +15%, 사례 10주 +44%p
```

**대시보드는 파는 물건이 아니라 "일해서 올렸다" 는 영수증이다. 돈은 배포에서 난다.**

| | GPTO | VEO |
|---|---|---|
| ① SEO 기술 진단 | 없음 | 45건 |
| ② GEO 구조 준비도 | 없음 | 19건 |
| ③ AI 답변 관측 | 본체 | 0건 ← 만드는 중 |
| ④ 네이버 | 없음 | 열쇠 살아 있음 |
| ⑤ 콘텐츠 생성·배포 | 본체 | 범위 밖 (ERP 토스) |

**그들에게 없는 것** — "왜 안 뜨는지" 를 못 짚는다. 언급률이 낮으면 "콘텐츠를 더 뿌리자"
밖에 답이 없다. 그리고 네이버가 통째로 비어 있다.

**그들이 앞선 것** — 검색 켬/끔 분리 · 8주 추이 · 5대 LLM · 경쟁사 63개 자동 추출 ·

**확인 안 되는 것 셋** — 반복 횟수 미공개 · SMR 산식 미공개 · **인과 증명 없음**(대조군 부재).
